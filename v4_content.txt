한국 줄타기 로봇의 FWE 균형 제어 메커니즘 수식 유도 가이드_V4 (최종 완결본)
본 문서는 복잡한 줄타기 로봇의 비선형 역학 시스템에서 균형을 달성하기 위한 이산적 FWE(Fold-Wait-Extend) 메커니즘의 수학적·물리적 전 과정을 생략 없이 완벽하게 유도한 최종 이론 가이드입니다. 특히 시스템 행렬의 블록 분리(Decoupling)와 기하학적 구속 조건의 역학적 위상을 명확히 정립하여, 고등학생 및 학부생 수준에서 한 치의 논리적 모순 없이 완벽히 이해할 수 있도록 밑바닥부터 꼼꼼하게 기술하였습니다.
1. 물리 시스템의 정의 및 좌표계 (곡률 리프레임)
1.1 유효 반지름 L_eff = R - h 의 기하학적 도출
아래로 볼록하게 처진 슬랙라인(줄)은 위쪽을 향해 오목한 곡률 호(Arc)를 형성합니다. 이 호의 기하학적 중심인 곡률중심(천장 고정축)을 원점 O라고 정의합니다. 곡률중심 O에서 줄(로봇의 발밑 바닥)까지의 거리를 줄의 곡률반경 R이라고 정의합니다. 로봇의 발목에서부터 로봇 신체 전체의 무게중심(CoM)까지의 직선 거리를 h라고 정의합니다. 로봇이 줄 위에 똑바로 서서 무게중심을 위쪽, 즉 곡률중심 O를 향해 뻗고 서 있으므로, 상상 속의 천장 고정축 O에서부터 로봇의 실제 무게중심(CoM)까지의 수직 유효 거리는 전체 반지름 R에서 높이 h를 차감한 R - h가 됩니다. 이에 따라 줄 시스템이 하나의 거대한 단진자처럼 좌우로 흔들릴 때의 고유진동수 ω는 뉴턴의 원운동 방정식에 의해 다음과 같이 엄밀하게 정의됩니다.
ω = √(g / (R - h))
1.2 절대 연직 좌표계 β의 물리적 필연성
몸체의 기울기 각도 β는 지구 중심을 향하는 연직선(지면 수직선)과 로봇 무게중심이 이루는 '절대 각도'로 정의합니다. 몸체를 쓰러뜨리는 근본 원인인 중력 가속도 g는 언제나 지구 중심 방향(연직 아래)으로만 작용하기 때문에, 중력 토크 방정식을 결합 항 없이 순수하게 유지하기 위해서는 절대 연직 좌표계를 고수해야 합니다. 발의 수평 위치가 원점으로부터 x_foot(R·φ)만큼 이동해 있을 때, 몸체 막대가 연직선 기준 절대 각도 β만큼 기울어져 있다면 발목에서 무게중심까지의 순수한 수평 거리는 소각 근사(sinβ ≈ β)에 의해 h·β가 됩니다. 따라서 중앙 기준 무게중심의 절대 수평 위치 x_CoM은 다음과 같은 순수한 선형 결합 형태로 일치하게 됩니다.
x_CoM = x_foot + h·β = R·φ + h·β
2. 역진자 기울어짐 미분방정식의 세부 해 풀이
발밑의 줄이 순간적으로 평형 상태에 고정되어 있다고 가정하고, 로봇 무게중심이 중력 토크를 받아 연직선 밖으로 쓰러지는 역진자 운동의 미분방정식을 한 단계씩 유도합니다.
2.1 뉴턴 회전 역학 방정식 세우기
로봇 신체의 총 질량을 M이라 하면, 무게중심에 수직 아래로 중력 Mg가 가해집니다. 발목 회전축을 기준으로 무게중심까지의 거리가 h이므로, 중력이 몸체를 외곽으로 밀어내 쓰러뜨리려는 중력 토크 τ는 다음과 같습니다.
τ = Mg · h · sinβ
미세 요동을 가정하여 테일러 전개 1차 항인 소각 근사(sinβ ≈ β)를 적용하면 토크 식은 다음과 같이 선형화됩니다.
τ ≈ Mghβ
발목 기준 신체 막대의 관성모멘트를 I라고 정의하고, 회전 역학의 핵심 방정식인 τ = I·β'' (토크 = 관성모멘트 × 각가속도)에 대입합니다.
I · β'' = Mgh · β
양변을 관성모멘트 I로 나누고, 시스템의 고유 물리량 덩어리를 고유 낙하율 λ = √(Mgh / I)로 정의하면 아래와 같은 쓰러짐 미분방정식을 얻습니다.
β'' = λ² · β
2.2 지수함수 대입을 통한 일반해 도출 과정
위 방정식은 변위(β)가 커질수록 가속도(β'')도 같은 방향으로 증가하여 기하급수적으로 발산하는 형태이므로, 해의 형태를 지수함수인 β(t) = e^(rt) (r은 상수)로 가정합니다. 이를 시간에 대해 2회 연속 미분합니다.
1) 1회 미분 (각속도): β'(t) = r · e^(rt)
2) 2회 미분 (각가속도): β''(t) = r² · e^(rt)
이 미분 결과들을 원래의 방정식 β'' = λ²·β 에 대입합니다.
r² · e^(rt) = λ² · e^(rt)
지수함수 성분 e^(rt)는 모든 시간 t에서 결코 0이 될 수 없으므로 양변을 나누어 소거하면 특성방정식 r² = λ² 을 얻게 되며, 근은 r = ±λ 가 됩니다. 따라서 두 개의 독립된 기저 해 e^(λt)와 e^(-λt)의 선형 결합을 통해 아래와 같은 완전한 일반해를 얻습니다.
β(t) = C_a · e^(λt) + C_b · e^(-λt) (C_a, C_b는 초기조건 상출 상수)
2.3 초기 조건을 통한 쌍곡선함수(cosh, sinh) 특수해 도출 전개
수식의 직관적 해석을 위해 수학적으로 정의된 쌍곡선함수 cosh(x)와 sinh(x)의 정의를 호출합니다.
cosh(x) = (e^x + e^(-x)) / 2, \quad sinh(x) = (e^x - e^(-x)) / 2
초기 시점(t = 0)에서의 위치 초기값을 β(0) = β_after, 속도 초기값을 β'(0) = β'_after 라고 선언하고 일반해 식에 대입합니다. (cosh(0) = 1, sinh(0) = 0, cosh'(x) = sinh(x), sinh'(x) = cosh(x) 성질 이용)
일반해의 형태를 쌍곡선함수로 변환하여 β(t) = C_1·cosh(λt) + C_2·sinh(λt) 로 설정한 후 미분 식을 전개합니다.
1) 위치 식에 t = 0 대입:
β(0) = C_1·cosh(0) + C_2·sinh(0) = C_1 · 1 + C_2 · 0 = C_1 = β_after
2) 속도 식 β'(t) = C_1·λ·sinh(λt) + C_2·λ·cosh(λt) 에 t = 0 대입:
β'(0) = C_1·λ·sinh(0) + C_2·λ·cosh(0) = C_1·λ·0 + C_2·λ·1 = C_2·λ = β'_after ⇒ C_2 = β'_after / λ
구해진 계수 C_1과 C_2를 최종 대입하면, 초기 위치와 속도가 모두 살아있는 역진자 운동의 완전한 특수해 공식이 유도됩니다.
β(t) = β_after · cosh(λt) + (β'_after / λ) · sinh(λt)
3. 가·감속 삼각형(Bang-Bang) 제어 프로파일 역학
실제 구동에서 관절 각도가 순간적으로 멈출 때 줄과 로봇에 가해지는 무한한 임펄스 충격을 배제하기 위해, 전체 접기 시간 T_f 구간을 정확히 절반으로 나누어 가속과 감속을 대칭적으로 수행하는 삼각형 모델을 도입합니다. 우리의 제어 목표는 최종 도달 각도 변위를 오차 진폭에 비례하게 만드는 것입니다 (δ_fold = k_1·β₀).
3.1 등가속도 구간 분할 전개
전반부 가속 구간 (0 ≤ t ≤ T_f/2): 모터가 일정한 가속도 +a_f로 회전합니다. t = T_f/2 시점에서의 도달 각도 속도는 ω_half = a_f · (T_f / 2) 이며, 이동한 회전 각도는 δ_half = (1/2) · a_f · (T_f / 2)² = (1/8)·a_f·T_f² 입니다.
후반부 감속 구간 (T_f/2 ≤ t ≤ T_f): 모터가 정확히 반대 방향 브레이크 가속도 -a_f를 인가합니다. 대칭성에 의해 후반부 동안 이동하는 추가 각도 역시 (1/8)·a_f·T_f² 이며, t = T_f 종료 시점의 관절 속도는 ω_final = ω_half - a_f · (T_f / 2) = 0 으로 임펄스 충격 없이 완벽히 멈춥니다.
3.2 총 접기 각도와 각가속도 배치의 대수적 관계
전체 FOLD 단계 동안 이동한 총 각도 δ는 두 구간 각도의 합입니다.
δ = δ_half + δ_half = (1/8)·a_f·T_f² + (1/8)·a_f·T_f² = (1/4)·a_f·T_f²
우리의 비례 제어 가설 δ = k_1·β₀ 를 대입하여 모터 각가속도 a_f에 대한 관계식으로 풉니다.
k_1 · β₀ = (1/4) · a_f · T_f² ⇒ a_f = (4·k_1 / T_f²) · β₀
이에 따라 뉴턴 법칙에 의해 줄과 몸체에 가해지는 단위 시간당 가력 f_phi와 f_beta 역시 초기 오차 진폭 β₀에 완벽하게 선형 비례하게 묶여 전개됩니다.
f_phi = (c_foot / R) · a_f = (4·c_foot·k_1 / (R · T_f²)) · β₀ = (f_bar_phi / T_f²) · β₀
f_beta = (c_foot / h) · a_f = (4·c_foot·k_1 / (h · T_f²)) · β₀ = (f_bar_beta / T_f²) · β₀
4. 제4 메인 식의 최종 마스터 유도 (동적 출발 · 유한 제어)
선형 제어계의 최종 장인 제4 메인 식은 줄이 출렁이고 몸이 회전하는 동적 초기 상태(φ_i, φ'_i, β₀, β'_i)에서 출발하여, 삼각형 프로파일의 유한 시간(T_f) 동안 허리를 접고, T_w 동안 대기한 후, 다시 T_f 동안 대칭적으로 펼쳐 한 사이클 만에 원점으로 동시 리셋시키는 연립 방정식 세트입니다.
4.1 1단계 FOLD(T_f) 종료 시점의 정밀 상태 전개
선형 미분방정식의 중첩 원리에 따라, 삼각형 프로파일 가·감속 외력이 존재하는 1단계 종료 시점(t = T_f)의 상태는 초기값에 의한 동차 자유진동 해와 모터 가력 토크에 의한 비동차 특수해의 대수적 합으로 오차 없이 완벽히 분리됩니다. 비동차 ODE를 후반부 감속 반전까지 연속 적분하여 펼치면 다음과 같습니다.
1) 줄 진자 상태 공식 (t = T_f):
φ(T_f) = φ_i·cos(ωT_f) + (φ'_i/ω)·sin(ωT_f) + [2f_phi / ω²] · cos(ωT_f/2) · [1 - cos(ωT_f/2)]
여기에 f_phi = (f_bar_phi / T_f²)·β₀ 를 대입하여 β₀항으로 묶어냅니다.
φ(T_f) = φ_i·cos(ωT_f) + (φ'_i/ω)·sin(ωT_f) + β₀ · Φ_pos(T_f)
(단, Φ_pos(T_f) = [2f_bar_phi / (ω² · T_f²)] · cos(ωT_f/2) · [1 - cos(ωT_f/2)] )
속도 성분 역시 대칭 미분 전개를 통해 동일하게 분리됩니다.
φ'(T_f) = -φ_i·ω·sin(ωT_f) + φ'_i·cos(ωT_f) + β₀ · Φ_vel(T_f)
2) 몸 역진자 상태 공식 (t = T_f):
동일한 방식으로 쌍곡선함수 비동차 ODE의 연속 가·감속 구간을 대수 전개하여 결합합니다.
β(T_f) = β₀·cosh(λT_f) + (β'_i/λ)·sinh(λT_f) - [f_beta / λ²] · [cosh(λT_f) - 2cosh(λT_f/2) + 1]
f_beta = (f_bar_beta / T_f²)·β₀ 를 대입하여 β₀항으로 전정 정리합니다.
β(T_f) = β₀·cosh(λT_f) + (β'_i/λ)·sinh(λT_f) + β₀ · B_pos(T_f)
(단, B_pos(T_f) = -[f_bar_beta / (λ² · T_f²)] · [cosh(λT_f) - 2cosh(λT_f/2) + 1] )
몸체의 속도 성분 역시 연속 미분을 통해 결합 상수가 추출됩니다.
β'(T_f) = β₀·λ·sinh(λT_f) + β'_i·cosh(λT_f) + β₀ · B_vel(T_f)
4.2 2단계 WAIT 및 3단계 EXTEND의 행렬 블록 전파
위에서 구한 FOLD 단계 종료 값을 시작점으로 삼아, 대기 시간 T_w 동안 자유 스윙시키고(WAIT), 다시 T_f 시간 동안 역방향 토크 가·감속 프로파일을 통과(EXTEND)시킵니다. 시스템 행렬 구조가 두 진자 간 간섭이 없는 2×2 블록 대각 구조를 유지하므로, 최종 한 사이클 시간 T_total = 2T_f + T_w 시점에서의 최종 도달 공식은 다음과 같이 선형 결합 구조가 깨지지 않고 우아하게 전개됩니다.
φ_final = φ_i·cos(ωT_total) + (φ'_i/ω)·sin(ωT_total) + β₀ · d_bar_phi(T_f, T_w)
β_final = β₀·cosh(λT_total) + (β'_i/λ)·sinh(λT_total) + β₀ · d_bar_beta(T_f, T_w)
4.3 양변 무차원 분할을 통한 제4 마스터 메인 식 최종 도출
우리의 최종 이론적 목적은 한 사이클 종료 시점에 줄과 몸이 동시에 완벽하게 원점으로 수렴하는 해를 얻는 것입니다 (φ_final = 0, β_final = 0). 이 조건을 위 마스터 연립식에 선언하고 양변을 h·β₀ 와 R·β₀ 의 결합 인자로 정교하게 나누어 밸런스를 맞춤으로써 무차원 변수 3가지(ψ, v_φ, v_β)를 도출하여 대입하면 최종 제4의 메인 식이 완성됩니다.
👑 제4의 메인 식 (The Fourth Main Equation)
줄 동적 복원 마스터 방정식 (𝒢₁ = 0):
ψ · cos(ωT_total) + v_φ · sin(ωT_total) + d_bar_phi(T_f, T_w) · (R / h) = 0
몸 동적 복원 마스터 방정식 (𝒢₂ = 0):
cosh(λT_total) + v_β · sinh(λT_total) + d_bar_beta(T_f, T_w) = 0
5. 시스템 행렬의 블록 분리와 기하학적 결합의 행방 (물리적 위상 정립)
여기서 대단히 깊이 있는 물리적 의문이 발생합니다. "실제 시스템에서는 무게중심 방정식($x_{\text{CoM}} = R\phi + h\beta$)에 의해 줄이 움직이면 기하학적으로 몸도 변해야 하고, 줄의 가속도가 몸에 관성력을 주는데, 왜 우리가 유도한 최종 행렬과 수식에서는 두 진자가 완전히 분리(교차 성분이 0)되어 있는가?"에 대한 해답입니다.
5.1 상태 방정식(동역학) 차원에서의 독립 가정이 주는 결과
시스템 전달행렬 $M$은 위치 변수 자체의 즉각적인 기하학적 종속성을 기술하는 행렬이 아닙니다. 이 행렬의 본질은 오직 '가속도 차원(힘의 인과관계)'에서의 변화율을 시간 축으로 누적 전파하는 것입니다. 우리가 대기 구간(Wait)에서 내린 영리한 분리 가설은 "줄의 가속도 $\ddot{\phi}$는 오직 줄의 위치에만 의해서, 몸의 가속도 $\ddot{\beta}$는 오직 몸의 위치에 의해서만 결정된다"는 독립적 역학 배치였습니다 ($\ddot{\phi} = -\omega^2\phi, \ \ddot{\beta} = \lambda^2\beta$). 따라서 가속도 차원에서 두 진자의 상호 간섭(관성력 결합)을 완전히 디커플링했기 때문에, 시스템 전이를 뜻하는 행렬 $M$의 교차 대각 블록이 수학적으로 깨끗하게 0이 된 것입니다.
5.2 기하학적 결합의 진짜 행방: 경계 조건(Boundary Conditions)의 문지기
그렇다면 두 진자를 묶어주는 거역할 수 없는 기하학적 끈인 $x_{\text{CoM}} = R\phi + h\beta$는 수식 어디로 사라진 것일까요? 이 결합은 시스템 행렬 내부가 아니라, 사이클의 처음과 끝을 통제하는 '경계 조건(Boundary Conditions)' 영역에서 문지기 역할을 수행하며 계를 완벽하게 지배하고 있습니다.
시작점 (Fold Gate): 허리를 접는 순간, 작용-반작용에 의해 전체 무게중심($x_{\text{CoM}}$)은 허공에 가만히 멈춰 있어야 한다는 강력한 기하학적 구속으로 인해 줄 각도 $\phi$와 몸 각도 $\beta$의 초기 상태가 서로 반대 부호로 강제 배정됩니다. 이 결합 효과는 행렬식이 아니라 외력 변위 벡터 $d$에 온전히 저장되어 수식에 녹아듭니다.
종착점 (Extend Gate): 대기 시간 동안 행렬 $M$ 내부에서 두 진자는 서로 간섭하지 않고 독립된 우주처럼 평화롭게 흘러갑니다. 그러다가 사이클이 끝나는 최종 마스터 시점($t = T_{\text{total}}$), 제어기의 목표 조건인 "최종 무게중심과 발을 모두 평형점 0으로 만들겠다"라고 선언하는 그 최종 연립 구속 방정식 문턱에서 두 변수가 비로소 다시 만나 연립 구속을 형성하게 됩니다.
5.3 레이어 분리(Decoupling Layer) 설계의 학술적 의의
"기다리는 동안(동역학)은 복잡한 교차 간섭 없이 심플하게 분리하고($M$의 블록 대각화), 시작과 끝(경계 조건)에서만 기하학적 끈으로 강하게 묶어 세우는" 제어 레이어 분리 설계는 대단히 세련된 물리학적 모델링 기법입니다. 이 영리한 배치 덕분에 복잡한 유한 시간 삼각형 가·감속 모델에서도 수식이 꼬이지 않고 초기 오차 $\beta_0$가 깨끗하게 약분되는 선형 대수의 축복, 즉 진폭 독립성을 완벽하게 수호해 낼 수 있었던 것입니다.
6. 결론: 선형 이상화 이론의 그랜드슬램과 공학적 제어로의 가교
본 유도 과정을 통해 줄타기 로봇의 균형 매커니즘을 관통하는 선형 이상화 세계관의 4가지 메인 식 시리즈가 완벽하게 종결되었습니다.
이론의 세계에서는 수치해석적 방법을 통해 이 제4 메인 식을 만족하는 완벽한 이론적 해 $(T_f^*, T_w^*)$ 한 쌍을 실시간으로 계산해 낼 수 있습니다. 그러나 실제 현실의 제어 플랜트로 넘어갈 때 발생하는 하드웨어 한계를 극복하기 위해, 우리는 $T_f$를 현실적인 상수로 고정하게 되며, 이로 인해 부족해진 수학적 자유도를 보완하기 위해 4단계(Wait₂) 확장 모델을 도입하거나, 오차를 매 스텝 지수적으로 감쇠시키는 반복 수렴비(|r| < 1) 패러다임으로 선회하게 됩니다.
