## 1. 출발점: 3중 진자의 발견

v14 시뮬레이션에서 제어기를 끄면, 시스템은 **3중 진자**로 작동한다.

```
기둥 꼭대기 (고정점)
  └─ [φ] 로프 — 정진자 (안정)
       └─ [α] 하체 — 역진자 (불안정)
            └─ [θ] 상체 — 역진자 (불안정)
```

**액추에이터는 허리 관절 1개뿐.** 1개 모터로 3자유도 시스템의 균형을 잡는다.

**핵심 질문**: 행렬 계산(가제어성)이 아닌, **물리적 추론**으로 이것이 왜 가능한지 설명할 수 있는가?

---

## 2. 프레이밍: 한국 줄타기 vs 서양 줄타기

서양의 타이트로프는 **장대**의 큰 관성모멘트로 균형을 잡는다.
한국 줄타기는 **장대 없이** 몸만으로 균형을 잡는다.

물리적 차이: 한국 줄타기의 줄은 **처져 있다**(정진자). 이 처짐이 장대의 역할을 대신하는 것이 아닌가?

---

## 3. 핵심 발견: 토크가 줄에 닿지 않는다

토크 입력 벡터:
```
E = [0, -1, +1]
     φ    α    θ
```

허리 토크 τ는 φ(줄)에 직접 작용하지 않는다. 그런데 φ까지 제어된다.
→ **간접 경로**가 존재한다. 이 경로의 정체가 가설의 핵심.

## 4. 제어 메커니즘: 접기 → 기다리기 → 펴기

### 4.1 허리 토크의 진짜 효과

> **"허리 토크의 직접적 효과는 '몸을 접는 것'이지만, 물리적으로 의미 있는 효과는 '발을 옮기는 것'이다."**

### 4.2 한 사이클의 상세 역학 (개정: 5월 11일)

```
[초기 상태] 몸이 오른쪽으로 기울어짐
  CoM이 발보다 오른쪽에 x_cm 만큼 위치
  이대로 두면 → 역진자로 오른쪽으로 쓰러짐

       CoM
        ↓
    ●───/        ← 발은 왼쪽, CoM은 오른쪽
    발             중력: 오른쪽으로 전복 ↗

[1단계: 접기] 발을 CoM보다 더 오른쪽으로 이동 (오버슈트!)
  ※ CoM "아래"가 아니라 CoM "너머"로 이동하는 것이 핵심!

       CoM
        ↓
         \───●   ← 이제 발이 CoM보다 오른쪽!
              발    중력: 왼쪽으로 전복 ↙ (방향 반전!)

  → 중력 토크의 방향이 뒤집힘!
  → 역진자의 자유낙하가 "복원 방향(왼쪽)"으로 시작

[2단계: 기다리기] 두 가지가 동시에 일어남
  (a) 몸: 역진자 자유낙하로 왼쪽으로 기울어짐 (점점 빨라짐)
  (b) 줄: 정진자 복원으로 발이 중앙을 향해 복귀 중

[3단계: 펴기] 왼쪽으로 너무 가기 전에 몸을 편다
  → 펴면서 발을 왼쪽으로 이동 → CoM 바로 아래에 위치시킴
  → 이 타이밍이 정진자의 복귀 타이밍과 맞으면:
     기울기 복원 ✓  발 위치 복원 ✓
     → 한 사이클 완료!
```

### 4.3 복원의 물리적 본질: 역진자 자유낙하의 방향 반전

복원은 SHM(단순조화진동)이 **아니다**.
기울어진 몸이 "세워지는" 것이 아니라, **반대 방향으로 쓰러지는 것**이다.

- 발을 CoM 너머로 이동 → 중력 토크 방향 반전
- 몸이 반대쪽으로 자유낙하 → 이것이 "복원"
- 쓰러지기 전에 펴서 발을 CoM 아래로 → 안정화

**역진자의 불안정성을 역이용**: 빠르게 쓰러지려는 성질이 빠른 복원을 가능하게 한다.

### 4.4 진폭 독립성

역진자 자유낙하: β(t) = β₀·cosh(ωt),  ω = √(Mgh/I)

초기 기울기의 **일정 배율**에 도달하는 시간:
  cosh(ωt) = k (상수)  →  t = arccosh(k) / ω

**이 시간은 β₀에 무관하다!**

기울기에 비례하여 접으면 (오버슈트도 비례):
- 작은 기울기 → 작은 접힘/오버슈트 → 작은 역방향 낙하 → 시간 τ
- 큰 기울기 → 큰 접힘/오버슈트 → 큰 역방향 낙하 → 시간 τ (같음!)

정진자의 주기도 진폭에 무관하다 (등시성).

**→ 두 개의 진폭-무관 시간 스케일이 존재하므로, 한 번 매칭시키면 모든 크기의 외란에 대해 작동한다.**

### 4.5 시간 매칭 조건 (H2의 정량적 형태)

```
역진자 낙하 시간:  τ_fall = arccosh(k) / √(Mgh/I)
정진자 복귀 시간:  T_rope/4 = (π/2) · √((R+h)/g)

매칭 조건: τ_fall = T_rope/4
```

여기서 k는 오버슈트 비율에 의해 결정되는 상수.
이 조건을 R에 대해 풀면 **최적 R이 체형 파라미터의 함수**로 결정된다.

### 4.6 역(逆)그네 원리와의 연결

| 그네 (이전 연구) | 슬랙라인 (현재) |
|----------------|---------------|
| 바닥에서 몸 펴기 → 에너지 주입 | 바닥에서 **몸 접기** → 에너지 추출 |
| 꼭대기에서 몸 접기 → 에너지 주입 | 꼭대기에서 **몸 펴기** → 에너지 추출 |
| 진폭 증가 (펌핑) | 진폭 감소 (**안티펌핑**) |

### 4.7 변수 분리법과의 방법론적 유사성

| 변수 분리법 | 이 연구 |
|-----------|---------|
| "분리 가능한가?" | H1: p₁ = p₂이면 분리 가능 |
| 공간 방정식 X(x) | 접기 운동 (δ) |
| 시간 방정식 T(t) | 줄의 진동 (φ) |
| 고유값 λ | 타이밍 커플링 조건 (H2) |
| 경계 조건 | 줄 곡률 매칭 (H3) |

## 5. 세 가설의 정립 — 계층적 필요조건 체인

### 가설 H1: 무게중심 불변 조건 — 자유도 축소

> **"p₁ = p₂ 조건을 만족하면, 접힘은 CoM을 변화시키지 않고 발의 위치만 이동시킨다."**

- **역할**: 3자유도 → 실질 2자유도(φ + δ)로 축소. "정진자 위의 막대"로 단순화.
- **수학**: `[0,p₁,p₂]·M⁻¹·E`의 σ 성분이 R에 무관하게 (p₂−p₁)에 의해 결정됨
- **계산 결과** (5/8): R로는 p₁≠p₂를 보상할 수 없음 → H1은 독립적 필요조건

### 가설 H3: 줄 비교란 조건 — 깨끗한 입력 확보

> **"특정 R에서, 접힘이 줄의 운동(φ)을 교란하지 않는다. 접힘 = 순수한 발의 위치 이동."**

- **역할**: 접힘이 줄을 안 흔들게 함 → H2가 예측 가능하게 작동
- **H1과의 차이** (개정 5/11):
  - H1: 토크 → **CoM을 안 움직임** (R 무관, 체형 조건)
  - H3: 토크 → **줄(φ)을 안 흔듦** (R 의존, 곡률 조건)
- **수학**: `[1,0,0]·M⁻¹(R)·E = 0`을 만족하는 R (검증 필요)

### 가설 H2: 시간적 커플링 — 균형 복원의 핵심 메커니즘

> **"기울기에 비례하여 몸을 CoM 너머로 접으면, 역진자 자유낙하에 의해 복원이 시작된다. 이 낙하 시간이 정진자의 1/4 주기와 일치하는 R에서, 한 번의 접기-펴기 사이클이 균형을 복원한다."**

- **역할**: 실제 균형 복원 메커니즘. 최적 R을 결정.
- **핵심**: 복원은 SHM이 아니라 **역진자 자유낙하의 방향 반전**
- **진폭 독립성**: cosh(ωt) = k의 해가 β₀에 무관 + 정진자의 등시성
- **수학**: τ_fall = arccosh(k)/√(Mgh/I) = T_rope/4 = (π/2)·√((R+h)/g)

## 6. 세 가설의 관계: 계층적 필요조건 체인

```
H1 (체형 조건: p₁ = p₂)
  "접힘이 CoM을 안 바꾼다"
  → 3자유도를 2자유도로 축소
  → 접기 = 순수한 발 이동

        ↓

H3 (곡률 조건: 특정 R)
  "접힘이 줄을 안 흔든다"
  → 입력에 잡음이 안 섞임
  → H2의 타이밍 예측이 가능해짐

        ↓

H2 (타이밍 조건: τ_fall = T_rope/4)
  "역진자 낙하 시간 = 정진자 1/4주기"
  → 접기-펴기 한 사이클로 균형 복원
  → 최적 R 결정
```

**H1 없이** → 시스템이 너무 복잡, H3 논의 불가
**H3 없이** → 접힘이 줄을 교란, H2 타이밍 깨짐
**H2 없이** → 에너지 추출 불가, 균형 불가

## 8. 파울레티 선행연구와의 관계

- 파울레티: 단일 몸체 모델, 경험적 최적 R ≈ 1~1.5 × h_CoM
- 본 연구: 상·하체 분리 모델 → "접힘" 자유도의 역할 분석
- **모델이 다르므로 최적 R도 다를 수 있음** — 이것 자체가 의미 있는 예측

차별점:
1. **상·하체 분리** → 접힘이라는 내부 자유도
2. **CoM 불변 조건(H1)** → 파울레티에 없는 메커니즘
3. **시간 커플링(H2)** → 최적 R의 이론적 유도
4. **역그네 원리** → 이전 그네 연구와의 연결

## 부록: 수학적 결과

### 좌표 변환 (φ, α, θ) → (φ, σ, δ)

| 새 좌표 | 정의 | 의미 |
|---------|------|------|
| φ | 그대로 | 줄 흔들림 |
| σ = p₁α + p₂θ | 가중 합 | CoM 수평 위치 |
| δ = θ − α | 차이 | 접힘 각도 |

### 단순 진자 환원 (α = θ = φ일 때)

φ̈ = −g/(R + h_CoM)·φ,  L_eff = R + h_CoM

### R_optimal 공식 (H2, 수정 중)

역진자: τ_fall = arccosh(k) · √(I/(Mgh))
정진자: T_rope/4 = (π/2) · √((R+h)/g)

매칭: arccosh(k)² · I/(Mgh) = (π/2)² · (R+h)/g

→ R = [4·arccosh(k)²/(π²)] · I/(Mh) − h

※ k (오버슈트 비율)의 결정이 남은 과제
