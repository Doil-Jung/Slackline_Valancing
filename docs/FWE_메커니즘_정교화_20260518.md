# FWE(접기-대기-펴기) 메커니즘 정교화 — 2026.05.18 논의 정리

## 1. 프로젝트 배경

슬랙라인 위의 로봇은 **관절 하나**(몸 접기)로 균형을 잡는다.
시스템에는 두 가지 운동이 결합되어 있다:

| 운동 | 변수 | 성격 |
|------|------|------|
| 줄 위에서 발이 좌우로 흔들림 | **φ** (줄 진자) | **안정** — 단진자, 중앙으로 복원 |
| 무게중심(CoM)이 기울어짐 | **β** (역진자) | **불안정** — 중력이 쓰러뜨림, 제어 필요 |

**핵심 가설**: 접기·펴기의 타이밍이 줄 진자의 복귀 시간과 일치하면,
단순한 메커니즘(접고 펴기만 반복)으로 β를 점진적으로 0에 수렴시킬 수 있다.

---

## 2. 수정된 사이클 구조: 4단계 (F-W₁-E-W₂)

기존에는 3단계(Fold-Wait-Extend)를 가정했으나, 논의 결과 **4단계**가 올바르다:

### 한 사이클의 흐름

```
[발 중앙, φ=0] 
  → ① Fold (접기, T_f)     : 토크 인가. 반작용으로 발이 밀려남(φ 변화) + β 변화
  → ② Wait₁ (대기1, T_w1)  : 토크 없음. 발이 진자 운동으로 되돌아오기 시작. β는 중력으로 계속 변화
  → ③ Extend (펴기, T_e)   : 역방향 토크 인가. 발이 아직 돌아오는 도중에 펴기 시작
  → ④ Wait₂ (대기2, T_w2)  : 토크 없음. 발이 중앙(φ=0)에 도착할 때까지 대기
[발 중앙, φ=0] 
  → 반대 방향으로 다음 사이클 시작
```

### 왜 4단계인가?

- **펴기(Extend)는 발이 돌아온 뒤에 하는 것이 아니라, 돌아오는 도중에 한다.**
- 펴기가 끝났을 때 발이 딱 중앙에 있을 수도 있고(T_w2=0), 
  아직 덜 돌아왔을 수도 있다(T_w2>0).
- 어느 쪽이든 **발이 φ=0에 도착한 순간** 다음 사이클(반대 방향 접기)을 시작한다.

### 반복 구조

```
... → [φ=0] → 오른쪽 접기 → W₁ → 펴기 → W₂ → [φ=0] → 왼쪽 접기 → W₁ → 펴기 → W₂ → [φ=0] → ...
```

매 사이클마다 접기 방향이 교대(좌→우→좌→...)하고, β의 절댓값이 감소한다.

---

## 3. 접기-펴기 비대칭이 β를 감소시키는 이유

접을 때와 펼 때 **같은 크기의 토크**를 가하지만, 결과가 다르다.
비대칭의 원인은 **두 가지**:

1. **φ가 다르다**: 접을 때는 발이 중앙(φ=0)이지만, 펼 때는 발이 다른 위치에 있다.
2. **β가 다르다**: 접고 기다리는 동안 중력이 β를 더 기울어지게 만들었다.

이 두 효과가 동시에 작용하여 접기·펴기가 단순 상쇄되지 않고,
한 사이클 후에 β가 **순감소**한다.

## 4. 핵심 타이밍 조건

### 자기일관성(Self-consistency) 조건

> **Fold-Wait₁-Extend-Wait₂ 의 총 시간 = 발이 중앙(φ=0)으로 복귀하는 실제 시간**

이 복귀시간은 순수한 진자 ¼주기(`π/(2ω)`)와 **다르다**. 왜냐하면:

- 접기(Fold)가 발에 **킥(임펄스)**을 가해 **위상을 이동**시키기 때문이다
- 킥 후의 진자 운동은 `φ(t) = R·cos(ωt - θ)` 형태이며,
  시작 위상 `θ = arctan2(φ̇₀/ω, φ₀)` 가 킥에 의해 0이 아니게 된다
- 따라서 첫 번째 φ=0 도착 시간은 `t_복귀 = θ/ω + π/(2ω)` 로, ¼주기와 다름

### 왜 주기가 아니라 복귀시간인가?

- 킥이 진자의 **고유주파수 ω** 를 바꾸지는 않는다 (ω는 g, R, h로만 결정)
- 하지만 킥이 **위상**을 바꾸므로, **평형점으로 돌아가는 데 걸리는 시간**은 달라진다
- 우리의 제어는 "발이 중앙에 왔을 때 동작"이므로, 맞춰야 할 것은 **주기가 아니라 복귀시간**이다

## 5. 기존 전달행렬 모델의 문제점

| 문제 | 설명 |
|------|------|
| 3단계 구조 (F-W-E) | **4단계** (F-W₁-E-W₂) 여야 함. Wait₂가 빠져있음 |
| `T_f, T_w, T_e`가 임의 상수 | φ=0 복귀조건에서 **자기일관적으로 결정**되어야 함 |
| 접기 방향 고정 | 매 사이클마다 **방향을 교대**해야 함 (β가 양·음 교대하며 감쇠) |
| φ 복귀만 고려 | β 변화도 비대칭에 기여하므로 **φ와 β를 동시에** 고려해야 함 |

## 6. 실제 제어 구현 방안

### 문제: φ를 직접 측정할 수 없다

실제 로봇에서 φ(줄 위 발의 위치)를 직접 측정하는 센서가 없다.
그러면 "φ=0일 때 동작"이라는 조건을 어떻게 만족시키는가?

### 방안 A — 오픈루프 (타이밍 기반)

- 물리 모델(R, h, g, τ_fold, T_f)로 복귀시간을 **미리 계산**
- 타이머만으로 F → W₁ → E → W₂ 실행
- **선형 모델에서는 φ의 복귀시간이 매 사이클 동일** (킥 크기가 τ_fold, T_f로 고정되므로)
- φ 센서 불필요. 단, 모델 오차에 취약

### 방안 B — 칼만필터 (강건한 방법)

- **측정 가능한 것**: β (IMU), δ (관절 엔코더)
- **추정할 것**: φ, φ̇ (줄 진자 상태)
- 운동방정식을 상태공간 모델로 구성하면, β와 δ 관측으로부터 φ, φ̇를 추정 가능
- 추정된 φ가 0에 도달하는 순간 다음 동작 트리거
- 모델 오차에 강건

### 단계적 접근

1. **이론 검증** (현재): 전달행렬로 메커니즘 작동을 증명
2. **MuJoCo 검증**: φ를 직접 읽어서 메커니즘 확인 (완벽한 옵저버 역할)
3. **실제 로봇**: 오픈루프(방안 A)로 시도 → 안 되면 칼만필터(방안 B) 추가

## 7. 다음 단계 (집에서 이어갈 작업)

### 7-1. 4단계 전달행렬 재구성

기존 `one_cycle(T_f, T_w)` 함수를 **4단계**로 수정:

```python
def one_cycle_4phase(T_f, T_w1, T_e, T_w2, fp, fb):
    """Fold → Wait₁ → Extend → Wait₂ 전체 사이클의 전달행렬"""
    A_F  = make_A(omega, lam, T_f)      # Fold 전이
    A_W1 = make_A(omega, lam, T_w1)     # Wait₁ 전이
    A_E  = make_A(omega, lam, T_e)      # Extend 전이
    A_W2 = make_A(omega, lam, T_w2)     # Wait₂ 전이
    
    b_F = make_b_fold(omega, lam, T_f, fp, fb)    # 접기 가력
    b_E = make_b_fold(omega, lam, T_e, -fp, -fb)  # 펴기 가력 (역방향)
    
    M = A_W2 @ A_E @ A_W1 @ A_F
    d = A_W2 @ A_E @ A_W1 @ b_F + A_W2 @ b_E
    return M, d
```

### 7-2. φ=0 복귀조건을 만족하는 시간 계산 (자기일관성)

주어진 `T_f`, `T_e`에 대해 `T_w1`, `T_w2`를 구하여
한 사이클 후 φ=0, φ̇=0 이 되도록 하는 방정식을 풀어야 함.

```
조건: v_end = M @ v_start + d 에서 v_end[0] = 0 (φ=0)
      v_start[0] = 0 (시작할 때도 φ=0)
```

이것은 `T_w1`, `T_w2`에 대한 비선형 방정식 → `scipy.optimize` 로 풀기

### 7-3. β 수렴 검증 (다중 사이클)

- 감소 비율(spectral radius)이 1 미만인지 확인
