# 슬랙라인 로봇 — 실측 캘리브레이션 절차

> **날짜**: 2026-06-20
> **대상**: v11_small 급 실제 프로토타입 (OpenCR + XM430-W210-R)
> **목적**: 질량·길이·CoM·관성모멘트·토크상수를 실측하여 모델 파라미터를 확정하고, 그에 맞는 LQR K게인을 산출한다.

---

## 0. 왜 실측이 필요한가

`compute_K.py`·`lqr_balance.ino`에 박혀 있는 값은 **v11_small 가정값**(균일 막대 근사 `I=mL²/12`, `ℓ=L/2`)이다. 실제 로봇은 모터·보드·배터리가 한쪽에 몰려 있어 **CoM과 관성모멘트가 균일 막대와 크게 다르다**. 선형화 모델의 질량행렬 `M_eq`와 중력행렬은 `m, ℓ, I`에 직접 의존하므로, 이 값이 틀리면 K게인도 틀린다.

확정해야 할 파라미터(3-DOF 모델, v17 규약):

| 기호 | 의미 | 측정 방법 |
|---|---|---|
| m₁ | 하체 질량 (발→힙 구간 + 그 구간 부착물) | 저울 |
| m₂ | 상체 질량 (힙→머리 구간 + 모터·보드·배터리) | 저울 |
| L₁ | 하체 길이 (발 접촉점 → 힙 축) | 자 |
| L₂ | 상체 길이 (힙 축 → 상체 끝) | 자 |
| ℓ₁ | **발 → 하체 CoM** 거리 | 나이프에지 균형법 |
| ℓ₂ | **힙 → 상체 CoM** 거리 | 나이프에지 균형법 |
| I₁ | 하체의 **자기 CoM 기준** 관성모멘트 | 복합진자법 |
| I₂ | 상체의 **자기 CoM 기준** 관성모멘트 | 복합진자법 |
| R | 줄 처짐 원호 반경 | 설치 시 기하 측정 |
| b_θ | 상체 점성 감쇠 | 자유진동 감쇠법(선택) |
| Kt | 모터 토크상수 (전류→토크) | 전류제어 토크 보정 |
| τ_max | 모터 가용 최대 토크 | 스펙 + 실측 클립 |

> ⚠️ **모델의 CoM 기준점이 세그먼트마다 다르다.** ℓ₁은 *발*에서, ℓ₂는 *힙*에서 잰다. 헷갈리면 K가 통째로 틀어진다.

## 1. 준비물

- 전자저울 (0.1 g 분해능 권장, 최소 1 g)
- 직자/줄자 (1 mm 분해능)
- 나이프에지(칼날 모서리)나 가는 원통 봉 — 균형점 찾기용
- 스마트폰 (슬로모 카메라 + 스톱워치) — 진동 주기 측정
- 클램프/스탠드 — 세그먼트를 한 점에서 자유롭게 매달기 위한 지그
- 작은 핀/못 — 회전축(피벗)
- 알려진 추 (예: 50 g, 100 g, 200 g 분동 또는 정밀히 잰 물체) — 토크 보정용
- 모눈종이/각도기 — 작은 진폭 확인용

## 2. 분해 vs 조립 상태 측정 — 원칙

로봇은 **힙 축(모터 출력축)** 을 경계로 위/아래 두 강체로 모델링된다. 따라서:

- **하체 세그먼트**: 발 끝 ~ 힙 축까지의 모든 것(하체 프레임, 하체 브라켓). 모터 본체는 힙에 있으므로 보통 상체 쪽에 포함시킨다(아래 3-A 참고).
- **상체 세그먼트**: 힙 축 ~ 상체 끝까지의 모든 것 + **모터 본체 + OpenCR + 배터리**.

가능하면 **힙 축에서 물리적으로 분리**해서 각 세그먼트를 따로 측정한다. 분리가 어렵다면 조립 상태에서 힙 축을 피벗으로 잡고 각 세그먼트를 측정하되, 반대쪽 세그먼트의 영향을 배제하도록 지그로 고정한다.

## 3. 질량 측정 (m₁, m₂)

### 3-A. 모터 본체의 귀속
모터 본체(82 g)는 힙 축에 위치한다. 모델에서 힙은 두 세그먼트의 경계(상체 회전축 위 거리 L₁ 지점)이므로, 모터 질량을 어디에 넣어도 그 CoM이 힙 축에 가까우면 영향이 작다. **관례상 상체(m₂)에 포함**시키되, CoM 측정 시 모터가 힙 축 근처에 있으면 ℓ₂에 거의 기여하지 않는다.

### 3-B. 절차
1. 로봇을 힙 축에서 분리(또는 세그먼트별 부품을 식별).
2. 하체 세그먼트 전체를 저울에 올려 **m₁** 기록.
3. 상체 세그먼트(모터·보드·배터리 포함) 전체를 올려 **m₂** 기록.
4. 전체 질량 `m₁+m₂`를 따로 한 번 더 재서 합이 맞는지 교차검증.

|---|---|---|---|---|
| m₁ (하체) [g] | | | | |
| m₂ (상체) [g] | | | | |
| 전체 (교차검증) [g] | | | | |

## 4. 길이 측정 (L₁, L₂)

- **L₁**: 발 접촉점(줄에 닿는 V홈 바닥) → 힙 축 중심까지 직선거리.
- **L₂**: 힙 축 중심 → 상체 최상단(또는 머리 끝)까지 직선거리.

## 5. CoM 측정 (ℓ₁, ℓ₂) — 나이프에지 균형법

각 세그먼트를 칼날 위에 가로로 올려 **좌우가 수평으로 균형 잡히는 지점**을 찾는다. 그 지점이 그 세그먼트의 CoM이다.

### 5-A. 하체 ℓ₁
1. 하체 세그먼트를 칼날 위에 얹고 좌우로 움직여 균형점을 찾는다.
2. **발 접촉점에서 균형점까지의 거리** = ℓ₁.
3. 검산: ℓ₁이 L₁/2보다 힙 쪽(위)이면 무거운 부품이 힙 근처에 있다는 뜻.

### 5-B. 상체 ℓ₂
1. 상체 세그먼트(모터·보드·배터리 포함)를 칼날 위에서 균형 잡는다.
2. **힙 축에서 균형점까지의 거리** = ℓ₂.
3. 배터리·보드가 상단에 있으면 ℓ₂ > L₂/2 (CoM이 위로 치우침)일 수 있다.

|---|---|---|---|
| ℓ₁ | 발 | | |
| ℓ₂ | 힙 | | |

## 6. 관성모멘트 측정 (I₁, I₂) — 복합진자법

세그먼트를 한 점(피벗)에 매달아 **작은 진폭**으로 흔들고 주기 T를 재면, 그 피벗 기준 관성모멘트를 구할 수 있다.

### 6-A. 이론
복합진자 미소진동 주기:

```
T = 2π · √( I_pivot / (m · g · d) )
```

여기서
- `I_pivot` : 피벗축 기준 관성모멘트
- `m` : 세그먼트 질량
- `d` : 피벗 → CoM 거리
- `g` = 9.81 m/s²

따라서 피벗 기준 관성:

```
I_pivot = m · g · d · (T / 2π)²
```

CoM 기준 관성(모델이 요구하는 값)은 평행축 정리로:

```
I_cm = I_pivot − m · d²
```

### 6-B. 절차 (각 세그먼트 공통)
1. 세그먼트 한쪽 끝에 가는 핀/못을 끼워 **마찰 적은 회전축(피벗)** 을 만든다. (발 끝이나 힙 구멍을 피벗으로 쓰면 편하다.)
2. 피벗 → CoM 거리 `d`를 측정한다. (5절의 CoM 위치 이용. 피벗이 발이면 d=ℓ₁, 피벗이 힙이면 d=ℓ₂에 해당하지만, **실제 피벗 위치에 맞춰** d를 다시 잰다.)
3. **5° 이내**의 작은 각도로 살짝 밀어 흔든다. (큰 진폭은 비선형 오차.)
4. 스톱워치/슬로모로 **20회 왕복 시간**을 잰다 → `T = (20회 시간)/20`. (왕복 1회 = 한쪽 끝→반대 끝→복귀.)
5. 3회 반복 평균.
6. `I_pivot = m·g·d·(T/2π)²` 계산 → `I_cm = I_pivot − m·d²`.

### 6-C. 주의사항
- **공기저항·피벗 마찰**을 줄여라. 진폭이 천천히 줄어드는 게 정상이며, 주기는 진폭에 거의 무관(미소진동).
- d 단위는 m, T 단위는 s. m은 kg.
- `I_cm`이 음수가 나오면 측정 오류(보통 d 또는 T 오차). 균일 막대 근사값 `mL²/12`와 자릿수 비교로 sanity check.

### 기록표 — 관성 (세그먼트별로 한 장씩)
| 세그먼트 | m [kg] | d [m] | 20T(1) [s] | 20T(2) [s] | 20T(3) [s] | T평균 [s] | I_pivot | I_cm |
|---|---|---|---|---|---|---|---|---|
| 하체 (I₁) | | | | | | | | |
| 상체 (I₂) | | | | | | | | |

## 7. 토크 보정 (Kt, τ_max) — 전류제어

> **중요**: 현재 펌웨어(`lqr_balance.ino`)는 전류제어가 아니라 **위치제어**(`OP_EXTENDED_POSITION`)에 `KP_EQUIV=8.0`으로 토크를 흉내내고 있다. LQR이 설계한 토크와 실제 토크가 일치하지 않는다. **전류제어 모드로 전환**하면 토크를 직접 명령할 수 있고 보정이 명확해진다.

### 7-A. XM430-W210-R 전류↔토크 스펙
| 항목 | 값 |
|---|---|
| 스톨 토크 @12V | 3.0 N·m (2.3 A) |
| 공칭 토크상수 Kt | **1.304 N·m/A** (=3.0/2.3) |
| Goal/Present Current 단위 | **2.69 mA / unit** |
| Current Limit | 1193 unit = 3.21 A |

전류 명령 변환:
```
I[A]      = τ[N·m] / Kt
raw_unit  = I[A] · 1000 / 2.69        (= Goal Current 레지스터 값)
```
예: τ=1.0 N·m → I=0.767 A → raw≈285 unit.

### 7-B. Kt 실측 절차 (정적 토크법)
공칭 1.304는 출발점일 뿐, 기어·마찰 때문에 실제는 다르다. 직접 잰다.

1. `torque_cal.ino` 업로드 (전류제어 모드, 시리얼로 Goal Current 입력).
2. 모터 출력축에 **수평 암**(길이 r, 예: 10 cm)을 단단히 고정.
3. 암 끝에 알려진 추 m을 매달면 부하 토크 `τ_load = m·g·r`.
4. Goal Current를 0부터 천천히 올리며, **암이 추를 들어 수평을 유지하기 시작하는 전류** I*를 찾는다. 그 순간 모터 토크 ≈ τ_load.
5. 추 질량을 바꿔(여러 점) (I*, τ_load) 쌍을 모은다.
6. τ vs I* 직선 적합 → **기울기 = 실측 Kt**, **절편 = 정지마찰/데드밴드**.
7. Present Current도 같이 읽어 명령값 대비 실제 전류 오차를 본다.

### 7-C. τ_max 확정
- 연속 운전 토크는 스톨(3.0)보다 작다. 안전하게 **τ_max ≈ 2.0~2.5 N·m**로 잡고 시작, 발열·과전류 보이면 낮춘다. (현재 코드의 4.0은 과대.)

## 8. R, b_θ, g

- **R (줄 처짐 반경)**: 로봇을 줄 중앙에 올렸을 때의 처짐 깊이로부터 원호 반경을 추정. 줄 길이·장력에 따라 달라지므로 **실제 설치 조건**에서 잰다. 모르면 일단 0.30 m로 두고 R 스윕(아래 `deploy` 툴)으로 강건한 범위를 찾는다.
- **b_θ (상체 감쇠)**: 선택. 상체를 살짝 치고 자유진동 진폭 감쇠율(로그 감쇠율 δ)로 추정. 보통 작아서 0.01 근방이면 충분.
- **g** = 9.81 m/s² (고정).

## 9. 측정 후 다음 단계

1. 위 기록표 값을 `compute_K_measured.py` 상단 **MEASURED 블록**에 입력.
2. 스크립트 실행 → 폐루프 안정성/관측가능성 자동 검증 → K게인·칼만게인 L·Ad/Bd + 전류 변환 상수가 Arduino 코드로 출력.
3. 출력된 `K_lqr`, `L_kf`, `Ad_mat`, `Bd_vec`, `TAU2UNIT`, `Kt`를 `lqr_balance_current/`에 붙여넣기.
4. ★`gain_scale`은 0.3부터(이 플랜트는 개루프 불안정이라 0.2 미만이면 *발산*함 — 2026-06-22 확인).
   0.3에서 잡히면 0.5→0.7→1.0으로 ↑. 그리고 폐루프 전에 `[RATE]`로 루프속도가 ~500Hz인지 먼저 확인할 것
   (느리면 Ad 시간축이 틀려 φ̂가 발산 → 방향 반대로 접힘, 2026-06-22 폭주 원인).

> **권장 순서**: 질량 → 길이 → CoM → 관성 → 토크 보정. 앞 단계 값이 뒤 단계 계산(d, τ_load)에 쓰이므로 순서대로 진행한다.
