> **날짜**: 2026-03-31  
> **방법**: 실제 파라미터로 V10 물리엔진 직접 실행 (6크기 × 4시나리오 = 24회)

| 항목 | 값 |
|---|:---:|
| 스톨 토크 | 15 kgf·cm (1.47 N·m) @ 7.4V |
| 무부하 속도 | 1200 °/s (0.05 s/60°) |
| 무게 | 67g |
| 토크 제어 | PWM 듀티비 직접 제어 가능 |
| 위치 피드백 | ✅ 자기 엔코더 (~0.3° 정밀도) |

**토크-속도 곡선** (부하 시 가용 토크 감소):
```
속도 0°/s → 15.0 kgf·cm (스톨)
     400   → 10.0 kgf·cm
     800   →  5.0 kgf·cm
    1200   →  0.0 kgf·cm (무부하)
```

## 3. ★ 최적 크기 추천: L=25cm (총 50cm)

| 항목 | 값 |
|---|:---:|
| 상체/하체 길이 | 각 25cm |
| 총 높이 | 50cm (전시 규격 60cm 이내 ✅) |
| R (줄 처짐) | 35cm |
| m₁ (하체) | 132g |
| m₂ (상체) | 173g |
| 총 질량 | 304g |
| 자연 낙하 시간 | **92ms** |

### 왜 50cm인가?

1. **모든 시나리오 통과** (8.6°/20°/30°/교란 전부 ✅)
2. **낙하 시간 92ms >> 제어 루프 15ms** → 제어 지연에 대한 여유 ×6
3. **전시 규격 60cm 이내** 충분히 여유
4. 40cm도 통과하지만 50cm가 **낙하 시간이 12% 더 길어** 지연에 더 강건
5. 60cm도 좋지만 **크기와 무게가 불필요하게 증가**

## 4. ⚠️ 중요 발견: 서보 토크 포화

모든 크기에서 **모든 시나리오에서 토크 포화가 발생**합니다.

```
시뮬 요청 토크  →  서보 한계(1.47 N·m = 15 kgf·cm)에 도달
               →  클리핑 후에도 균형 유지됨 ✅
```

이것은 **"서보가 부족하다"는 뜻이 아니라**, 시뮬의 LQR이 이상적으로 계산한 토크가 서보 한계보다 크지만, **실제로는 서보가 줄 수 있는 최대 토크만으로도 균형을 잡을 수 있다**는 뜻입니다.

단, 토크-속도 곡선을 반영하면:

| 상황 | 힙 속도 | 해당 속도 가용 토크 | 필요 토크 | 판정 |
|---|:---:|:---:|:---:|:---:|
| 정상 균형 | ~50°/s | 14.4 kgf·cm | ~1 kgf·cm | ✅ 충분 |
| 8.6° 복원 | ~477°/s | 9.0 kgf·cm | 15.0 kgf·cm | ⚠️ 부족 |
| 교란 복원 | ~838°/s | 4.5 kgf·cm | 15.0 kgf·cm | ⚠️ 부족 |

> [!WARNING]
> 토크-속도 곡선을 고려하면 **고속 회전 구간에서 가용 토크가 줄어듭니다**. 하지만 시뮬에서 포화 상태로도 균형을 잡았으므로, 실물에서도 **실제 가용 토크 범위 내에서 균형은 가능**할 것으로 판단됩니다. 다만 복원 시간이 시뮬보다 길어질 수 있으며, 현장에서 게인 튜닝이 필요합니다.

## 5. 설계 주의사항

1. **초기 자세**: 줄 위에 세울 때 **최대한 수직**(10° 이내)으로 세팅
2. **게인 튜닝**: 실물에서 R(제어 노력 페널티) 값을 높여 토크 요구를 줄이는 방향으로 튜닝
3. **무게 중심**: 배터리를 상체 상단에, 보드를 중간에 배치 → 균일 막대 근사 유지
4. **서보 전원**: 7.4V(2S LiPo) 직접 공급으로 최대 토크/속도 확보
5. **제어 주기**: ESP32에서 1ms는 이상적이지만, **5ms로 해도 낙하시간(92ms) 대비 충분**
