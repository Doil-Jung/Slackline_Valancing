# 슬랙라인 균형 로봇 — 재설계 요구사항 스펙 (v1)

> 날짜: 2026-07-08 · 상태: **초안(프레임·줄 시스템 확정 진행 중, 로봇 몸체는 개요 수준)**
> 배경: 기계 컨설팅(박사님) 3원칙 — ① 베어링/엔코더로 φ 직접측정, ② 줄–발 접점도 관통+베어링,
> ③ 배터리·보드를 좌우 대칭으로 몸체 내장 — 을 반영해 몸체·줄·프레임을 다시 설계한다.
> 목표: **모델–실물 갭을 기계적으로 강제**(평면운동·정의된 관성·저마찰 φ축)하고 φ를 직접 측정.
> 이 문서는 §8 형상최적화 결론(30:70, h≈43cm, R 0.4~0.5, 발끝 비움, **저중심 금지**)과 충돌하지 않는다.

---

## 0. 범위 / 전시용 vs 실험용

- **이 문서의 우선 대상 = 슬랙라인 프레임 + 줄 시스템** (먼저 확정). 로봇 몸체는 치수·원칙만 잡고 세부는 후속.
- **실험용(현재 제작 대상)**: 프레임을 높여, 로봇이 균형을 잃고 떨어져도 **바닥에 충돌하지 않고 매달려 흔들리도록** 한다.
- **전시용(추후 별도 제작)**: 전람회 높이 제한이 있으므로 프레임을 낮춘 별도 버전으로 다시 만든다. 본 스펙은 실험용 기준.

## 1. 좌표계·기하 규약 (★내 해석 — §9에서 확인 요망)

```
        Z(위)
        │
        │        ← 스윙 평면 = X–Z (시상면). 로봇은 이 평면에서만 기운다.
        └──── X(스윙 방향, 앞뒤)
       /
      Y(피벗 축 방향, 좌우) : 모든 회전축(2개 상단 피벗 + 하단 발축 + 로봇 발목)이 Y와 평행

프레임(2020) 정면(X–Z):
   ┌───────────────────────────┐  ← 상단은 X 방향으로 '뚫려' 있음(윗 모서리 2개 제거)
   ▲(베어링)          ▲(엔코더)     두 상단 피벗: X로 60cm 이격, 축은 Y평행
    \                /            빗변 카본 50cm (크랭크)
     \              /
      \____________/   ← 하단 바(카본 10cm) = 발축. 여기 로봇 하체끝이 베어링으로 관통
        [로봇 몸체]                로봇: 하체(발축→힙) 25cm + 상체(힙→머리) 40cm
        ↓ (떨어지면 매달려 스윙)
   ═══════════════════ 바닥        프레임 높이 ~120cm로 로봇이 바닥에 안 닿음
```

- **φ (스윙각)**: 상단 피벗 기준 줄(사다리꼴)의 스윙. **상단 엔코더가 직접 측정.**
- **α (하체 절대기울기)**: 로봇 하체끝 **발목 베어링**(자유 피벗, 토크 없음)이 허용. 발은 하단 바와 함께 스윙하되 로봇은 그 위에서 자유롭게 기운다 = 모델의 "점접촉·발목 토크 無".
- **θ (상체 절대기울기)**: 힙 관절(δ=θ−α, XM430 1개)로 구동.

## 2. 슬랙라인 프레임

| 항목 | 값 | 비고 |
|---|---|---|
| 소재 | 알루미늄 프로파일 **2020** | |
| 기본 형상 | 직육면체에서 **윗 모서리 2개 제거**(X방향 상단 레일 2개 제거) | 상단 중앙이 열려 로봇이 X로 스윙 가능 |
| 남은 상단 모서리 | **2개**(Y방향, X=0/X=60에 위치) | 각 중앙에 상단 피벗 장착 |
| 상단 피벗 간격 (=사다리꼴 윗변) | **60 cm** (X 방향) | 두 슬랙 카본이 여기 매달림 |
| 앞뒤 폭 (Y) | **40 cm** | 기능 무관, 형상 안정용 |
| 높이 (Z) | **~120 cm** | 필요치 = 처짐 43.3 + 로봇 65 = **108.3cm**, 여유 ~12cm |
| 상단 피벗 | 한쪽 = **베어링**, 다른 한쪽 = **엔코더**(φ 측정) | 두 축 동축(Y평행), 동일 높이 |

- 두 상단 피벗은 **같은 Y축을 공유하도록 정렬**해야 4절(스윙) 링크가 성립(§8).

## 3. 줄 시스템 (카본 사다리꼴)

| 항목 | 값 | 비고 |
|---|---|---|
| 소재 | **8 mm 카본파이프** | |
| 형상 | **사다리꼴** (윗변 열림) | |
| 빗변(크랭크) | **50 cm × 2** | 카본 원자재 길이 = 50cm |
| 아랫변(발축 바) | **~10 cm** | 로봇 발이 여기 관통 |
| 윗변 | **비어 있음(물리 바 없음)** | 두 상단 피벗이 사실상 윗변 두 꼭짓점 |
| 수직 처짐(sag) | **43.3 cm** (=√(50²−25²)) | = 모델의 처짐 |
| 결합 | **3D 프린트 소켓** | ① 카본↔카본(하단 코너), ② 카본↔베어링/엔코더(상단) |

- **하단 코너**(빗변↔발축 바): 3D 소켓으로 결합. 강체로 붙일지 회전 여부는 §9 확인.
- **발축 바(10cm)**: 로봇 하체끝을 **베어링으로 관통** → 발목 자유 피벗(α).

## 4. 베어링·엔코더 인터페이스

- **상단 φ 측정**: 한쪽 피벗에 **절대 엔코더**(후보: AS5048A 14bit SPI / AMT223 14bit / 광학 MA3 — 미확정).
  φ = ±60° → **단회전 절대**면 충분, 12bit(0.088°)~14bit(0.022°). 엔코더 샤프트 ↔ 빗변 카본을 소켓으로 동축 커플.
- **상단 반대쪽**: 동일 규격 베어링(엔코더와 동축).
- **하단 발목**: 발축 바(카본 10cm)에 **베어링**, 로봇 하체끝이 관통 → α 자유 피벗.
- **결정 필요**: 엔코더 최종 모델, 베어링 내경(8mm 카본/샤프트 정합), 소켓 공차, 케이블 관리(엔코더 배선), 자석 보어(자기식 선택 시).

## 5. 로봇 몸체

| 항목 | 현재 | 재설계 | 형상최적화 목표(§8) |
|---|---|---|---|
| 폭 | ~6 cm | **~10 cm** | (좌우 대칭 강화) |
| 하체 길이(발→힙) | ~20 cm | **~25 cm** | — |
| 상체 길이(힙→머리) | — | **~40 cm** | — |
| 총 길이 | | **65 cm** | 80cm(가능시 100) |
| 하체:상체 | | **25:40 = 38.5:61.5** | 30:70 |
| 상체 내부 | 부착식 | **보드·배터리 매립 포켓** → 직육면체 유지 | 장비 상체 위쪽 |

원칙(컨설팅 + §8 조율):

- **좌우(Y) 대칭**: 보드·배터리를 시상면 중심에 대칭 배치 → yaw/좌우 넘어짐 실패 클래스 제거.
- **몸체 내장**: 상체를 파서 매립, 직육면체 강체 유지 → 정의된 관성·보호.
- **★수직으로는 여전히 상체 고중심 유지**: 대칭·내장을 이유로 **무게중심을 낮추면 안 됨**(§8: 저중심 시 FWE 4~5배 붕괴). "좌우 대칭·내장 + 수직 고중심"은 양립 — 장비를 **상체 안쪽 높은 곳**에 대칭 배치.
- **발끝 비움**: 접점(발축)은 카트일 뿐 질량 금지.
- **IMU**: OpenCR 보드(ICM-20648)를 상체 상단, 힙축에서 위쪽. ELL_IMU(힙→IMU) 확정·실측 필요(칼만 가속보상).

## 7. 모델 자유도와의 대응 (이 설계의 강점)

- **4절 스윙(1DOF)** = φ, 상단 엔코더가 직접 읽음 → 칼만의 φ 복원(가장 취약점) 제거.
- **발목 베어링(자유, 1DOF)** = α, 토크 없음 → 모델의 "점접촉·발목 토크 無" 충실 구현.
- **힙(1DOF, 구동)** = θ(δ=θ−α), XM430 1개 → **저구동 구조 유지**(액추에이터 1개 불변).
- 결과: **3DOF·입력 1개** 모델을 기계가 그대로 강제. 인코더는 관측성만 개선, 가제어성(연구 핵심 기여)은 불변.

## 8. 확인·결정 필요 (Open Questions)

1. **좌표/축 해석**(§1) 맞나? 스윙 평면이 X–Z, 피벗축이 Y평행, 상단 피벗 60cm 이격이 스윙방향(X)인지.
2. **하단 코너 결합**: 빗변↔발축 바를 강체로 붙이나(→ 4절 스윙), 아니면 회전? R·기구학이 달라짐.
3. **엔코더 최종 모델** 확정(AS5048A 14bit 자기식 / AMT223 14bit / 광학 MA3). 로직 전압(OpenCR 3.3V)·마운트 난이도 고려.
4. **베어링/샤프트 규격**: 8mm 카본과 베어링 내경·샤프트 정합, 발축 바 이탈방지(리테이너).
5. **소켓 설계 공차**: 카본 8mm 외경 억지끼움 공차, 상단 엔코더 커플 동축도.
6. **상체 매립 배치**: 보드·배터리 치수 → 포켓 위치(고중심·좌우대칭 동시 만족), 총 질량 예산.
7. **ELL_IMU** 목표값(마운트 높이) 및 배선.
8. **프레임 높이 120cm**로 충분한지(로봇 65 + 처짐 43 + 스윙 시 여유).
