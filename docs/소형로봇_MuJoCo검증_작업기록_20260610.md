## 2. δ_fold 영향 분석 (대형 로봇)

### 2.1 문제 제기
- 접기 후 δ=0이 아니라 δ=δ_fold(≠0)일 때 시스템 동역학이 달라지는가?
- δ_fold가 관성행렬의 커플링항 M₂₃ = J_at·cos(δ_fold)에 영향

### 2.2 결과
- **대형 로봇 (R=0.7, 1.0)**: δ_fold에 의한 eps* 변화가 **<2%** → 무시 가능
- **소형 로봇**: δ_fold에 의한 eps* 편차가 10% 이상 가능하나, 무게중심 변화까지 고려하면 해석적으로 계산이 어려움
- **결론**: 대형 모델 검증 결과는 유효. 소형은 경향성만 파악하고 다음 단계로 넘어가기로 결정

## 3. PD 서보 게인 튜닝

### 3.1 문제
기존 PD 게인(Kp=10000, Kd=200)은 대형 로봇(J_tt=13.6 kg·m²) 기준으로 설정됨.
소형 로봇(J_tt≈0.005~0.05 kg·m²)에 그대로 적용하면 **발산** 또는 **기생 안정화** 발생.

### 3.2 게인 설계 공식
관성 비례 스케일링:
```
Kp = J_tt × ωn²
Kd = 2 × ζ × ωn × J_tt
```

### 3.3 튜닝 결과 (50cm 로봇, L=25cm, R=0.5m)

| 설정 | Kp | Kd | max\|δ\| | 상태 |
|------|----|----|---------|------|
| 원본 Kp=10000 | 10000 | 200 | 40.5° | ❌ 완전 분리 |
| ωn=27, ζ=0.27 | 5.9 | 0.12 | 8.5° | △ |
| ωn=50, ζ=0.5 | 20 | 0.40 | 2.8° | ○ |
| **ωn=100, ζ=0.7** | **80** | **1.12** | **0.80°** | ✅ |
| **ωn=200, ζ=0.7** | **321** | **2.25** | **0.25°** | ✅ 최적 |
| ωn=500, ζ=0.7 | 2005 | 5.61 | 12.5° | ❌ 고주파 진동 |

**최적 선택: ωn=200, ζ=0.7** → δ 유지 0.25° 수준

## 4. ★ 핵심 버그 발견 및 수정: MJCF Body Tree 구조

### 4.1 증상
히트맵이 파란색(음의 x_CoM)으로만 진행 → 빨간색 쪽으로 오거나 흰색으로 오지 않음
→ 초기조건이 복원을 만드는 방향으로 작동하지 않음

### 4.2 원인
**소형 모델의 MJCF body tree 구조가 대형 모델과 근본적으로 달랐음:**

#### 대형 모델 (batch_experiment.py) — 정상
```
rope_a_mount (pole_a 위치)
  ├─ phi_Y joint        ← phi가 로프 마운트에 있음 (진짜 진자)
  ├─ rope_a_X joint
  ├─ rope_a geom
  └─ lower_body (로프 끝에 위치)  ← 몸체가 로프의 자식
      ├─ ankle joint
      └─ upper_body
          └─ hip joint
rope_b_mount (pole_b 위치)
  ├─ rope_b_Y joint
  └─ rope_b_end
equality: rope_b_end → ankle_b_target (하나만)
solref="0.001 1" solimp="0.999 0.999 0.0001"
option: iterations="200" tolerance="1e-10", contact="disable"
armature="0.001"
```

#### 소형 모델 (수정 전) — 잘못됨
```
rope_a (pole_a 위치)
  └─ rope_a_Y joint
rope_b (pole_b 위치)
  └─ rope_b_Y joint
foot (POLE_H - rv 위치)    ← 별도 body!
  ├─ phi_Y joint            ← phi가 foot에 있음 (제자리 회전!)
  └─ lower
      ├─ ankle joint
      └─ upper
equality: rope_a → foot, rope_b → foot (두 개)
solref="-10000 -200" (직접 강성, 질량 비적응)
armature="0", 접촉 활성화
```

### 4.3 핵심 차이점

| 항목 | 대형 (정상) | 소형 (수정 전) |
|------|-----------|-------------|
| phi_Y 위치 | rope_a_mount (진자) | foot body (제자리 회전) |
| 몸체 연결 | 로프 끝에 자식 | equality constraint |
| constraint 수 | 1개 (rope_b 동기화) | 2개 (양쪽 로프→foot) |
| solref | "0.001 1" (시간기반, 질량적응) | "-10000 -200" (고정강성) |
| armature | 0.001 | 0 |
| solver | iterations=200, tol=1e-10 | 기본값 |
| contact | disable | 활성화 |

### 4.4 수정 내용
`v14_mujoco/small_robot_scan_v2.py`의 `generate_mjcf_param` 함수를 대형 모델과 **완전히 동일한 구조**로 재작성:
- phi_Y를 rope_a_mount에 배치
- 몸체를 로프 끝의 자식으로 연결
- equality constraint 1개 (rope_b 동기화)
- solref="0.001 1", solimp="0.999 0.999 0.0001"
- armature=0.001, iterations=200, tolerance=1e-10, contact=disable

### 4.5 수정 전후 phi 거동 비교

```
수정 전 (잘못된 구조):
  t=0.000: phi=-4.018°
  t=0.010: phi=-2.519°  ← 10ms 만에 1.5° 이동! (constraint 복원)
  t=0.040: phi=-0.301°  ← phi가 0으로 돌아감

수정 후 (대형과 동일):
  t=0.000: phi=-4.018°
  t=0.010: phi=-4.572°  ← 정상적 진자 운동
  t=0.040: phi=-3.765°  ← 천천히 변화
```

### 5.2 결과 요약

### 5.3 히트맵 패턴 (대형과 동일하게 확인됨)
- **eps* 위 (과접기)**: 파란색 → 음의 x_CoM으로 발산
- **eps* 아래 (부족접기)**: 빨간색 → 양의 x_CoM으로 발산
- **eps* 근처**: 흰색 띠 → 가장 오래 생존
- 로봇이 클수록 안정 띠가 넓고 오래 생존

## 6. 물리적 결론

### 6.1 eps* 이론 검증
- **대형/소형 모두에서 eps* 이론이 MuJoCo로 확인됨**
- eps*에서 불안정 모드 계수 c₂=0 → 생존 시간 최대화

### 6.2 소형 로봇의 한계
- λ(불안정 발산률)가 대형 대비 2~3배 큼 (λ≈5~9 vs 대형 3.5~4)
- 단일 FWE로 2초 생존 불가 → **반복 FWE 사이클이 필수**

### 6.3 δ_fold 영향
- 대형: 무시 가능 (<2%)
- 소형: 잠재적으로 10%+ 영향 가능하나, 해석적 계산 어려움
- 무게중심 하강 + R에 따른 방향 반전 등 복잡한 효과

## 9. 핵심 교훈

> **이전에 잘 작동하고 검증된 코드는 새로 짜지 말고 그대로 가져다 써야 한다.**
> 소형 로봇용 MJCF를 "파라미터만 바꾸면 되겠지"라며 새로 작성한 것이 근본 원인이었다.
> 대형 모델의 `batch_experiment.py`의 `generate_mjcf`를 그대로 복사해서 파라미터만 인자로 빼냈으면
> body tree 구조 차이, solref 차이, option 차이 등이 애초에 발생하지 않았다.
> **검증된 코드를 복제 → 파라미터화**하는 것이 정답이다.
