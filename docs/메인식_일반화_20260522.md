## 1. 동기: 1차 사이클과 2차 사이클의 차이

### 1.1 문제 발견

v15_fwe 시뮬레이터에서 프레임별 스텝 관찰 결과:

- **1차 사이클**: 깔끔하게 접고 펴짐. 균형 보정 효과 확인.
- **2차 사이클**: 접기 방향은 맞았으나, **너무 많이 접고 너무 오래 기다림** → 과보정 후 반대쪽 발산.

### 1.2 근본 원인

메인 식 `(1+ε)·cos(ωT) = ε·cosh(λT)`의 유도 전제:

```
Phase 0 가정:  φ = 0,  φ̇ = 0,  β̇ = 0  (발이 중앙에 정지)
```

이 가정은 **1차 사이클에서만 성립**. 2차 이후:

```
실제 Phase 0:  φ ≠ 0,  φ̇ ≠ 0,  β̇ ≠ 0  (발이 움직이고, 몸도 기울어지는 중)
```

## 2. FWE 메커니즘의 정확한 이해

### 2.1 접기의 역할 (5/22 논의에서 명확화)

접기(FOLD)는 단순히 CoM을 이동시키는 것이 아니다:

```
접기 → CoM이 한쪽으로 이동
     → 하지만 발이 CoM보다 더 많이 이동 (c_foot = p₂/pₛ 비율)
     → 결과: beta_rel이 반전! (CoM이 발 반대편에 위치)
     → 반전된 beta_rel의 중력 토크가 x_com을 복원 방향으로 가속
```

**핵심**: 접기는 **복원 가속도를 생성**하는 행위.

### 2.2 기다리기(WAIT1)의 역할

```
접기 전: beta_rel > 0  →  ẍ_com > 0  (발산 가속)
접기 후: beta_rel < 0  →  ẍ_com < 0  (복원 가속)  ← 이 상태에서 기다림

WAIT1 동안: 복원 가속도에 의해 몸체 각도(α, θ)가 수직 방향으로 복원
```

### 2.3 발 스윙은 부수효과

발(φ)의 진자 운동은 FWE 보정의 **의도된 수단이 아니라 교란 요소**:

```
의도: beta_rel에 의한 중력 토크 → α, θ 복원  (몸의 역학)
교란: 발의 독립적 진자 운동 → phi 변화 → x_com에 간섭  (줄의 역학)
```

## 3. 제어 신호 분석: beta vs x_com vs beta_rel

### 3.1 세 변수의 정의

| 변수 | 정의 | 물리적 의미 |
|------|------|-------------|
| beta_rel | (p₁α + p₂θ) / (Mₜ·h) | 발 기준 CoM 상대 기울기 |
| x_com | R·sin(φ) + (p₁·sin(α) + p₂·sin(θ))/Mₜ | CoM의 절대 수평 위치 |
| beta | x_com / h | CoM의 중앙 기준 편차 (각도 환산) |

관계: `x_com = R·sin(φ) + h·beta_rel`

### 3.2 각 변수를 제어 신호로 사용할 때의 문제

**beta_rel만 사용 (구 로직)**:
- 발이 중앙에 있을 때는 OK (x_com ≈ h·beta_rel)
- 발이 이동해 있으면: x_com의 phi 기여를 무시 → 방향 오류 가능
- 예: phi >> 0이면 x_com > 0인데 beta_rel < 0일 수 있음 → 잘못된 방향으로 접기

**x_com만 사용**:
- 방향은 항상 정확
- 하지만 접기량이 과대: 발의 자연 복귀분까지 보정하려 함
- 발이 이미 중앙으로 돌아오는 중인데도 "x_com이 크다"며 접기

**x_com + beta_rel 이중 신호 (5/22 도입)**:
- 트리거/방향: x_com (글로벌 목표)
- 접기량: beta_rel (로컬 역학)
- 접기 조건: sign(x_com) == sign(beta_rel) 일 때만
  - 부호 같음: 발이 아직 CoM을 못 따라감 → 접기 필요
  - 부호 다름: 발이 이미 CoM을 지남 → 자연 복귀에 맡김
- **문제**: 발의 속도를 고려하지 않아 여전히 접기량 과대/과소

## 4. 메인 식의 일반화

### 4.1 원래 메인 식 (정지 초기 조건)

```
Phase 0:  φ_i = 0,  φ̇_i = 0,  β_i = β₀,  β̇_i = 0

접기 후:  φ(0⁺) = h·β₀·(1+ε)/R,  β(0⁺) = −ε·β₀

Phase 2:  φ(t) = [h·β₀·(1+ε)/R]·cos(ωt)
          β(t) = −ε·β₀·cosh(λt)

복원 조건 x_CoM(T) = 0:
  (1+ε)·cos(ωT) = ε·cosh(λT)    ← 메인 식
```

### 4.2 일반화 메인 식 (비정지 초기 조건)

```
Phase 0:  φ_i ≠ 0,  φ̇_i ≠ 0,  β_i = β₀,  β̇_i ≠ 0

접기 후:  φ_after = φ_i + h·β₀·(1+ε)/R
          β_after = −ε·β₀
          φ̇_after = φ̇_i         (순간 접기이므로 속도 불변)
          β̇_after = β̇_i         (순간 접기이므로 속도 불변)

Phase 2:  φ(t) = φ_after·cos(ωt) + (φ̇_i/ω)·sin(ωt)
          β(t) = β_after·cosh(λt) + (β̇_i/λ)·sinh(λt)
                                     ^^^^^^^^^^^^^^^^
                                     새로 추가된 항!
```

### 4.3 일반화 메인 식의 유도

복원 조건 `x_CoM(T) = R·φ(T) + h·β(T) = 0`에 대입:

```
R·[φ_after·cos(ωT) + (φ̇_i/ω)·sin(ωT)]
  + h·[(-ε·β₀)·cosh(λT) + (β̇_i/λ)·sinh(λT)] = 0
```

φ_after = φ_i + h·β₀·(1+ε)/R 를 전개:

```
R·φ_i·cos(ωT) + h·β₀·(1+ε)·cos(ωT) + R·(φ̇_i/ω)·sin(ωT)
  − h·ε·β₀·cosh(λT) + h·(β̇_i/λ)·sinh(λT) = 0
```

양변을 `h·β₀`으로 나누면 (β₀ ≠ 0):

```
[R·φ_i/(h·β₀)]·cos(ωT) + (1+ε)·cos(ωT) + [R·φ̇_i/(h·β₀·ω)]·sin(ωT)
  = ε·cosh(λT) − [β̇_i/(β₀·λ)]·sinh(λT)
```

### 4.4 일반화 메인 식: 단일 공식

무차원 변수 정의:

| 변수 | 정의 | 물리적 의미 |
|------|------|-------------|
| ψ | R·φ_i / (h·β₀) | 접기 시점의 발 위치 (β₀ 대비 무차원) |
| v_φ | R·φ̇_i / (h·β₀·ω) | 접기 시점의 발 속도 (진자 고유속도로 무차원화) |
| v_β | β̇_i / (β₀·λ) | 접기 시점의 몸 각속도 (낙하율로 무차원화) |

> ### **일반화 메인 식**
>
> **(1+ε+ψ)·cos(ωT) + v_φ·sin(ωT) = ε·cosh(λT) − v_β·sinh(λT)**

#### 특수해 환원 검증

| 조건 | ψ | v_φ | v_β | 결과 |
|------|---|-----|-----|------|
| 정지 출발 (1차 사이클) | 0 | 0 | 0 | **(1+ε)·cos(ωT) = ε·cosh(λT)** ← 원래 메인 식 ✅ |

### 4.5 식의 물리적 해석

**좌변: 정진자(발)의 운동** — 중앙으로 복원하는 힘

```
(1+ε+ψ)·cos(ωT)  :  접기 후 발 위치에서 시작하는 진동 (진폭에 ψ 보정)
 + v_φ·sin(ωT)   :  기존 발 속도에 의한 위상 이동 (sin 성분 추가)

→ 합성하면: A·cos(ωT + Φ)  (진폭 A와 위상 Φ가 초기 조건으로 결정)
  여기서 A = √((1+ε+ψ)² + v_φ²),  tan(Φ) = v_φ/(1+ε+ψ)
```

**우변: 역진자(몸)의 낙하** — 쓰러지는 속도

```
ε·cosh(λT)       :  오버슈트에 의한 역방향 자유낙하 (원래 메커니즘)
 − v_β·sinh(λT)  :  기존 몸 각속도의 기여
                     β̇_i가 복원 방향이면(v_β > 0): 낙하 감소 → ε 줄여도 됨
                     β̇_i가 발산 방향이면(v_β < 0): 낙하 증가 → ε 늘려야 함
```

**등호: 발의 복원과 몸의 낙하가 정확히 상쇄** → x_CoM(T) = 0 → 한 사이클 완전 복원.

### 4.6 ε 결정 공식

일반화 메인 식을 ε에 대해 풀면:

```
ε = [(1+ψ)·cos(ωT) + v_φ·sin(ωT)] / [cosh(λT) − cos(ωT) − v_β·sinh(λT)/ε]
```

이는 ε에 대한 음함수이므로, v_β ≈ 0 근사에서:

> **ε ≈ [(1+ψ)·cos(ωT) + v_φ·sin(ωT)] / [cosh(λT) − cos(ωT)]**

정지 출발 (ψ=0, v_φ=0): `ε = cos(ωT) / (cosh(λT) − cos(ωT))` ← 원래 식과 일치 ✅

### 4.7 소각/소시간 근사

T ≈ 0.17 × T_quarter ≈ 130ms 이므로:

```
cos(ωT) ≈ 1,   sin(ωT) ≈ ωT
cosh(λT) ≈ 1,  sinh(λT) ≈ λT
```

이 근사에서 x_CoM(T) = 0 조건은:

```
x_CoM(T) ≈ [R·φ_after + h·β_after] + [R·φ̇_i + h·β̇_i]·T
          = x_com(0⁺) + ẋ_com · T
```

여기서 **ẋ_com = R·φ̇ + h·β̇_rel** 은 x_com의 시간 미분.

**실용적 의미**: 접기량은 현재 x_com이 아니라 **T 후 예측 x_com**에 비례해야 한다.

```
d_fold ∝ |x_com + ẋ_com · T_w1| / h
          ─────────────────────────
          "T_w1 후의 예측 x_com 위치"
```

### 4.8 c_pred와의 관계

이전에 도입한 적응적 예측 계수 `c_pred`:

```
beta_eff = beta / (1 − c_pred · β̇ · sign(β))
```

이것은 사실상 `x_com + ẋ_com·T`의 **1차 테일러 전개와 동치**:

```
c_pred ≈ T / h   (대기 시간을 높이로 나눈 값)
```

다만 c_pred는 beta_rel에만 적용했지, φ̇ 기여는 빠져있었음.
**ẋ_com 전체에 대한 예측**이 올바른 일반화.

## 5. 가정과 한계

### 5.1 이 식의 전제 조건 (원래 메인 식과 동일)

1. **H1**: 순간 접기에서 CoM 불변 (순간 접기이면 자동 성립, §12.2)
2. **H3**: 접기가 줄(φ)을 교란하지 않음 (분리 가정)
3. **순간 접기/펴기**: 접고 펴는 행위는 dt=0에서 일어남
4. **소각 근사**: sin β ≈ β, cos β ≈ 1

### 5.2 일반화의 타당성 근거

정지 초기 조건(ψ=v_φ=v_β=0)의 메인 식이 **1차 사이클에서 정성적으로 유효함**이
시뮬레이션으로 확인되었다 (5/13 MuJoCo 검증, T_cross 방향·R 의존성 일치).

일반화 식은 동일한 물리적 가정 하에서 초기 조건만 확장한 것이므로,
**2차 이후 사이클에서도 동일한 수준의 정성적 유효성**이 기대된다.

| | 메인 식 (ψ=v_φ=v_β=0) | 일반화 메인 식 |
|---|---|---|
| **적용 대상** | 1차 사이클 (정지 출발) | 2차+ 사이클 (이동 중 출발) |
| **정성적 유효성** | MuJoCo에서 확인 ✅ | 동일 가정 → 기대 ✅ (검증 필요) |
| **정량적 정확도** | T를 3~4배 과대예측 | 유사한 수준으로 예상 |
| **β₀ 소거** | 소거됨 (진폭 독립) | **소거됨** (ψ, v_φ, v_β ∝ 1/β₀ 아님) |

### 5.3 β₀ 소거에 대한 주의

일반화 식에서 ψ = R·φ_i/(h·β₀), v_φ = R·φ̇_i/(h·β₀·ω), v_β = β̇_i/(β₀·λ).

이들은 β₀를 **포함**하지만, φ_i, φ̇_i, β̇_i는 β₀와 독립적인 상태 변수이므로
**β₀ 비례 접기(δ ∝ β₀)를 해도 ψ, v_φ, v_β는 소거되지 않는다.**

이것은 2차 이후 사이클에서는 **단순 비례 제어(δ ∝ β)만으로는 불충분**하며,
발과 몸의 현재 상태(φ, φ̇, β̇)를 명시적으로 고려해야 함을 의미한다.

## 6. 정리: 오늘의 인사이트

### 6.1 핵심 결론

> **메인 식 (1+ε)·cos(ωT) = ε·cosh(λT) 는 정지 출발의 특수해이다.**
>
> 일반해는:
>
> **(1+ε+ψ)·cos(ωT) + v_φ·sin(ωT) = ε·cosh(λT) − v_β·sinh(λT)**
>
> 여기서 ψ, v_φ, v_β는 접기 시점의 발 위치·속도와 몸 각속도를 나타내는 무차원량이다.

### 6.2 제어 설계에의 함의

1. **접기량(ε)**은 발과 몸의 현재 운동 상태에 따라 적응적으로 조절되어야 한다.
2. **소시간 근사**에서, 이는 **"T 후 예측 x_com"에 비례하는 접기**로 단순화된다.
3. 이전의 c_pred 적응적 예측은 이 일반화의 **불완전한 근사** (φ̇ 기여 누락).

### 6.3 검증 전략: 두 가지 접근

#### 방법 1: FWE 직접 구현 — "이 메커니즘으로 균형이 잡히는가?"

```
목표: 일반화 식 기반 FWE 제어기가 실제로 수렴하는 시뮬레이션 시연
방법: v15_fwe 시뮬레이터에서 x_com_pred 기반 접기량 + 이중 신호 제어 구현
성공 기준: 수 사이클 후 x_com 진폭 감소 (|r| < 1)
의미: 이 메커니즘이 물리적으로 유효함을 직접 보여줌
```

#### 방법 2: LQR 대응 — "LQR의 접기량 보정이 이 식과 맞는가?"

**1차 사이클 (이미 확인)**:

```
이전 결과 (5/12): β₀ 커지면 δ_peak(접기량)도 커짐 → ε ∝ β₀ 비례 관계 확인
원래 식: ε = cos(ωT)/(cosh(λT)−cos(ωT)) → β₀에 무관한 상수
→ 정성적 일치 확인됨 (5/12 §12.3, RMSE=0.116)
```

**2차 사이클 (새로운 검증)** — 일반화 식의 핵심 테스트:

```
프로토콜:
1. MuJoCo에서 다양한 β₀로 LQR 시뮬레이션 실행
2. 각 사이클 시작 시점의 상태 기록: (φ_i, φ̇_i, β₀, β̇_i)
3. ψ, v_φ, v_β 계산
4. 해당 사이클의 LQR δ_peak 측정 → ε_measured 추출
5. 일반화 식으로 ε_predicted 계산

비교:
  ε_predicted = [(1+ψ)·cos(ωT) + v_φ·sin(ωT)] / [cosh(λT) − cos(ωT)]
  ε_measured  = δ_peak · c_foot / (h·β₀)  (LQR에서 직접 측정)
```

**테스트할 예측**:

| # | 예측 내용 | 확인 방법 |
|---|----------|----------|
| 1 | ε₂ ≠ ε₁ (2차 접기량이 1차와 다름) | LQR의 1차/2차 δ_peak 비교 |
| 2 | Δε = ε₂ − ε₁ 의 부호가 ψ, v_φ 보정항과 일치 | 부호 비교 |
| 3 | Δε의 크기가 ψ·cos(ωT) + v_φ·sin(ωT) 보정과 정량적 일치 | 수치 비교 |

**핵심**: 원래 식으로는 "왜 2차 접기량이 1차와 다른가"를 설명할 수 없다.
일반화 식은 ψ(발 위치)와 v_φ(발 속도)에 의한 보정으로 이 차이를 **정량적으로 예측**한다.
이 예측이 LQR과 일치하면, 일반화 식의 타당성이 검증된다.

| | 방법 1 (직접 시연) | 방법 2 (LQR 대응) |
|---|---|---|
| **증명 대상** | 메커니즘의 물리적 유효성 | 메커니즘과 LQR의 동치성 |
