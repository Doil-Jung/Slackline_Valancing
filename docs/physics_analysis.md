# 슬랙라인 균형 시뮬레이터 — 물리 모델 분석

## 1. 물리 상황 정리 (줄타기 서핑)

사람이 느슨한 줄(슬랙라인) 위에 올라서면, 줄이 **V자 형태**로 팽팽해집니다.
이때 발이 닿는 V자의 꼭짓점이 좌우로 흔들릴 때, **줄의 전체 길이가 일정**하다는 구속조건 때문에 꼭짓점은 **원호(circular arc)** 궤적을 그립니다.

```
       ─── 앵커 ─────────── 앵커 ───
        \                       /
         \                     /      줄 길이 = 일정
          \                   /       → 꼭짓점은 원호 위 이동
           \     발(꼭짓점)  /
            \       ●       /
             \     /|\     /
              \   / | \   /
               \ /  |  \ /
                V   |   V
                    R (원호 반경 = 처짐 깊이)
```

> **핵심**: 이 문제는 본질적으로 **"원호 위를 달리는 카트에 역진자가 올라간 문제"**와 동일합니다.
> 일반적인 cart-pendulum 문제에서 카트가 직선 위를 움직이는 반면, 여기서는 **원호 위**를 움직입니다.

## 2. 현재 V3 모델의 문제점

### 현재 구현 (2-DOF: φ, θ)
현재 코드의 주석을 보면:

> *"하체(다리): 원호 법선에 고정, 각도 = **-φ** (발목 관절 없음)"*

즉, **하체 각도가 항상 원호의 법선 방향(-φ)으로 잠겨** 있습니다.

```
        현재 모델                      실제 물리 상황
                                      
    θ ↗ (상체 자유)              θ ↗ (상체 자유)
   ──●── 힙                    ──●── 힙
     |                           /
     | 하체 = -φ (고정!)        / α (하체 자유!)
     |                         /
     ● 발 (원호 위)            ● 발 (원호 위)
   ~~∪~~~~ 줄               ~~∪~~~~ 줄
```

### 왜 이것이 물리적으로 부정확한가

1. **발-줄 접촉은 힌지(hinge)**: 발이 줄 위에 놓여 있을 때, 발목에는 따로 토크를 주지 않습니다 (발과 줄 사이에 능동적 토크 없음). 이는 **발 위치에서 자유 회전**(frictionless pivot)이 가능하다는 것을 의미합니다.
2. **하체 각도는 독립적 자유도**: 발이 원호에 구속되어 위치(φ)가 정해지더라도, 하체가 어떤 각도로 서 있는지(α)는 **힙 토크, 중력, 원호 가속도의 상호작용**에 의해 동역학적으로 결정되어야 합니다.
3. **현재 모델의 결과**: 하체를 -φ에 고정하면, 하체가 항상 "원호 중심을 향해" 서게 되어, **실제로는 가능한 넘어짐 모드를 인위적으로 억제**합니다. 이는 사실상 발목에 무한한 토크를 가하는 것과 같습니다.

## 3. 올바른 모델: 3-DOF (φ, α, θ)

Paoletti & Mahadevan (2012) 논문의 모델을 2-body로 확장하면:

### 일반화 좌표

| 좌표 | 의미 | 설명 |
|------|------|------|
| **φ** | 발의 원호 위치 | 원호 최저점에서 발까지의 각도 |
| **α** | 하체(다리) 각도 | 수직선에서 하체가 기울어진 각도 |
| **θ** | 상체(몸통) 각도 | 수직선에서 상체가 기울어진 각도 |

### 기하학적 관계

```
좌표계: 원호 중심이 원점, x = 수평(오른쪽 양), y = 위쪽 양
원호 중심 = (0, R)  (줄 최저점 위로 R만큼)
```

- **발 위치** (원호 구속):
  `x_foot = R·sin(φ)`,  `y_foot = R·(1 − cos(φ))`

- **힙 위치** (발에서 하체 길이 L₁만큼 α 방향):
  `x_hip = x_foot + L₁·sin(α)`,  `y_hip = y_foot + L₁·cos(α)`

- **머리 위치** (힙에서 상체 길이 L₂만큼 θ 방향):
  `x_head = x_hip + L₂·sin(θ)`,  `y_head = y_hip + L₂·cos(θ)`

### 구속 조건 & 힘

| 항목 | 설명 |
|------|------|
| 구속 | 발은 원호 위에서만 미끄러짐 (x²+(y−R)² = R²) |
| 발목 토크 | **없음** (발-줄 접촉이 자유 힌지) |
| 힙 토크 τ | **유일한 제어 입력** (상체-하체 상대각에 작용) |
| 무릎 관절 | 현재 없음 (추후 필요시 추가) |

### EOM 유도 방법 (라그랑주 역학)

1. 각 질량체(하체 m₁, 상체 m₂)의 CoM 위치를 (φ, α, θ)로 표현
2. 운동에너지 T와 위치에너지 V 계산
3. 라그랑지안 L = T − V
4. 오일러-라그랑주 방정식 → 3×3 질량행렬 M(q)·q̈ + C(q,q̇) + G(q) = Q(τ)

EOM은 다음과 같은 형태:

```
[M₁₁  M₁₂  M₁₃] [φ̈ ]   [f₁(q, q̇, τ)]
[M₂₁  M₂₂  M₂₃] [α̈ ] = [f₂(q, q̇, τ)]
[M₃₁  M₃₂  M₃₃] [θ̈ ]   [f₃(q, q̇, τ)]
```

여기서:
- **τ는 힙 토크**: α̈ 방정식에 −τ로, θ̈ 방정식에 +τ로 나타남 (반작용)
- **φ̈ 에는 직접적 토크 없음**: 원호 운동은 오직 중력과 관성력의 반작용으로 결정

### 제어 목표

현재 구현에서는 **상체 각도 θ → 0**만을 목표로 PID를 적용했지만, 실제로는:

> **전체 CoM의 x좌표가 발(접촉점)의 x좌표 근처에 유지**되는 것이 진정한 균형 목표

이는 `x_com ≈ x_foot` 조건, 즉:

```
(m₁·x_com1 + m₂·x_com2) / (m₁ + m₂) ≈ R·sin(φ)
```

이 조건이 만족되어야 무게중심이 지지점 위에 있게 됩니다.

## 4. Paoletti(2012) 모델과의 비교

| 항목 | Paoletti(2012) | 현재 V3 | 올바른 V3 |
|------|----------------|---------|-----------|
| 사람 모델 | 1체 역진자 | 2체 (상+하) | 2체 (상+하) |
| 자유도 | 2 (φ, θ) | 2 (φ, θ) | **3 (φ, α, θ)** |
| 카트(발) | 원호 위 미끌림 | 원호 위 미끌림 | 원호 위 미끌림 |
| 하체 각도 | (1체이므로 해당 없음) | -φ에 고정 ❌ | α 자유도 ✅ |
| 제어 입력 | 발목 토크 | 힙 토크 | 힙 토크 |
| 제어 목표 | θ → 0 | θ → 0 | **CoM ≈ 지지점** |

> **V1**: Paoletti 논문과 동일한 1-체 모델이지만, 발목 토크를 사용 → 물리적으로 비현실적
>
> **V3 현재**: 2-체로 확장하고 힙 토크를 사용한 것은 올바르지만, **하체를 법선에 고정**시킨 것과 **제어 목표**가 부정확

## 5. 힙 토크만으로 균형 가능한가?

이것이 사용자의 핵심 질문입니다.

> **직관적 분석**: 힙 토크 τ는 상체-하체 **상대각**(θ−α)에 작용합니다. 상체를 한 방향으로 밀면 반작용으로 하체가 반대로 밀리고, 이것이 원호 위에서 발 위치를 이동시킵니다. 이 **"서핑"** 효과가 균형의 핵심입니다.

- **가능성**: 힙 토크 → 상체/하체 상대각 변경 → 하체 반작용으로 발 위치(φ) 이동 → CoM 위치 조절. 이 간접적 경로를 통해 이론적으로 균형 유지가 가능합니다.
- **어려움**: 3-DOF에 1개 입력(under-actuated), 비선형 시스템이므로 **단순 PID로는 불충분**할 수 있습니다. LQR이나 비선형 제어가 필요할 수 있습니다.
- **무릎이 필요할 수 있는 경우**: 큰 교란에서 회복할 때, 추가 자유도(무릎)와 추가 토크가 도움이 될 수 있습니다.
