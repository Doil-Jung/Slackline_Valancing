## 1. 출발점: 3중 진자의 발견

### 관찰

v14 시뮬레이션에서 제어기(LQR)를 끄고 로봇을 매달아 두면, 시스템은 **3중 진자(Triple Pendulum)**로 작동한다.

```
기둥 꼭대기 (고정점)
  └─ [φ] 로프 — 1번째 진자 (정진자, 안정 평형)
       └─ [α] 하체 — 2번째 진자 (역진자, 불안정)
            └─ [θ] 상체+머리 — 3번째 진자 (역진자, 불안정)
```

| 부분 | 진자 종류 | 평형점 |
|------|----------|--------|
| 줄 (φ) | **정(正)진자** — 매달려 있음 | 아래가 안정 |
| 하체 (α) | **역(逆)진자** — 줄 위에 서 있음 | 위가 불안정 |
| 상체 (θ) | **역(逆)진자** — 하체 위에 서 있음 | 위가 불안정 |

3중 진자는 카오스 거동으로 유명한 시스템이다. 초기 조건의 미세한 차이에도 궤적이 완전히 달라진다.

### 놀라운 사실

이 시스템에서 **액추에이터는 허리 관절(hip motor) 단 1개**뿐이다.
1개의 모터로 3자유도 카오틱 시스템을 안정화시킨다 — 이것은 제어공학적으로 매우 도전적인 문제이다.

### 문제 의식

이 결과는 제어공학자에게는 인상적이지만, **물리학자나 물리 교사들에게는 임팩트가 약하다.** "가제어성 행렬(Controllability Matrix)의 랭크가 full이다"라는 설명은 물리적 통찰이 아니라 수학적 계산이기 때문이다.

**핵심 질문**: 행렬 계산이 아닌, **물리적 추론**으로 "왜 1개 모터로 3자유도를 제어할 수 있는가"를 설명할 수 있는가?

## 3. 핵심 발견: 토크가 줄에 닿지 않는다

v14의 운동방정식을 분석하면 결정적인 사실이 드러난다.

토크 입력 벡터:
```
E = [0, -1, +1]
     φ    α    θ
```

**허리 토크 τ는 α(하체)와 θ(상체)에만 직접 작용하고, φ(줄의 흔들림)에는 직접 작용하지 않는다.**

그런데 실제로 줄(φ)까지 제어가 된다. 이것은 τ가 φ에 영향을 미치는 **간접 경로**가 존재한다는 뜻이다. 이 간접 경로의 정체를 밝히는 것이 가설 설정의 핵심 과제가 된다.

## 4. 역학적 메커니즘의 추론

### 4.1 허리 토크의 진짜 효과

물리적 추론의 핵심 통찰:

> **"허리 토크의 직접적 효과는 '몸을 접는 것'이지만, 물리적으로 의미 있는 효과는 '발을 옮기는 것'이다."**

줄의 질량이 매우 작고 평형점 근처의 상황을 고려하면, 상체와 하체는 거의 무중력 공간에 떠 있는 것처럼 작동한다. 허리 토크(내력)로 몸을 접으면:
- 상체와 하체가 서로 반대 방향으로 회전
- 적절한 조건에서 전체 무게중심(CoM)은 거의 변하지 않음
- 대신 **발의 위치가 이동**함

### 4.2 제어 메커니즘: 접기 → 기다리기 → 펴기

외란에 의해 몸이 기울어졌을 때, 균형 복원은 **세 단계**로 일어난다:

```
t=0:  외란 → 몸이 오른쪽으로 기울어짐
      
t=0⁺: [접기] 기울기에 비례하여 몸을 접음
      → 발이 CoM 아래로 이동 (H1: CoM은 안 움직임)
      → 줄은 발과 함께 변위됨 (φ > 0)

t ~ T/4: [기다리기] 중력이 알아서 일한다
      → 복원 1: 발이 CoM 아래에 있으니 중력이 몸을 세움
      → 복원 2: 줄은 정진자이므로 중앙을 향해 복귀 중

t = T/4: [펴기] 줄이 중앙을 지나는 순간 몸을 편다
      → 몸: 기울기 회복됨 ✓
      → 줄: φ ≈ 0 통과 중 → 발이 중앙으로 복귀 ✓
      → 한 사이클 완료!
```

### 4.3 핵심 타이밍: 왜 T/4인가?

정진자의 운동: φ(t) = φ₀ cos(ωt)

- t = 0: φ = φ₀ (최대 변위, 접은 직후)
- t = T/4: φ = 0 (중앙 통과)
- t = T/2: φ = -φ₀ (반대쪽 최대)

**T/4에서 펴야 하는 이유**: 줄이 정확히 중앙을 지나는 순간에 발을 중앙으로 돌려놓아야 진동이 감쇠된다. 이보다 빠르면 잔류 진동, 느리면 진폭 증가.

### 4.4 진폭 독립성 — 왜 이 메커니즘이 강건한가

정진자의 주기는 진폭에 무관하다 (등시성). 한편 몸의 복원 시간은:

기울기 β에 비례하여 접으면 (δ = k·β):
- 발 이동량: Δx = c·k·β (β에 비례)
- 복원 토크: τ = M·g·Δx = M·g·c·k·β (β에 비례)
- 운동 방정식: I·β̈ = −M·g·c·k·β → **단순조화진동!**
- 복원 시간: τ_body = (π/2)·√(I/(Mgck)) → **진폭 무관!**

| 기울기 | 접힘량 | 발 이동 | 복원 토크 | **복원 시간** |
|--------|--------|---------|----------|:-----------:|
| β = 0.05 | 작음 | 작음 | 작음 | τ_body |
| β = 0.30 | 큼 | 큼 | 큼 | τ_body |

**두 개의 진폭-무관 주기가 존재**:
1. 정진자: T_rope = 2π√((R+h)/g) — 진폭 무관
2. 몸 복원: T_body = 2π√(I/(Mgck)) — 진폭 무관 (비례 제어 시)

**한 번 매칭시키면 모든 크기의 외란에 대해 작동한다.**

### 4.5 역(逆)그네 원리와의 연결

5년 전 연구했던 "앉아서 그네타는 로봇"과의 연결:

| 그네 (이전 연구) | 슬랙라인 (현재) |
|----------------|---------------|
| 바닥에서 몸 펴기 → 에너지 주입 | 바닥에서 **몸 접기** → 에너지 추출 |
| 꼭대기에서 몸 접기 → 에너지 주입 | 꼭대기에서 **몸 펴기** → 에너지 추출 |
| 진폭 증가 (펌핑) | 진폭 감소 (**안티펌핑**) |

같은 모터가 같은 동작(접기/펴기)으로 몸 복원과 줄 감쇠를 모두 수행한다.

### 4.6 변수 분리법과의 방법론적 유사성

이 접근은 미분방정식의 **변수 분리법**과 구조적으로 동일하다:

| 변수 분리법 | 이 연구 |
|-----------|---------|
| "분리 가능한가?" | H1: p₁ = p₂이면 분리 가능 |
| 공간 방정식 X(x) | 접기 운동 (δ) |
| 시간 방정식 T(t) | 줄의 진동 (φ) |
| 고유값 λ | 타이밍 커플링 조건 (H2) |
| 경계 조건 | 줄 곡률 매칭 (H3) |

물리학에서 복잡한 시스템을 다루는 핵심 전략은 **"결합된 것처럼 보이는 것을 분리하는 올바른 좌표를 찾는 것"**이다. (φ, α, θ) → (φ, σ, δ) 좌표 변환이 이 역할을 한다.

## 5. 세 가설의 정립 — 계층적 필요조건 체인

### 가설 H1: 무게중심 불변 조건 (CoM Invariance) — 자유도 축소

> **"상·하체의 질량 분포가 p₁ = p₂ 조건을 만족하면, 허리 토크에 의한 접힘은 전체 무게중심을 변화시키지 않고 발의 위치만 이동시킨다."**

- **역할**: 3자유도 → 실질 2자유도(φ + δ)로 축소. 시스템을 "정진자 위의 막대"로 단순화.
- **수학적 표현**: 좌표 (φ, σ, δ)에서 토크의 σ 성분 = (p₂ − p₁)τ → p₁ = p₂이면 0
- **p₁ = p₂의 의미**: M₁·LC₁ + m₂·L₁ = m₂·LC₂ (체형의 질량·길이 조건)
- **검증 결과**: R*(CoM 불변을 만족하는 R)은 존재하지 않음 — 이 조건은 R과 독립 (2026-05-08 계산)

### 가설 H3: 줄 비교란 조건 (Rope Non-Perturbation) — 깨끗한 입력 확보

> **"줄의 곡률 R이 특정 조건을 만족하면, 허리 토크에 의한 접힘이 줄의 운동(φ)을 교란하지 않는다. 접힘의 효과는 순수하게 줄 위에서 발의 위치를 이동시키는 것으로만 작용한다."**

- **역할**: 접힘이 줄을 안 흔들게 함 → H2(타이밍 동기화)가 예측 가능하게 작동
- **H1과의 차이**:
  - H1: 토크 → **CoM을 안 움직임** (체형 조건, R 무관)
  - H3: 토크 → **줄을 안 흔듦** (곡률 조건, R 의존)
- **수학적 표현**: `[1,0,0] · M⁻¹(R) · E = 0` 을 만족하는 R (검증 필요)
- **물리적 비유**: 발이 줄 위를 미끄러지듯 이동 — 마치 와이어 위 구슬의 수직항력이 0인 것

### 가설 H2: 시간적 커플링 (Temporal Coupling) — 균형 복원 메커니즘

> **"기울기에 비례하여 몸을 접으면, 몸의 복원 시간이 기울기에 무관한 상수가 된다. 이 상수가 정진자의 1/4 주기와 일치하는 R이 최적 R이다. 이 조건에서는 어떤 크기의 외란에 대해서도 하나의 접기-펴기 사이클이 균형을 복원한다."**

- **역할**: 실제로 균형을 복원하는 핵심 메커니즘. 최적 R을 결정.
- **수학적 표현**: τ_body = T_rope/4, 즉 R + h_CoM = I/(M·h_CoM)
- **핵심 성질**: 진폭 독립성 — 비례 제어(δ = k·β) 시 복원 시간이 진폭에 무관
- **검증 방법**: R을 변화시키며 시뮬레이션 → R_optimal 근처에서 제어 성능 최적 확인

## 6. 세 가설의 관계: 계층적 필요조건 체인

```
H1 (체형 조건: p₁ = p₂)
  "접힘이 CoM을 안 바꾼다"
  → 3자유도를 2자유도로 축소
  → 시스템이 "막대 + 진자"로 단순화됨

        ↓ 단순화된 시스템에서

H3 (곡률 조건: R = R_opt)
  "접힘이 줄을 안 흔든다"
  → 접힘의 효과 = 순수한 위치 이동
  → 깨끗한 제어 입력 확보

        ↓ 깨끗한 입력이 있으므로

H2 (타이밍 조건: τ_body = T_rope/4)
  "접는 타이밍이 줄의 위상과 동기화"
  → 안티펌핑으로 에너지 추출
  → 줄의 진동을 0으로 수렴시킴
```

**H1이 없으면** 시스템이 너무 복잡해서 H3를 논할 수 없고,
**H3가 없으면** 입력에 잡음이 섞여서 H2가 깨끗하게 작동할 수 없고,
**H2가 없으면** 에너지를 뺄 방법이 없어서 균형이 안 잡힌다.

### H1과 H3의 구분 (개정: 2026-05-11)

이전에는 H1과 H3가 "같은 말"처럼 보였으나, 계산을 통해 서로 다른 물리량에 대한 조건임을 확인:

| | H1 | H3 |
|---|-----|-----|
| 대상 물리량 | CoM 가속도 (σ̈) | 줄 각가속도 (φ̈) |
| 수학적 표현 | `[0,p₁,p₂]·M⁻¹·E = 0` | `[1,0,0]·M⁻¹·E = 0` |
| R 의존성 | **R 무관** (p₁=p₂만으로 결정) | **R 의존** (특정 R에서 성립) |
| 물리적 의미 | 접으면 몸이 안 기울어짐 | 접으면 줄이 안 흔들림 |

## 7. R_optimal 계산 (H2 매칭 조건)

### 계산 과정 (v14 파라미터)

```
[파라미터]
  M = 75 kg, h_CoM = 0.96 m, g = 9.81 m/s²
  I_foot = 89.05 kg·m² (발목 기준 관성모멘트)

[유도]
  τ_body = (π/2)·√(I/(Mgh))     ... 몸 복원 1/4주기
  T_rope/4 = (π/2)·√((R+h)/g)   ... 정진자 1/4주기

  매칭: τ_body = T_rope/4
  → I/(Mgh) = (R+h)/g
  → R + h = I/(Mh)
  → R = I/(Mh) - h

[계산]
  R = 89.05 / (75 × 0.96) - 0.96
    = 89.05 / 72.0 - 0.96
    = 1.237 - 0.96
    = 0.277 m

[결과]
  R_optimal = 0.277 m = 0.288 × h_CoM
  τ_body = T_rope/4 = 0.558 s
```

### 해석

- R_optimal ≈ 0.28 m — **h_CoM의 약 0.29배**
- 파울레티의 경험적 결과 (1.0~1.5 × h_CoM ≈ 0.96~1.44 m)과는 다름
- **모델의 차이**: 파울레티는 단일 몸체 모델, 우리는 상·하체 분리 모델
- **물리적 의미**: 상·하체가 분리되어 접힘이 가능한 모델에서는, 접힘 메커니즘의 효율성 때문에 줄이 덜 처져도(R이 작아도) 균형이 가능하다는 예측
- **k의 선택에 따라 달라질 수 있음**: 현재 k = h/c (발을 CoM 아래로 이동시키는 최소 접힘량)를 사용함. 실제 LQR 제어기의 이득이 다르면 R_optimal도 달라짐

### 검증 필요

1. v14 시뮬레이션에서 R = 0.28 m 근처와 R = 1.0 m 근처에서 제어 성능 비교
2. H3 조건(`[1,0,0]·M⁻¹(R)·E = 0`)을 만족하는 R 계산 및 R_optimal과 비교
3. k (제어 이득)의 영향 분석

## 8. 파울레티 선행연구와의 관계

파울레티(Paoletti)의 연구에서는:
- 상·하체 분리 없이 단일 몸체 + 줄 모델을 사용
- R이 너무 작거나(타이트로프) 너무 크면(평지) 제어 불가능
- 경험적으로 최적 R ≈ 1~1.5 × 무게중심 높이

본 연구의 차별점:
1. **상·하체 분리 모델** → "접힘"이라는 내부 자유도의 역할을 분석 가능
2. **CoM 불변 조건(H1)** → 파울레티에 없는 새로운 물리적 메커니즘
3. **시간 커플링(H2)** → 최적 R을 이론적으로 유도 (경험적 → 이론적)
4. **역그네 원리** → 이전 그네 연구와의 연결, 댐핑 없이도 줄 감쇠 가능
5. **줄 비교란(H3)** → 접힘이 줄을 교란하지 않는 조건

## 부록 A: 관련 수학적 결과

### 좌표 변환

기존 좌표 (φ, α, θ) → 새로운 좌표 (φ, σ, δ):

| 새 좌표 | 정의 | 물리적 의미 |
|---------|------|------------|
| φ | 그대로 | 줄의 흔들림 |
| σ = p₁α + p₂θ | 가중 합 | 무게중심 수평 위치 (발 기준) |
| δ = θ − α | 차이 | 접힘 각도 (허리 꺾임) |

토크 입력의 변환:
```
기존:  E = [0, -1, +1]ᵀ   (φ에 영향 없음)
새로운: E' = [0, (p₂-p₁), 2]ᵀ
             φ   σ(CoM)    δ(접힘)
```

p₁ = p₂이면 토크의 σ(CoM) 성분이 0 → 접힘이 CoM을 안 바꿈.

### 단순 진자 환원

α = θ = φ (몸이 줄과 정렬)일 때:

$$\ddot{\varphi} = -\frac{g}{R + h_{CoM}} \cdot \varphi$$

유효 진자 길이: L_eff = R + h_CoM
고유진동수: ω = √(g / (R + h_CoM))

### R_optimal 공식 (H2)

$$R_{optimal} = \frac{I_{foot}}{M_t \cdot h_{CoM}} - h_{CoM}$$

여기서 I_foot은 직립 상태에서 발목 기준 전체 관성모멘트.
