## 1. 문제 설정

### 1.1 시스템

```
기둥 (고정점)
  └─ [φ] 줄 — 정진자 (안정)
       └─ [α] 하체 — 역진자 (불안정)
            └─ [θ] 상체 — 역진자 (불안정)
```

3자유도(φ, α, θ), 액추에이터 1개(허리 관절). 토크 입력: E = [0, −1, +1].

### 1.2 핵심 질문

> **1개 모터로 3자유도 시스템의 균형이 왜 가능한가?**
> 행렬 계산(가제어성)이 아닌, 물리적 추론으로 설명할 수 있는가?

### 1.3 프레이밍

서양 줄타기: 장대의 관성모멘트 → 균형.
한국 줄타기: 장대 없이, 줄의 처짐(정진자) → 균형.

## 2. 메인 결과: 균형 복원 조건식

### 2.1 균형 복원의 메인 식

> **(1+ε)·cos(ω·T) = ε·cosh(λ·T)**

| 기호 | 정의 | 물리적 의미 |
|------|------|-----------|
| ω | √(g/(R+h)) | 정진자의 고유진동수 |
| λ | √(Mgh/I) | 역진자의 낙하율 |
| ε | 오버슈트 비율 | 발을 CoM 너머로 얼마나 더 이동시키는가 |
| T | 대기 시간 | 접기와 펴기 사이의 시간 |
| R | 줄의 곡률 반경 | 줄의 처짐 정도 |
| h | CoM 높이 | 발목 위 무게중심 높이 |
| M | 전체 질량 | |
| I | 관성모멘트 | 발목 기준 |

### 2.2 이 식의 의미

- **좌변** (1+ε)·cos(ωT): 정진자가 복원하는 정도 (줄이 중앙으로 돌아오는 양)
- **우변** ε·cosh(λT): 역진자가 쓰러지는 정도 (몸이 반대쪽으로 넘어간 양)
- **등호**: 두 효과가 정확히 상쇄 → **한 번의 접기-펴기로 완전 균형 복원**

### 2.3 이 식에서 β₀(초기 기울기)가 없다

기울기에 비례하여 접으면(δ ∝ β₀), 모든 항이 β₀에 비례 → 나누면 소거.

→ **최적 대기 시간 T는 초기 기울기에 무관** (진폭 독립성)
→ 이것이 선형 비례 제어(LQR)가 작동하는 물리적 이유

### 2.4 이 식에서 알 수 있는 것

| 질문 | 답 |
|------|-----|
| 최적 대기 시간 T는? | 식을 T에 대해 풀면 됨 |
| 최적 오버슈트 ε는? | 식을 ε에 대해 풀면 됨 |
| 최적 줄 곡률 R은? | ω 안에 R이 있으므로 식에서 유도 |
| 왜 비례 제어로 충분한가? | β₀가 없으므로 (진폭 독립) |

## 3. 메인 식의 유도: 단순화 모델

### 3.1 가정 (근사 조건)

1. **H1 만족** → 접힘은 CoM을 안 바꾸고 발만 이동
2. **H3 만족** → 접힘은 줄을 교란하지 않음 (줄 독립 진동)
3. **순간 접기/펴기** → 접고 펴는 행위는 dt = 0에서 일어남
4. **소각 근사** → sin β ≈ β, cos β ≈ 1

### 3.2 변수 정의

- **φ(t)**: 줄의 각도. 발의 위치 = R·φ
- **β(t)**: 발 대비 CoM의 기울기 = (x_CoM − x_foot) / h
  - β = 0: 몸이 수직 (발 위에 CoM)
  - β = φ: 몸이 줄에 정렬 (단일 진자로 환원)

### 3.3 제어 사이클

#### Phase 0: 초기 상태

```
x_CoM = h·β₀   (오른쪽으로 기울어짐)
x_foot = 0      (발은 중앙)
β = β₀,  φ = 0
```

#### Phase 1: 순간 접기 (오버슈트)

발을 CoM **너머**로 이동. 오버슈트 비율 ε.

```
x_foot → h·β₀·(1+ε)      (CoM 너머로)
x_CoM → h·β₀              (불변, H1)

φ(0⁺) = h·β₀·(1+ε)/R     (줄 변위)
β(0⁺) = −ε·β₀             (반대쪽으로 약간 기울어짐)
```

왜 오버슈트가 필요한가:
- 자유공간에서 접기→펴기 = 완전 가역 (CoM 변화 0)
- 따라서 곧바로 펴면 아무 효과 없음
- 오버슈트 → 중력이 복원 방향으로 일함 → 비가역 상황 생성

#### Phase 2: 기다리기 (두 역학의 동시 진행)

```
줄 (정진자):  φ̈ = −ω²·φ    →  φ(t) = φ₀·cos(ωt)    ← 중앙으로 복귀
몸 (역진자):  β̈ = +λ²·β    →  β(t) = −ε·β₀·cosh(λt) ← 왼쪽으로 쓰러짐
```

줄은 진동하며 중앙으로 돌아오고, 몸은 자유낙하로 반대쪽으로 쓰러진다.

#### Phase 3: 순간 펴기 (균형 복원)

발을 CoM 바로 아래로 이동 → β_new = 0.

이때 시스템의 새 상태:

```
x_CoM(T) = x_foot(T) + h·β(T) = R·φ(T) + h·β(T)
x_foot_new = x_CoM(T)
φ_new = x_CoM(T)/R = φ(T) + h·β(T)/R
β_new = 0
```

#### 완전 복원 조건: φ_new = 0 AND β_new = 0

```
φ(T) + h·β(T)/R = 0

[h·β₀·(1+ε)/R]·cos(ωT) + h·[−ε·β₀·cosh(λT)]/R = 0

양변을 h·β₀/R로 나누면:
```

> **(1+ε)·cos(ωT) = ε·cosh(λT)**

**β₀가 소거됨 → 진폭 독립성!**

## 4. 세 가설의 역할

### 4.1 가설 체계의 구조

```
    H1 (CoM 불변)    ─┐
                       ├─ 메인 식이 유도되기 위한 전제 (근사 조건)
    H3 (줄 비교란)    ─┘

    H2 (시간 커플링)  ── 메인 식이 나오게 된 물리 원리
                         (접기 → 기다리기 → 펴기)
```

### 4.2 H1: 무게중심 불변 — 자유도 축소

> **p₁ = p₂ 조건에서, 접힘은 CoM을 안 바꾸고 발만 이동시킨다.**

- p₁ = M₁·LC₁ + m₂·L₁,  p₂ = m₂·LC₂
- 3자유도 → 실질 2자유도(φ, δ)로 축소
- R로는 p₁≠p₂를 보상할 수 없음 (5/8 계산)
- 이 조건이 없으면 메인 식의 "x_CoM 불변" 가정이 깨짐

**수학적 검증 (5/12)**:
LQR 이득 행렬을 (φ,σ,δ) 좌표로 변환하면 K_δ = −18.885 (R에 완전 무관).
→ 접힘 제어는 줄의 기하학과 독립 = 공간적 디커플링 확인.

### 4.3 H3: 줄 비교란 — 깨끗한 입력

> **특정 R에서, 접힘이 줄(φ)을 교란하지 않는다.**

- 이 조건이 없으면 메인 식의 "φ̈ = −ω²φ (줄 독립)" 가정이 깨짐
- H1과 다른 물리량: H1은 σ̈(CoM), H3는 φ̈(줄)에 대한 조건

**수학적 검증 (5/12)**:
가제어성 행렬의 조건수 → R = 0.7 m에서 최소 (94,347).
→ 이 R에서 1개 모터의 힘이 3자유도에 가장 균등하게 전달.

### 4.4 H2: 시간적 커플링 — 균형 복원 원리

> **역진자 자유낙하의 방향을 반전시키고, 그 낙하 시간이 정진자의 복귀 시간과 매칭되도록 한다.**

- 오버슈트(ε) → 중력 토크 방향 반전 → 역진자가 "복원 방향으로" 쓰러짐
- 정진자 복귀 + 역진자 낙하가 동시에 완료되는 타이밍 = 메인 식의 T
- 비례 제어(δ ∝ β₀) → β₀ 소거 → 모든 기울기에 동일한 T

**수학적 검증 (5/12)**:
가제어성 그래미안 W(T)의 조건수 → R = 0.5 m에서 최소 시간과 T_rope/4가 8.5% 차이.
A 행렬 고유값: 역진자 시간 τ ≈ 0.33 s (R 무관), 정진자 주기는 R 의존.

## 6. LQR과의 관계

### 6.1 순간 제어 vs 연속 제어

```
순간 제어 (이 모델):  접기(Δx) → 기다리기(T) → 펴기    [이산적]
LQR (실제 제어):     τ = −K·x                          [연속적]

LQR = 순간 접기/펴기의 연속 버전
    = 매 순간 미소한 접기/펴기를 수행
```

### 6.2 왜 선형 제어기(LQR)가 작동하는가

1. **비례 제어(δ ∝ β)가 β₀를 소거** → 고정된 타이밍/이득으로 모든 기울기에 대응 가능
2. **H1이 비선형 교차항을 제거** → 선형 조합(k₁φ + k₂α + k₃θ)으로 충분
3. **H3가 줄을 독립화** → 줄과 몸의 역학을 분리하여 각각 선형으로 처리 가능

고정 계수 제어가 불가능하면(β₀가 남으면), 기울기마다 다른 타이밍이 필요 → 비선형 제어 필수.

## 7. R → ε → T 결정 구조

### 7.1 메인 식의 성격: 필요조건

메인 식: **(1+ε)·cos(ωT) = ε·cosh(λT)**

- ω = √(g/(R+h)) ← R이 결정
- λ = √(Mgh/I) ← 체형이 결정 (R 무관)
- 식 1개, 미지수 2개(ε, T) → 유효한 (ε, T) 조합의 **곡선**을 정의
- 이 곡선 위의 어떤 점이든 β=0, φ=0 달성 가능 (1사이클 복원)
- **ε을 유일하게 결정하지 않음** → 추가 조건 필요

### 7.2 ε=0이 작동하지 않는 이유

T = T_quarter에서 ε=0은 수학적으로 식을 만족하지만:

```
접기: 발을 CoM 바로 아래로 (오버슈트 없음), β = 0
기다리기: β = 0이므로 역진자 작동 안 함 (가역)
펴기: 접기의 정확한 역과정 → β 다시 β₀로 복귀!
→ 아무 효과 없음 (ε=0 = 공 과정)
```

오버슈트(ε>0)가 필요한 물리적 이유: 역진자를 작동시켜 **비가역성**을 만들기 위함.

### 7.3 ε와 T의 관계

```
ε 큼 (많이 오버슈트) → T 짧아야 (빨리 펴야, 역진자 낙하 보상)
ε 작음 (조금 오버슈트) → T 길어도 됨 (천천히 복원)
ε = 0 → T = T_quarter (공 과정, 효과 없음)
```

### 7.4 ε을 결정하는 추가 조건

메인 식만으로는 ε이 결정되지 않음. 실제로는:

- **관절 가동범위**: δ_max → ε_max = c·δ_max/(h·β₀) − 1
- **모터 토크 한계**: 접는 속도 제한 → ε 상한
- **제어 비용 (LQR의 Q/R)**: 빠른 복원 vs 에너지 절약의 균형

```
ε 작음 → 느리지만 작은 토크로 제어 가능
ε 큼 → 빠르지만 큰 토크 필요 + 관절 한계 도달
```

### 7.5 접힘 각도 환산

Δx_foot ≈ c·δ (c ≈ 0.126 m/rad), 필요 발 이동 = h·β₀·(1+ε):

> **δ = h·(1+ε)/c · β₀ ≈ 7.62·(1+ε)·β₀**

| β₀ | δ (ε=0.2) | δ_max=90°일 때 ε_max |
|:---:|:---:|:---:|
| 5° | 46° | 1.36 |
| 10° | 91° | 0.18 |
| 15° | 137° | 불가능 |

## 8. 수렴비 공식과 반복 수렴

### 8.1 완벽 복원 vs 반복 복원

```
완벽 복원 (1사이클):  메인 식을 정확히 만족하는 ε, T
                     → β₀ → 0  (한 방에 끝)
                     → 현실에서는 거의 불가능

반복 복원 (n사이클):  ε, T가 약간 벗어남
                     → β₀ → r·β₀ → r²·β₀ → ...
                     → |r| < 1이면 지수적 수렴
```

### 8.2 수렴비의 닫힌 공식

펴기 후 잔류 기울기: β₁ = β₀·(1+ε)·(1−cos(ωT))

메인 식으로 (1+ε) 치환:

> **r = β₁/β₀ = cosh(λT)·(1−cos(ωT)) / (cosh(λT)−cos(ωT))**

ε에 독립! **T만의 함수**. (ε이 크면 T가 작아지므로 간접적으로 r에 영향)

```
T → 0 (ε → ∞):   r → ω²/(λ²+ω²)  (최소, 최고 성능)
T → T_quarter (ε → 0): r → 1      (효과 없음)
```

### 8.3 최소 수렴비의 R 의존성

r_min = ω²/(λ²+ω²) = g / [λ²(R+h) + g]

| R [m] | r_min | 최대 감소율 | 1% 수렴 사이클 (이론 하한) |
|:---:|:---:|:---:|:---:|
| 0.3 | 0.48 | 52% | 7 |
| 0.7 | 0.42 | 58% | 6 |
| 1.0 | 0.38 | 62% | 5 |
| 1.5 | 0.33 | 67% | 5 |
| 2.0 | 0.29 | 71% | 4 |

R이 클수록 사이클당 수렴이 좋지만, 1사이클의 시간(T_quarter)도 길어짐.

### 8.4 실제 수렴: 관절 한계에 의한 ε 제한

ε이 무한대일 수 없으므로, δ_max = 90°에서:

| β₀ | ε_max | r (R=0.7) | r (R=1.5) | 수렴 사이클 |
|:---:|:---:|:---:|:---:|:---:|
| 3° | 2.94 | 0.43 | 0.35 | 6~9 |
| 5° | 1.36 | 0.45 | 0.38 | 7~10 |
| 10° | 0.18 | 0.82 | 0.66 | 15~25 |

**β₀ 작음 → ε 여유 큼 → 수렴 빠름** (시계열에서 1~2번 진동 후 수렴)
**β₀ 큼 → ε 여유 없음 → 수렴 느림** (시계열에서 오래 진동)

이것이 시뮬레이션에서 관찰되는 "큰 기울기일수록 오래 진동"의 물리적 원인.

### 8.5 이것이 LQR의 정체

```
순간 모델:   r ≈ 0.5  →  한 사이클에 50% 감소, 수 회 반복
LQR:        r ≈ 0.99 →  매 dt에 1% 감소, 연속 반복
```

LQR = 순간 접기/펴기의 연속 버전. K 행렬의 이득 비율이 ε과 T를 암묵적으로 결정.

## 9. 단순화 모델의 한계

### 9.1 접기 ≠ 펴기 (비대칭)

접기 시점과 펴기 시점에서 몸의 상태가 다르므로:

```
접기: δ_fold  (β₀에 비례한 접힘량)
펴기: δ_unfold ≠ δ_fold  (기다리는 동안 β가 변했으므로)

→ 펴기 후 몸은 완전히 곧지 않음 (잔여 접힘 δ_residual ≠ 0)
→ 단, β ≈ 0 (CoM이 발 위) 이므로 넘어지지는 않음
```

δ가 약간 남아있는 것은 **기울기(β)가 아니라 형태(모양)의 문제**로, 안정성에는 영향 없음.

### 9.2 시뮬레이션에서 완전 직립하는 이유

LQR의 평형점이 α = θ = φ = 0 (완전 직립):

```
순간 모델:  β → 0, φ → 0 은 보이지만, δ → 0은 보장 안 됨
LQR:       β → 0, φ → 0, δ → 0 모두 동시 수렴

→ LQR이 매 순간 미세한 접기/펴기로 δ까지 제거
→ 단순화 모델의 "잔여 접힘"은 LQR이 다음 사이클에서 해결
```

### 9.3 단순화 모델의 가치와 한계 정리

| 설명 가능 | 설명 불가 |
|----------|----------|
| ✓ 왜 균형이 복원되는가 (메인 식) | ✗ 최종 완전 직립까지의 과정 |
| ✓ 왜 비례 제어로 충분한가 (β₀ 소거) | ✗ 연속 제어의 세부 역학 |
| ✓ 최적 R, ε, T의 관계 | ✗ H1/H3 불만족 시의 보상 메커니즘 |
| ✓ 수렴 조건 (\|r\| < 1) | ✗ 잔여 접힘(δ)의 수렴 과정 |

이상 기체 모델이 열역학의 핵심 원리를 보여주지만 실제 기체의 상전이를 설명하지 못하는 것과 같은 구조. **원리를 보여주는 것이 목적이므로 충분하다.**

## 12. 메인 식의 재검증 (5/13)

### 12.1 x_CoM(T) = 0 과 메인 식의 동치

Phase 2 동안 무게중심 위치:

```
x_CoM(t) = x_foot(t) + h·β(t)
         = h·(1+ε)·β₀·cos(ωt)  −  h·ε·β₀·cosh(λt)
           ^^^^^^^^^^^^^^^^^^^^^^^^   ^^^^^^^^^^^^^^^^^^^^
           줄이 발을 되돌림 (cos)      몸이 쓰러짐 (cosh)
```

조건 x_CoM(T) = 0 을 전개하면:

> (1+ε)·cos(ωT) − ε·cosh(λT) = 0 ← **메인 식과 동일**

φ_new = 0 (발 복귀)과 x_CoM(T) = 0 (CoM 복귀)은 β_new = 0 조건 하에서 **수학적 동치**.

### 12.2 H1(CoM 불변)은 자동 성립

순간 접기에서 H1을 가정할 필요가 없음:

```
순간 접기 = 내부 토크 (허리 관절)
내부 토크 × 시간 0 = 운동량 변화 0
줄의 구속력 × 시간 0 = 충격량 0
→ CoM 이동 = 0  (뉴턴 제3법칙)
```

p₁ ≠ p₂여도 순간 접기이면 H1은 자동 성립 → 새로운 방정식 없음.

### 12.3 두 번째 식의 탐색: 유한 접기 시간 모델

순간 모델: 식 1개, 미지수 2개 (ε, T) → 곡선 (유일 결정 불가)

유한 접기 시간을 도입하면:

```
식 1 (메인 식): (1+ε)cos(ωT) = εcosh(λT)    (균형 복원 필요조건)
식 2 (접기 시간): T = √(2h(1+ε)/(c·a_eff))   (모터 가속도 제한)

두 식 연립 → R이 주어지면 ε 유일 결정
```

**a_eff(R) = 702/(R+h)²** 으로 놓으면 LQR과 RMSE = 0.116으로 일치:

| R [m] | ε_theory | ε_LQR | 오차 |
|:---:|:---:|:---:|:---:|
| 0.7 | 0.86 | 1.12 | −0.26 |
| 1.0 | 0.68 | 0.64 | +0.04 |
| 1.5 | 0.49 | 0.41 | +0.08 |
| 2.0 | 0.35 | 0.25 | +0.10 |

### 12.4 식의 위상 정리

| | 메인 식 | 접기 시간 식 |
|---|---|---|
| **성격** | 물리적 **필요조건** | 경험적 **기술** |
| **의미** | 균형 복원에 반드시 필요 | LQR이 이렇게 움직인다 |
| **없으면?** | 균형 불가 | 다른 ε으로도 균형 가능 |

**결론: 메인 식 하나가 이 연구의 핵심이며, 그것으로 충분하다.**
