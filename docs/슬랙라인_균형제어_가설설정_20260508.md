## 1. 출발점: 3중 진자의 발견

### 관찰

v14 시뮬레이션에서 제어기(LQR)를 끄고 로봇을 매달아 두면, 시스템은 **3중 진자(Triple Pendulum)**로 작동한다.

```
기둥 꼭대기 (고정점)
  └─ [φ] 로프 — 1번째 진자 (정진자, 안정 평형)
       └─ [α] 하체 — 2번째 진자 (역진자, 불안정)
            └─ [θ] 상체+머리 — 3번째 진자 (역진자, 불안정)
```

| 부분 | 진자 종류 | 평형점 |
|------|----------|--------|
| 줄 (φ) | **정(正)진자** — 매달려 있음 | 아래가 안정 |
| 하체 (α) | **역(逆)진자** — 줄 위에 서 있음 | 위가 불안정 |
| 상체 (θ) | **역(逆)진자** — 하체 위에 서 있음 | 위가 불안정 |

3중 진자는 카오스 거동으로 유명한 시스템이다. 초기 조건의 미세한 차이에도 궤적이 완전히 달라진다.

### 놀라운 사실

이 시스템에서 **액추에이터는 허리 관절(hip motor) 단 1개**뿐이다.
1개의 모터로 3자유도 카오틱 시스템을 안정화시킨다 — 이것은 제어공학적으로 매우 도전적인 문제이다.

### 문제 의식

이 결과는 제어공학자에게는 인상적이지만, **물리학자나 물리 교사들에게는 임팩트가 약하다.** "가제어성 행렬(Controllability Matrix)의 랭크가 full이다"라는 설명은 물리적 통찰이 아니라 수학적 계산이기 때문이다.

**핵심 질문**: 행렬 계산이 아닌, **물리적 추론**으로 "왜 1개 모터로 3자유도를 제어할 수 있는가"를 설명할 수 있는가?

## 2. 프레이밍의 전환: 공학 → 물리

### 제어공학의 언어 (청중에게 닿지 않는 설명)
> "1-input으로 3-DOF underactuated system의 controllability를 확보한다"

### 물리학의 언어 (새로운 프레이밍)
> "정진자와 역진자의 결합에서 나오는 기하학적 안정화 덕분에, 허리 관절의 움직임만으로 전신의 균형이 가능하다"

이 프레이밍은 교과서에 없는 구조를 드러낸다:
- 단순 역진자도 아니고
- 단순 3중 진자도 아닌
- **"정진자 위에 역진자 두 개가 올라탄 혼합형 시스템"**

## 3. 핵심 발견: 토크가 줄에 닿지 않는다

v14의 운동방정식을 분석하면 결정적인 사실이 드러난다.

토크 입력 벡터:
```
E = [0, -1, +1]
     φ    α    θ
```

**허리 토크 τ는 α(하체)와 θ(상체)에만 직접 작용하고, φ(줄의 흔들림)에는 직접 작용하지 않는다.**

그런데 실제로 줄(φ)까지 제어가 된다. 이것은 τ가 φ에 영향을 미치는 **간접 경로**가 존재한다는 뜻이다. 이 간접 경로의 정체를 밝히는 것이 가설 설정의 핵심 과제가 된다.

## 4. 역학적 메커니즘의 추론

### 4.1 허리 토크의 진짜 효과

물리적 추론의 핵심 통찰:

> **"허리 토크의 직접적 효과는 '몸을 접는 것'이지만, 물리적으로 의미 있는 효과는 '발을 옮기는 것'이다."**

줄의 질량이 매우 작고 평형점 근처의 상황을 고려하면, 상체와 하체는 거의 무중력 공간에 떠 있는 것처럼 작동한다. 허리 토크(내력)로 몸을 접으면:
- 상체와 하체가 서로 반대 방향으로 회전
- 적절한 조건에서 전체 무게중심(CoM)은 거의 변하지 않음
- 대신 **발의 위치가 이동**함

접힘 자체는 CoM을 거의 바꾸지 못하고, **발의 이동이 줄의 기하학적 복원력을 통해 진짜 안정화를 만든다.**

### 4.2 두 가지 복원 메커니즘

외란에 의해 몸이 기울어졌을 때, 복원은 **두 단계**로 일어난다:

**복원 1 — 몸 세우기 (빠름, 역진자 안정화)**

발이 CoM 아래로 이동하면, 발(새로운 지지점)을 회전축으로 몸에 작용하는 중력이 복원 토크를 만들어 기울어진 몸을 바로 세운다.

```
기울어진 상태:        발 이동 후:
    /                    /
   / ← CoM              / ← CoM
  /                    /
 ●(발)               ●(발이 CoM 아래로 이동)
                      ↑ 중력이 복원 토크 생성
```

**복원 2 — 발 위치 복원 (느림, 정진자 복원)**

줄은 정진자이므로, φ ≠ 0인 상태에서 자연스럽게 φ → 0으로 돌아간다. 발이 원래 중앙 위치로 복귀한다.

### 4.3 단순 진자로의 환원

제어기가 몸을 줄과 정렬시키면 (α → φ, θ → φ), 운동방정식에 대입하면:

$$\ddot{\varphi} = -\frac{g}{R + h_{CoM}} \cdot \varphi$$

이것은 **유효 길이 L_eff = R + h_CoM 인 단순 진자 방정식**이다.

즉, 몸이 줄과 정렬된 상태에서 전체 시스템은 하나의 단순 정진자로 환원되며, 자연스럽게 중앙으로 복원된다.

### 4.4 역(逆)그네 원리와의 연결

5년 전 연구했던 "앉아서 그네타는 로봇"과의 연결:

| 그네 (이전 연구) | 슬랙라인 (현재) |
|----------------|---------------|
| 바닥에서 몸 펴기 → 에너지 주입 | 바닥에서 **몸 접기** → 에너지 추출 |
| 꼭대기에서 몸 접기 → 에너지 주입 | 꼭대기에서 **몸 펴기** → 에너지 추출 |
| 진폭 증가 (펌핑) | 진폭 감소 (**안티펌핑**) |

그네 원리의 역과정(안티펌핑)으로, 물리적 감쇠 없이도 줄의 진동(φ)을 0으로 수렴시킬 수 있다.

**같은 모터가 같은 동작(접기/펴기)으로 복원 1(몸 세우기)과 복원 2(줄 감쇠)를 모두 수행한다.**

### 4.5 디커플링인가, 커플링인가

하나의 접고-펴는 동작으로 Phase 1(몸 복원)과 Phase 2(줄 감쇠)를 동시에 달성하려면:
- Phase 1: 접고 → 중력에 의해 몸이 서는 것을 기다리고 → 적절한 타이밍에 펴야 함
- Phase 2: 정진자의 위상에 맞춰 접고 펴야 함 (역그네)

둘 사이에는 **시간적 커플링**이 필요하다. 즉:

- **공간적으로는 디커플링** — 접힘이 CoM을 안 바꾸고 발만 이동 (H1)
- **시간적으로는 커플링** — 접는 타이밍이 줄의 위상과 동기화 (H2)

이 두 조건을 동시에 만족하는 R이 최적 R이다.

## 5. 세 가설의 정립

### 가설 H1: 무게중심 불변 조건 (CoM Invariance)

> **"상·하체의 질량 분포가 p₁ = p₂ (즉, M₁·LC₁ + m₂·L₁ = m₂·LC₂) 조건을 만족하면, 허리 토크에 의한 접힘 운동은 전체 무게중심을 변화시키지 않고 발의 위치만 이동시킨다."**

- **유형**: 체형의 질량·길이 조건 (기하학적)
- **물리적 의미**: 접힘이라는 내부 운동이 순수하게 발의 이동으로만 변환됨
- **수학적 근거**: 좌표 변환 (φ, σ, δ)에서 토크의 σ(CoM) 성분 = (p₂ - p₁)τ → p₁ = p₂이면 0

**주의**: H1은 자유공간에서의 조건이다. 줄 위에서 H1이 유지되려면 H3가 추가로 필요하다.

### 가설 H2: 시간적 커플링 (Temporal Coupling)

> **"몸 복원(Phase 1: 접고 기다려서 중력으로 몸을 세움)과 줄 감쇠(Phase 2: 역그네 원리로 진동 소멸)는 하나의 허리 관절로 수행되므로, 두 과정의 시간적 동기화 조건이 존재한다. 이 조건이 단일 모터의 가제어성(controllability)과 일치할 것이다."**

- **유형**: 동역학적 조건 (시간 스케일)
- **물리적 의미**: 하나의 접기-펴기 주기가 몸 복원과 줄 감쇠를 동시에 달성
- **검증 방법**: 커플링 조건을 유도하여 가제어성 행렬의 full rank 조건과 비교

### 가설 H3: 발 궤적 곡률 매칭 (Trajectory Curvature Matching)

> **"자유공간에서 몸을 접을 때 발이 그리는 궤적의 곡률 반경 ρ_foot이 존재하며, 줄의 곡률 R이 이 값과 일치할 때(R = ρ_foot), 발은 줄로부터 수평 반력을 받지 않고 자유롭게 이동할 수 있다. 이것이 제어가 가장 용이한 최적 R의 조건이다."**

- **유형**: 기하학적 조건 (곡률 매칭)
- **물리적 의미**: 줄의 구속력이 접힘 운동을 방해하지 않음 — 마치 와이어 위 구슬의 수직항력이 0인 것과 같은 원리
- **핵심 예측**: ρ_foot은 순수하게 체형(m₁, m₂, L₁, L₂)의 함수 → 최적 R을 체형만으로 계산 가능
- **검증 방법**: ρ_foot을 계산하고, R을 변화시키며 시뮬레이션하여 R = ρ_foot 근처에서 최적 제어 확인

## 6. 세 가설의 관계

### 독립적이면서 보완적

세 가설은 **동일한 물리적 동작(허리를 접었다 펴기)의 세 측면**을 다룬다:

- **H1**: 접을 때 **무엇이 움직이는가** → 발만 움직이고 CoM은 안 움직인다
- **H3**: 접을 때 발이 **어떻게 움직이는가** → 줄의 곡선을 따라 저항 없이 미끄러진다
- **H2**: 접고 펴는 **타이밍이 무엇을 만드는가** → 몸 복원 + 줄 감쇠를 동시에 달성

### H1과 H3의 관계

- **H1**은 자유공간에서의 조건 (체형의 질량·길이 관계)
- **H3**는 줄 위에서 H1이 깨지지 않기 위한 조건 (줄의 곡률)
- H3가 만족되지 않으면 → 줄의 수평 반력(외력) → CoM이 변함 → H1이 깨짐

즉, **H3는 "자유공간의 물리를 줄 위에서도 재현하는 기하학적 조건"**이다.

### 통합 메커니즘 (하나의 문장)

> **"줄의 곡률이 인체의 접힘에 의한 발 궤적의 곡률과 일치할 때(R = ρ_foot), 접힘은 줄에 간섭하지 않고 발만 이동시키며(H3→H1), 이 조건에서 몸의 복원과 줄의 감쇠가 하나의 접기-펴기 주기 안에서 자연스럽게 동기화된다(H2). 이것이 단일 모터로 3자유도 시스템을 제어할 수 있는 물리적 원리이다."**

## 7. 파울레티 선행연구와의 관계

파울레티(Paoletti)의 연구에서는:
- 상·하체 분리 없이 단일 몸체 + 줄 모델을 사용
- R이 너무 작거나(타이트로프) 너무 크면(평지) 제어 불가능
- 경험적으로 최적 R ≈ 1~1.5 × 무게중심 높이

본 연구의 차별점:
1. **상·하체 분리 모델** → "접힘"이라는 내부 자유도의 역할을 분석 가능
2. **CoM 불변 조건(H1)** → 파울레티에 없는 새로운 물리적 메커니즘
3. **궤적 곡률 매칭(H3)** → 최적 R을 체형으로부터 이론적으로 유도 (경험적 → 이론적)
4. **역그네 원리(H2)** → 이전 그네 연구와의 연결, 댐핑 없이도 줄 감쇠 가능

## 8. 다음 단계: 검증 계획

### 8.1 ρ_foot 계산 (H3 검증의 출발점)

임의의 (m₁, m₂, L₁, L₂)에 대해 자유공간에서 몸을 접을 때:
1. CoM 고정 + 각운동량 보존(L=0) 조건 하에서 α(δ) 관계 결정
2. 발 위치 (x_f, z_f)를 접힘 각도 δ의 함수로 계산
3. 발 궤적의 곡률 반경 ρ_foot 유도

### 8.2 시뮬레이션 검증

v14에서 R을 체계적으로 변화시키며 (0.5ρ ~ 2ρ 범위):
- 제어 수렴 시간
- 최대 필요 토크
- 안정 영역 (최대 초기 기울기)

등을 측정하여 R = ρ_foot 근처에서 최적임을 확인.

### 8.3 커플링 조건 검증 (H2)

접기-펴기의 타이밍 조건을 유도하고, 이것이 가제어성 행렬의 full rank 조건과 일치하는지 비교.

## 부록: 관련 수학적 결과

### 좌표 변환

기존 좌표 (φ, α, θ) → 새로운 좌표 (φ, σ, δ):

| 새 좌표 | 정의 | 물리적 의미 |
|---------|------|------------|
| φ | 그대로 | 줄의 흔들림 |
| σ = p₁α + p₂θ | 가중 합 | 무게중심 수평 위치 (발 기준) |
| δ = θ − α | 차이 | 접힘 각도 (허리 꺾임) |

토크 입력의 변환:
```
기존:  E = [0, -1, +1]ᵀ   (φ에 영향 없음)
새로운: E' = [0, (p₂-p₁), 2]ᵀ
             φ   σ(CoM)    δ(접힘)
```

p₁ = p₂이면 토크의 σ(CoM) 성분이 0 → 접힘이 CoM을 안 바꿈.

### 단순 진자 환원

α = θ = φ (몸이 줄과 정렬)일 때:

$$\ddot{\varphi} = -\frac{g}{R + h_{CoM}} \cdot \varphi$$

유효 진자 길이: L_eff = R + h_CoM
고유진동수: ω = √(g / (R + h_CoM))

### 발 궤적 곡률 (계산 예정)

자유공간에서 δ로 접힐 때 발의 궤적:
- 수평: Δx ≈ A·δ (1차)
- 수직: Δz ≈ B·δ² (2차)

포물선 근사: Δz ≈ (B/A²)·Δx²
줄의 곡선: Δz ≈ Δx²/(2R)

매칭 조건: **R_optimal = A² / (2B)** — 체형의 함수로 표현됨.
