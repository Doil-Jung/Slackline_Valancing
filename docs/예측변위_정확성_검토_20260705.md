# 예측변위(q + q̇/λ)의 정확성 검토 — "4D를 2D로 보는 게 위험하지 않은가"

> 2026-07-05. 질문(정도일): FWE는 (φ, φ̇, β, β̇) 4차원에서 움직이는 시스템을 (φ,β) 2차원
> 상태공간으로 보고, 속도는 "예측변위"로 흡수한다. 그 예측변위가 부정확하면 2D 그림 전체가
> 흔들리는 것 아닌가? — 검토 결과와 근거. 수치 검증: `analysis/pred_disp_check.py`.

## 결론 한 줄

**예측변위는 근사가 아니라 선형 결합모델의 정확한 모드 대수(exact modal algebra)다.**
4D→2D는 속도를 버리는 축소가 아니고, 속도는 1/λ_eff 환산으로 정확히 한 번, 손실 없이 들어간다.
따라서 "노브 1개" 구조는 2D 단순화의 산물이 아니라 **불안정성 자체가 1차원**이라는 사실의 표현이다.
단, 의심이 유효한 지점이 따로 있다 — §3 (선형화 범위, 상태추정 품질, 프로파일 충실도, 유계≠소진폭).

## 1. 왜 정확한가 — 예측변위의 진짜 정체

Wait 동역학(δ 고정)의 4D 상태공간은 A₂=M₂₂⁻¹G₂₂의 고유분해로 **서로 불변인 2D 모드평면 두 장**으로
정확히 쪼개진다. 모드좌표 η=V⁻¹q에서:

- 안정평면 (η₁, η̇₁): η̈₁=−ω²_eff η₁ — 진폭 보존 진동. 발산에 기여 없음.
- 불안정평면 (η₂, η̇₂): η̈₂=+λ²_eff η₂ — 정확해가 **η₂(t) = A·e^{λt} + B·e^{−λt}**,
  여기서 **A = ½(η₂ + η̇₂/λ), B = ½(η₂ − η̇₂/λ).**

즉 성장지수의 계수 A는 정의상 ½·u₂ᵀ(q + q̇/λ). **"예측변위에 u₂ 사영"은 A를 꺼내는 좌표 트릭 그 자체**이고,
ε*_gen의 안정조건 A=0은 이 계수를 정확히 소거한다. 세 가지 함의:

1. **속도는 손실 없이 반영된다.** φ̇, β̇는 1/λ 환산으로 A에 정확히 들어간다. "속도를 대충 위치로 바꿨다"가 아니라,
   성장해의 계수가 원래 (위치 + 속도/λ)/2 꼴이다.
2. **u₂ 사영이 안정모드 성분을 위치·속도 모두 자동으로 걸러낸다.** 안정모드가 아무리 크게 출렁여도 A 계산을
   오염시키지 않는다.
3. **"예측변위 = 미래 위치"로 읽으면 틀린다.** 상태가 실제로 q_pred에 도달하는 게 아니다(안정모드·감쇠성분이
   따로 있음). 올바른 독해는 "발산 여부를 결정하는 유일한 스칼라 A의 좌표 표현". (φ,β) 평면 그림은 시각화용
   사영일 뿐, 결정 공식은 4D 전체를 쓴다. B(감쇠성분)를 무시하는 건 의도된 것 — e^{−λt}, 시정수 0.28 s로 사라진다.

## 2. 수치 확인 (R=0.7 사람스케일, `analysis/pred_disp_check.py`)

- **E1 (정확성)**: 임의 4D 상태 100개(위치 ±8°/±4°, 속도 ±20°/s)에 ε*_gen 접기 →
  접기 직후 **|A| ≤ 6×10⁻¹⁷ (기계정밀도)**, 3초 자유전파 유계. 속도가 있어도 정확.
- **E2 (속도 무시 대조군)**: 정지공식 ε*를 움직이는 상태에 쓰면 잔여 A ~ 10⁻²~10⁻³ →
  **0.67~1.05 s에 β>15° 낙하**. docx의 MuJoCo 관찰(비정지에 정지공식 → 1.1~1.6 s 낙하)과 정합.
  같은 상태에 ε*_gen이면 A ~ 10⁻¹⁷. — "예측변위가 부정확하면 다 무너진다"는 걱정의 반대 방향 증거:
  예측변위를 **빼면** 무너지고, 넣으면 정확히 선다.
- **E3 (분해 정확성)**: c₂(t)=Ae^{λt}+Be^{−λt} 닫힌형 vs RK4 수치적분 최대오차 7×10⁻¹⁵.

## 3. 의심이 유효한 지점 — 진짜 오차가 사는 곳

정확성은 **선형 결합모델 안에서의** 정확성이다. 실제 오차원(源) 4가지:

1. **선형화 범위 (소각근사).** e^{λt} 외삽과 모드평면 분해는 선형모델의 것 — 비선형에선 불안정 다양체가 휘고
   λ, u₂ 자체가 상태 의존이 된다. 다만 이건 이미 정면 검증됨: MuJoCo 전물리에서 ε*_gen이 수치최적과
   **±2% (R≥0.6~0.7)** — 예측변위 구조가 전물리를 통과한 직접 증거. R=0.3(φ_max 23.5°)에서 깨지는 것도 기지
   사실이고 원인이 소각근사임과 일관.
2. **상태추정 품질 (실물의 지배 오차 예상).** A 계산에 들어가는 φ는 직접측정 불가(칼만 복원), β̇은 p₁·p₂
   가중합이라 파라미터 오차(유효값!)가 **편향**으로 들어간다. 민감도(R=0.7): β̇ 오차 1°/s → 잔여 A=4.2×10⁻³ →
   β 15° 도달까지 **1.2 s**; φ 추정오차 1° → **1.07 s**. 즉 추정오차는 접기를 "틀리게" 만들지만 폭발적이지 않고,
   λ_eff 배가시간(~0.2 s) 대비 재개입 여유가 5배 이상 — **FWE를 반복 메커니즘으로 쓰는 한 흡수 가능**.
   노이즈(무편향)는 반복마다 새로 뽑히니 평균적으로 상쇄되고, 위험한 건 파라미터 오차발(發) **계통 편향**이다.
3. **유한시간 프로파일 충실도.** γ 보정은 접기 프로파일 형상(삼각 등)을 가정한다. 실제 서보 추종이 다르면
   γ가 어긋나고, δ̈ 추종오차는 μ항을 통해 (φ,β)로 샌다. 예측변위 공식의 문제가 아니라 입력 실행의 문제.
4. **유계 ≠ 소진폭.** A=0이어도 안정모드에 남는 에너지는 크다(E1에서 속도 20°/s급 초기상태는 잔여 진동
   β 진폭 ~18°). 진폭이 크면 1번(소각근사 이탈)으로 되먹임되는 2차 경로가 열린다. "노브 1개"는 발산 소거에
   대한 답이고, **잔여 진동 에너지 관리는 별개의 문제** — 완전 사이클의 T_w=n·T_osc 선택이 바로 그걸 다룬다.

## 4. 요약

- 2D 그림이 흔들릴 걱정은 불필요: 예측변위는 4D를 정확히 담는다. 불안정성이 스칼라 하나(A)로 환원되는 것이
  "노브 1개"의 수학적 실체.
- 실물에서 정말 검토할 것: (a) 칼만 추정 품질이 A에 주는 계통 편향(파라미터 실측이 임계경로인 이유 하나 추가),
  (b) 서보 프로파일 충실도, (c) 큰 속도 상태에서의 잔여 진동 관리(소각근사 이탈 방지).
- 보고서 서술 제안: "속도를 예측변위로 근사했다"라고 쓰지 말 것. "성장모드 계수 A=½(η₂+η̇₂/λ)를 소거한다"가
  정확한 서술이며, 예측변위는 그 계수의 (φ,β) 좌표 표현이다.

## 5. 후속 (같은 날): (φ,β) 평면의 기하적 지위 — 사영인가 단면인가, 그리고 "예측점 평면"

추가 질문: ① (φ,β) 평면은 4D의 사영인가 단면인가? 안정모드 "평면"이 내 그림에서 직선으로 보이는
이유는? ② 사이클 초기의 q_pred는 이해되지만, **진행 도중·후의 상태를 (φ,β)에 찍는 건** 속도가 안 보이는
표시인데 의미가 있는가?

**① 사영(그림자)이다, 단면이 아니다.** 단면이라면 φ̇=β̇=0인 정지상태들만 찍히는 것이고, 실제 궤적은
속도를 가진 4D 곡선의 그림자다. 4D는 두 불변 2D 모드평면 — 안정평면 (η₁,η̇₁)과 불안정평면 (η₂,η̇₂) —
으로 쪼개지는데, **안정평면의 그림자가 바로 안정모드 직선 span(v₁)**이고 (불안정평면의 그림자는
span(v₂)), 그래서 4D의 "평면"이 그림에선 "직선"으로 보인다. 직관이 정확했던 것.

**② 의심은 절반 정확하다.** 원위치 (φ,β) 점은 도중·후의 운명을 담지 못한다 — 같은 점이라도 속도가
다르면 운명이 다르고, 그림자라서 궤적이 자기교차도 한다. **"점이 직선 위/근처" ≠ 안정.** 기존 그림의
정당성은 그림에서 읽는 기하가 아니라 뒤에서 4D 전체로 강제한 대수(A_final=0)였다.

**③ 구원: 같은 평면에 예측점 q_pred = q + q̇/λ 를 찍으면 그림이 정확해진다.** 근거는 쌍직교성
u₂⊥v₁: 안정모드 직선은 정확히 u₂의 영직선 {x: u₂ᵀx=0}이고, u₂ᵀq_pred = 2A. 따라서 예측점 평면에서:

- **예측점이 직선 위 ⇔ A=0** — 속도를 포함한 정확한 안정 판정. 직선까지 수직거리 = 2A/|u₂|
  (잔여 발산의 눈금).
- Wait(자유운동) 중: q_pred = v₁(η₁+η̇₁/λ) + v₂·2A e^{λt}. **A=0이면 예측점이 직선 위를 문자
  그대로 미끄러지고**(안정모드 진동으로 왕복), A≠0이면 **순수 e^{λt}**로 직선에서 멀어진다 —
  감쇠성분 B가 자동으로 걸러져서 원평면보다 오히려 깨끗하다.
- 순간접기 점프는 속도 보존이라 예측점도 같은 Δq — **CoM 등고선 방향 이동이 그대로 유지**된다.
- 완전 사이클의 서사가 그림에서 문자 그대로 보인다: 과접기로 직선 반대편에 일부러 떨어뜨림 →
  Wait 동안 e^{λt}로 자람 → 펴기 킥이 정확히 직선 위에 착지 → 이후 직선을 따라 미끄러짐.

수치 확인(`analysis/pred_plane_traj.py`, R=0.7): 순간 ε* 접기 후 예측점의 직선이탈 ≤ 8×10⁻¹⁴;
완전사이클 Wait 중 이탈거리 = 2A·e^{λt}/|u₂| 일치(격자오차 수준); 펴기 종료 후 직선 복귀.
그림 `docs/예측점평면_궤적_R0.7.png` (왼쪽 원평면 = 그림자, 오른쪽 예측점 평면 = 정확 판정).

**두 평면의 역할 분담**: 원평면은 **위치 법칙**의 무대(CoM 등고선, x_CoM=Rφ+hβ, 접기 점프 기하)이고,
예측점 평면은 **안정성 판정**의 무대(직선 = 판정선). 보고서에는 둘을 나란히 놓는 게 정확하다.
단, 예측점 평면에서는 유한시간 접기 중 속도 스파이크가 1/λ로 증폭돼 크게 보이는 것이 정상(왜곡 아님).
