# 모드 분석과 로봇 제어 전략 논의 (2026-06-07)

## 1. 유효 변수의 발견 : phi-beta 커플링

### 사용된 형상 파라미터 (사람 기준)

| 파라미터 | 값 | 설명 |
|---------|-----|------|
| M1 | 30 kg | 하체 질량 |
| m2 | 45 kg | 상체 질량 |
| Mt | 75 kg | 총 질량 |
| L1 | 0.85 m | 하체 길이 |
| LC1 | 0.30 m | 하체 CoM (발목 기준) |
| L_upper | 0.85 m | 상체 길이 |
| LC2 | 0.40 m | 상체 CoM (힙 기준) |
| B_theta | 0.5 Nm·s/rad | 힙 관절 감쇠 |

### 배경
- 기존 분리 모델(H3)에서 메인식의 T(복원 시간)가 MuJoCo 대비 3~4배 과대예측되는 문제가 있었음
- 원인: phi(줄 흔들림)와 beta(몸 기울기)가 질량행렬의 비대각 항으로 **관성 커플링**되어 있음을 무시했기 때문

### 핵심 발견

질량행렬 `M`을 역행렬한 후 (phi, beta) 2x2 부분계의 동역학:

```
phi_dd  = -w^2_diag * phi  + c_phi * beta
beta_dd =  c_beta   * phi  + lambda^2_diag * beta
```

여기서 **c_phi ≠ c_beta** (부호도 크기도 다름):

| R [m] | c_phi (phi_dd 내 beta 커플링) | c_beta (beta_dd 내 phi 커플링) |
|-------|-------------------------------|-------------------------------|
| 0.3 | -142.0 | +49.0 |
| 1.0 | -42.6 | +49.0 |
| 3.0 | -14.2 | +49.0 |

- **c_beta는 R에 무관 (항상 +49.0)**: 몸 기울기(beta)에 대한 중력 복원력은 줄 반지름과 무관
- **c_phi는 R이 작을수록 큼**: R↓ → 진자 고유진동수 ω↑ → 같은 변위에서 가속도↑ → beta에 더 강한 관성력 전달

이 2x2 행렬을 **고유값 분해**하면 두 개의 독립 모드가 나옴:

| R [m] | Phi_eff (안정 모드) | Beta_eff (불안정 모드) |
|-------|--------------------|--------------------|
| 0.3 | phi + (-0.26)*beta | (-0.76)*phi + beta |
| 0.5 | phi + (-0.41)*beta | (-0.72)*phi + beta |
| 1.0 | phi + (-0.67)*beta | (-0.59)*phi + beta |
| 1.5 | phi + (-0.80)*beta | (-0.46)*phi + beta |
| 2.0 | phi + (-0.86)*beta | (-0.37)*phi + beta |
| 3.0 | phi + (-0.92)*beta | (-0.27)*phi + beta |

- **Phi_eff**: 안정 진자 모드 (줄 흔들림 + 몸 기울기 혼합)
- **Beta_eff**: 불안정 역진자 모드 (쓰러짐 + 줄 흔들림 혼합)

### 유효 주파수

| R [m] | w_diag | w_eff | 비율 | l_diag | l_eff | 비율 |
|-------|--------|-------|------|--------|-------|------|
| 0.3 | 13.22 | 11.72 | 0.89x | 7.00 | 3.41 | 0.49x |
| 0.5 | 10.24 | 8.35 | 0.82x | 7.00 | 3.71 | 0.53x |
| 1.0 | 7.24 | 4.87 | 0.67x | 7.00 | 4.50 | 0.64x |
| 2.0 | 5.12 | 2.80 | 0.55x | 7.00 | 5.53 | 0.79x |

- 커플링이 양쪽 주파수를 **모두 느리게** 함 (관성 증가 효과)
- R이 작을수록 커플링이 강함 (phi-beta 성분이 크게 섞임)

### 커플링 강도

```
c_phi / w^2_diag = 81.3%  (모든 R에서 동일 — 비율이 R에 무관)
c_beta           = +49.0  (모든 R에서 동일 — 값 자체가 R에 무관)
```

- c_phi의 **절대값**은 R에 따라 변하지만, **대각항 대비 비율**은 체형(p1, p2, h_com)에만 의존
- c_beta는 절대값 자체가 체형에만 의존하고 R과 완전히 무관


## 2. LQR 게인의 모드 좌표 변환

### (phi, alpha, theta) -> (phi, beta, delta) -> (Phi_eff, Beta_eff, delta)

LQR 게인 K를 세 좌표계에서 비교한 결과:

**R = 1.0 m 예시:**
```
(phi, alpha, theta):      pos=[6623  -7613  -3013]  vel=[1700  -1817  -921]
(phi, beta,  delta):      pos=[6623 -10626    -82]  vel=[1700  -2738  -166]
(Phi_eff, Beta_eff, d):   pos=[-11430 12516   -82]  vel=[-2940  3221  -166]
```

### 핵심 결과

#### K_delta의 R 독립성 (변동 0.10%)
```
R=0.3: K_delta = -81.52
R=0.5: K_delta = -81.55
R=1.0: K_delta = -81.51
R=2.0: K_delta = -81.39
R=3.0: K_delta = -81.32
```
-> **접힘(delta) 게인은 줄 길이와 완전히 무관한 상수**

#### 모드별 게인 비율
```
R=0.3:  Beta/Phi = 1.96x
R=1.0:  Beta/Phi = 1.10x
R=1.5:  Beta/Phi = 1.01x  <-- 거의 동일
R=3.0:  Beta/Phi = 0.89x
```
-> LQR은 두 모드를 **비슷한 비중**으로 제어

#### 속도 게인/위치 게인 비율 (감쇠비)
```
R=0.3: Phi모드 0.324, Beta모드 0.320  <-- 거의 같음
R=1.0: Phi모드 0.257, Beta모드 0.257  <-- 완전히 같음
R=1.5: Phi모드 0.228, Beta모드 0.229  <-- 완전히 같음
```
-> LQR이 두 모드에 **같은 감쇠비** 적용

### 토크 입력 벡터 (모든 R에서 동일)
```
E = [0, -0.4483, +2.0000] in (phi, beta, delta)
```
- phi에 직접 작용 없음 (under-actuated)
- delta에 가장 강하게 작용


## 3. 실전 로봇 제어 전략

### 모드 기반 제어 코드 구조 (ESP32용)
```
[센서] IMU -> alpha, theta, alpha_dot, theta_dot
[변환]
  beta = (p1*alpha + p2*theta) / (Mt*h_com)
  delta = theta - alpha
  Phi_eff = phi + c1*beta     (c1: 상수, R에서 한번 계산)
  Beta_eff = c2*phi + beta    (c2: 상수)
[칼만] phi만 추정 (beta, delta는 직접 계산 가능)
[제어]
  tau = -K_Phi*Phi_eff - K_Beta*Beta_eff - K_delta*delta
        -K_dPhi*dPhi_eff - K_dBeta*dBeta_eff - K_ddelta*ddelta
```

### 실질적 튜닝 파라미터 (2~3개)

| 파라미터 | 의미 | 조절 상황 |
|---------|------|---------|
| K_Beta | 쓰러짐 방지 강도 | 넘어지면 올리기 |
| K_Phi | 줄 흔들림 잡는 강도 | 좌우 흔들리면 올리기 |
| 감쇠비 | K_vel/K_pos (두 모드 공통) | 떨리면/발진하면 올리기 |
| K_delta | 접힘 반응 | -81.5 (고정, 건드리지 않음) |


## 4. LQR과 FWE의 물리적 연결

### FWE (이산적)
```
접기(Fold) -> 기다리기(Wait) -> 펴기(Extend)
한 사이클을 크게 수행
```

### LQR (연속적)
```
매 순간 미세한 접기/펴기를 연속 수행
"기다림"은 물리 법칙(질량행렬 커플링)이 자동으로 처리
tau 비례 beta -> delta 변화 -> phi 변화 -> beta 복원 (체인)
```

- 둘 다 같은 물리적 경로(delta -> phi -> beta)를 사용
- FWE는 이산적 큰 동작, LQR은 연속적 미세 동작


## 5. 내일 작업 계획

### 로봇 제작 순서
```
1. 줄(철사) 물성 측정: R, m_wire, b_phi (자유 진동 테스트)
2. 로봇 물성 측정: M1, m2, L1, L2, 각 CoM
3. 최적 형태 시뮬레이션 (파라미터 편차에 대한 마진 탐색)
4. 모드 기반 LQR 게인 계산 (오프라인)
5. ESP32 코드: 센서 -> 칼만(phi) -> 모드변환 -> 제어 -> 모터
6. 지연 측정 -> 보상 추가
7. 현장 튜닝: K_Beta, K_Phi 조절
```

### 고려사항
- 줄이 두꺼운 철사+베어링 구조 -> 줄 질량과 베어링 마찰 감쇠 측정 필요
- phi 직접 측정 불가 -> 칼만필터 (phi 1자유도만 추정)
- 통신/계산 지연 -> 상태증강 방식 보상 필요
- 파라미터 2% 오차 민감도 -> 최적 형태 + 여유 있는 감쇠비로 마진 확보
