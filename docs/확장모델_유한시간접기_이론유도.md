# 확장 모델: 유한 시간 접기-기다리기-펴기 이론 유도

## 1. 상태 변수와 파라미터

### 1.1 상태 벡터

**v** = [φ, φ̇, β, β̇]ᵀ

| 변수 | 정의 |
|------|------|
| φ | 줄의 진자 각도. x_foot = R·φ |
| β | CoM 기울기. β = (p₁α + p₂θ)/(p₁+p₂) |

### 1.2 시스템 파라미터

| 기호 | 정의 | 단위 |
|------|------|------|
| ω | √(g/(R+h)) — 정진자 고유진동수 | rad/s |
| λ | √(Mgh/I) — 역진자 낙하율 | rad/s |
| a_f | τ_fold / I_δ — 접기 각가속도 | rad/s² |
| c_foot | p₂/(p₁+p₂) — 발 변위 계수 | 무차원 |
| f_φ | (c_foot/R)·a_f — 줄에 대한 가력 | rad/s² |
| f_β | (c_foot/h)·a_f — β에 대한 가력 | rad/s² |

### 1.3 접기 시간

등가속 회전 가정: δ(t) = ½·a_f·t²

δ_fold = ½·a_f·T_f² 이므로:

> **T_f = √(2·δ_fold / a_f)**

대칭 펴기: T_e = T_f (같은 토크, 같은 각도)

총 사이클 시간: **T_total = 2·T_f + T_w**

---

## 2. 각 Phase의 운동 방정식과 해석해

β₀ > 0 (오른쪽 기울어짐), 접기 방향 = 오른쪽 (발을 오른쪽으로) 기준.

### 2.1 Phase FOLD (0 ≤ t ≤ T_f)

**운동 방정식:**

```
φ̈ = -ω²φ + f_φ     (진자 + 접기 가력)
β̈ = +λ²β - f_β     (역진자 - 접기 보정)
```

물리적 의미:
- f_φ: 접기 토크의 반작용이 줄을 밀어냄 → φ 증가 방향 가력
- f_β: 접기가 발을 CoM 방향으로 이동 → β 감소 방향 가력

**해석해 (상수 계수 비동차 2계 ODE):**

φ 방정식의 특수해: φ_p = f_φ/ω²

```
φ(t) = φ₀·cos(ωt) + (φ̇₀/ω)·sin(ωt) + (f_φ/ω²)·(1 - cos(ωt))
φ̇(t) = -φ₀·ω·sin(ωt) + φ̇₀·cos(ωt) + (f_φ/ω)·sin(ωt)
```

검증: φ̈ = -ω²[φ₀cos(ωt) + (φ̇₀/ω)sin(ωt) + (f_φ/ω²)(1-cos(ωt))] + f_φ
     = -ω²φ(t) + f_φ ✓

β 방정식의 특수해: β_p = f_β/λ²

```
β(t) = β₀·cosh(λt) + (β̇₀/λ)·sinh(λt) - (f_β/λ²)·(cosh(λt) - 1)
β̇(t) = β₀·λ·sinh(λt) + β̇₀·cosh(λt) - (f_β/λ)·sinh(λt)
```

검증: β̈ = λ²[β₀cosh(λt) + (β̇₀/λ)sinh(λt) - (f_β/λ²)(cosh(λt)-1)] + f_β·(cosh-1 미분 보정)
     → β̈ = λ²β(t) - f_β ✓

**t = T_f에서의 값 (FOLD 종료):**

```
φ_f = φ₀·C_ω + (φ̇₀/ω)·S_ω + (f_φ/ω²)·(1 - C_ω)
φ̇_f = -φ₀·ω·S_ω + φ̇₀·C_ω + (f_φ/ω)·S_ω

β_f = β₀·Ch_λ + (β̇₀/λ)·Sh_λ - (f_β/λ²)·(Ch_λ - 1)
β̇_f = β₀·λ·Sh_λ + β̇₀·Ch_λ - (f_β/λ)·Sh_λ
```

약어: C_ω = cos(ωT_f), S_ω = sin(ωT_f), Ch_λ = cosh(λT_f), Sh_λ = sinh(λT_f)

---

### 2.2 Phase WAIT (0 ≤ t' ≤ T_w)

**운동 방정식** (가력 없음):

```
φ̈ = -ω²φ     (순수 진자)
β̈ = +λ²β     (순수 역진자)
```

**해석해:**

```
φ(t') = φ_f·cos(ωt') + (φ̇_f/ω)·sin(ωt')
φ̇(t') = -φ_f·ω·sin(ωt') + φ̇_f·cos(ωt')

β(t') = β_f·cosh(λt') + (β̇_f/λ)·sinh(λt')
β̇(t') = β_f·λ·sinh(λt') + β̇_f·cosh(λt')
```

---

### 2.3 Phase EXTEND (0 ≤ t'' ≤ T_e = T_f)

**운동 방정식** (반대 방향 가력):

```
φ̈ = -ω²φ - f_φ     (진자 - 펴기 가력)
β̈ = +λ²β + f_β     (역진자 + 펴기 보정)
```

**해석해:**

```
φ(t'') = φ_w·cos(ωt'') + (φ̇_w/ω)·sin(ωt'') - (f_φ/ω²)·(1 - cos(ωt''))
φ̇(t'') = -φ_w·ω·sin(ωt'') + φ̇_w·cos(ωt'') - (f_φ/ω)·sin(ωt'')

β(t'') = β_w·cosh(λt'') + (β̇_w/λ)·sinh(λt'') + (f_β/λ²)·(cosh(λt'') - 1)
β̇(t'') = β_w·λ·sinh(λt'') + β̇_w·cosh(λt'') + (f_β/λ)·sinh(λt'')
```

## 3. 행렬 표현

### 3.1 각 Phase의 전달 행렬

각 phase를 **v_out = A · v_in + b** 형태로 표현:

#### FOLD 행렬 A_F (4×4)

```
A_F = [ C_ω     S_ω/ω    0        0      ]
      [-ω·S_ω   C_ω      0        0      ]
      [ 0        0        Ch_λ     Sh_λ/λ ]
      [ 0        0        λ·Sh_λ   Ch_λ   ]
```

C_ω = cos(ωT_f), S_ω = sin(ωT_f), Ch_λ = cosh(λT_f), Sh_λ = sinh(λT_f)

#### FOLD 변위 b_F (4×1)

```
b_F = [ +(f_φ/ω²)·(1 - C_ω)  ]
      [ +(f_φ/ω)·S_ω          ]
      [ -(f_β/λ²)·(Ch_λ - 1)  ]
      [ -(f_β/λ)·Sh_λ         ]
```

#### WAIT 행렬 A_W (4×4)

```
A_W = [ C_ω'     S_ω'/ω    0         0       ]
      [-ω·S_ω'   C_ω'      0         0       ]
      [ 0         0         Ch_λ'     Sh_λ'/λ ]
      [ 0         0         λ·Sh_λ'   Ch_λ'   ]
```

C_ω' = cos(ωT_w), S_ω' = sin(ωT_w), Ch_λ' = cosh(λT_w), Sh_λ' = sinh(λT_w)

변위: **b_W = 0** (가력 없음)

#### EXTEND 행렬 A_E (4×4)

A_E = A_F와 동일한 구조 (T_e = T_f이므로 같은 행렬)

#### EXTEND 변위 b_E (4×1)

```
b_E = -b_F = [ -(f_φ/ω²)·(1 - C_ω)  ]
             [ -(f_φ/ω)·S_ω          ]
             [ +(f_β/λ²)·(Ch_λ - 1)  ]
             [ +(f_β/λ)·Sh_λ         ]
```

### 3.2 1사이클 전달

```
v_final = A_E · (A_W · (A_F · v₀ + b_F) + 0) + b_E
        = A_E · A_W · A_F · v₀ + A_E · A_W · b_F + b_E
```

> **v_final = M · v₀ + d**

여기서:
- **M = A_E · A_W · A_F** (4×4 전달 행렬)
- **d = A_E · A_W · b_F + b_E** (4×1 변위 벡터)

## 4. 표준 초기 조건 분석

### 4.1 정지 출발: v₀ = [0, 0, β₀, 0]ᵀ

FOLD 후 (약어: C=C_ω, S=S_ω, Ch=Ch_λ, Sh=Sh_λ):

```
φ_f = (f_φ/ω²)·(1 - C)
φ̇_f = (f_φ/ω)·S
β_f = β₀·Ch - (f_β/λ²)·(Ch - 1)
β̇_f = β₀·λ·Sh - (f_β/λ)·Sh = (β₀λ - f_β/λ)·Sh
```

β_f를 정리하면:

```
β_f = (β₀ - f_β/λ²)·Ch + f_β/λ²
```

φ_f 관찰:
- φ_f > 0: 접기에 의해 줄이 밀려남 ✓
- φ_f는 β₀에 무관! (f_φ는 상수) ← 주의: 접는 양이 β₀에 비례하면 T_f가 β₀에 의존하므로 C, S도 β₀에 의존

### 4.2 T_f의 β₀ 의존성

제어 법칙 δ_fold = k₁·β₀에 의해:

```
T_f = √(2·k₁·β₀ / a_f)
```

T_f ∝ √β₀ 이므로 C_ω, S_ω, Ch_λ, Sh_λ 모두 β₀에 의존.

→ **β₀가 소거되지 않음** (순간 모델과의 핵심 차이)
→ 수렴비 r = |β_final/β₀|는 β₀의 함수

### 4.3 소각 근사 (β₀ → 0, T_f → 0)

T_f → 0일 때:
```
cos(ωT_f) → 1,  sin(ωT_f) → ωT_f
cosh(λT_f) → 1, sinh(λT_f) → λT_f
```

FOLD의 효과:
```
φ_f → (f_φ/ω²)·½ω²T_f² = ½f_φ·T_f² = (c_foot/R)·½a_f·T_f² = (c_foot/R)·δ_fold
β_f → β₀ - (f_β)·½T_f² = β₀ - (c_foot/h)·δ_fold
```

→ 순간 모델의 "점프 조건"으로 환원! ✓
- Δφ = (c_foot/R)·δ_fold (발 변위)
- Δβ = -(c_foot/h)·δ_fold (기울기 보정)

---

## 5. 수렴 조건

### 5.1 일반 수렴비

v₀ = [0, 0, β₀, 0]ᵀ에 대해 v_final = M·v₀ + d를 계산하면:

```
β_final = M₃₁·0 + M₃₂·0 + M₃₃·β₀ + M₃₄·0 + d₃
        = M₃₃·β₀ + d₃
```

수렴비:
```
r = |β_final / β₀| = |M₃₃ + d₃/β₀|
```

d₃는 f_β에 비례하고, f_β = (c_foot/h)·a_f는 상수.
하지만 M₃₃과 d₃ 모두 T_f(β₀)에 의존.

### 5.2 T_f를 고정 파라미터로 취급

β₀ 의존성을 피하기 위해, **T_f를 직접 제어 파라미터로** 사용:
- "β₀에 비례하여 접는다"를 "T_f를 상태에 따라 결정한다"로 전환
- 또는 τ_fold를 조절하여 T_f를 일정하게 유지

T_f를 고정하면 M, d 모두 상수 → 선형 해석 가능:
- M의 고유값 |λᵢ| < 1이면 수렴
- d는 고정점 v* = (I-M)⁻¹·d를 결정

---

## 6. 순간 모델 극한 검증

T_f → 0, a_f → ∞ (δ_fold = ½a_f·T_f² 유지) 극한:

- A_F → I₄ (단위행렬)
- b_F → [c_foot·δ_fold/R, 0, -c_foot·δ_fold/h, 0]ᵀ
- A_E → I₄
- b_E → -b_F

1사이클:
```
v_final = I · A_W · (I · v₀ + b_F) + (-b_F)
        = A_W · v₀ + A_W · b_F - b_F
        = A_W · v₀ + (A_W - I) · b_F
```

이는 원래 순간 모델과 동일:
- A_W로 자유 진화 (WAIT 동안)
- (A_W - I)·b_F로 접기 효과 전파

→ **확장 모델이 순간 모델의 일반화임을 확인** ✓

## 7. 전달 행렬 M의 블록 구조 전개

### 7.1 블록 대각 구조

A_F, A_W, A_E는 모두 **2×2 블록 대각 행렬**:

```
A = [ P  0 ]     P: φ 부분행렬 (2×2)
    [ 0  Q ]     Q: β 부분행렬 (2×2)
```

따라서 M = A_E · A_W · A_F도 블록 대각:

```
M = [ P_E·P_W·P_F    0           ]
    [ 0               Q_E·Q_W·Q_F ]
```

φ와 β가 **독립적으로** 전파됨 (행렬 수준에서 비결합).
결합은 오직 **변위 벡터 d**를 통해서만 발생.

### 7.2 φ 블록: P_cycle = P_E · P_W · P_F

각 phase의 P 행렬 (2×2 회전 행렬):

```
P_F = [ cos(ωT_f)     sin(ωT_f)/ω  ]
      [-ω·sin(ωT_f)   cos(ωT_f)    ]

P_W = [ cos(ωT_w)     sin(ωT_w)/ω  ]
      [-ω·sin(ωT_w)   cos(ωT_w)    ]

P_E = P_F  (T_e = T_f)
```

P는 모두 **회전 행렬** → det = 1, 고유값 = e^{±iωT}

P_cycle = P_F · P_W · P_F = 회전 행렬의 곱 = 총 회전각 ω·(2T_f + T_w) = ω·T_total의 회전

```
P_cycle = [ cos(ωT_total)     sin(ωT_total)/ω  ]
          [-ω·sin(ωT_total)   cos(ωT_total)    ]
```

**φ 블록의 고유값**: e^{±iωT_total}, |고유값| = 1

→ φ는 **발산도 수렴도 하지 않음** (에너지 보존 진자)
→ φ의 수렴은 오직 변위 벡터 d를 통해 이루어져야 함

### 7.3 β 블록: Q_cycle = Q_E · Q_W · Q_F

```
Q_F = [ cosh(λT_f)     sinh(λT_f)/λ  ]
      [ λ·sinh(λT_f)   cosh(λT_f)    ]

Q_W = [ cosh(λT_w)     sinh(λT_w)/λ  ]
      [ λ·sinh(λT_w)   cosh(λT_w)    ]

Q_E = Q_F  (T_e = T_f)
```

Q는 **쌍곡 회전 행렬** → det = 1, 고유값 = e^{±λT}

Q_cycle의 고유값: e^{±λT_total} (단순 곱일 때)

실제로는 Q_F · Q_W · Q_F ≠ 단순 총 시간의 쌍곡 회전.
정확한 계산:

```
Q_F · Q_W = [ Ch_f·Ch_w + Sh_f·Sh_w    Ch_f·Sh_w/λ + Sh_f·Ch_w/λ ]
            [ λSh_f·Ch_w + λCh_f·Sh_w   Sh_f·Sh_w + Ch_f·Ch_w     ]

         = [ cosh(λ(T_f+T_w))     sinh(λ(T_f+T_w))/λ ]
           [ λsinh(λ(T_f+T_w))    cosh(λ(T_f+T_w))   ]
```

(쌍곡 덧셈 정리 적용)

마찬가지로: (Q_F · Q_W) · Q_F = Q(T_f + T_w + T_f) = Q(T_total)

```
Q_cycle = [ cosh(λT_total)     sinh(λT_total)/λ  ]
          [ λ·sinh(λT_total)   cosh(λT_total)    ]
```

**β 블록의 고유값**: e^{±λT_total}

→ **β는 항상 발산** (|e^{λT_total}| > 1)
→ 단, 변위 벡터 d가 이 발산을 상쇄해야 수렴 가능

### 7.4 핵심 통찰

> **전달 행렬 M 자체는 수렴을 보장하지 않는다.**
> - φ 블록: |고유값| = 1 (중립)
> - β 블록: |고유값| > 1 (발산)
>
> 수렴은 **변위 벡터 d의 효과**에 의해 달성된다.
> d는 접기/펴기 가력(f_φ, f_β)에 의한 "밀어내기" 효과.
> 이 밀어내기가 β 발산보다 크면 수렴.

## 8. 변위 벡터 d의 전개

### 8.1 d = A_E · A_W · b_F + b_E

b_F와 b_E를 φ, β 블록으로 분리:

```
b_F = [ b_F^φ ]    b_F^φ = [ +(f_φ/ω²)(1-C)  ]    b_F^β = [ -(f_β/λ²)(Ch-1)  ]
      [ b_F^β ]            [ +(f_φ/ω)·S       ]            [ -(f_β/λ)·Sh       ]

b_E = -b_F
```

A_W · b_F의 각 블록:

```
(A_W · b_F)^φ = P_W · b_F^φ
(A_W · b_F)^β = Q_W · b_F^β
```

A_E · (A_W · b_F):

```
(A_E · A_W · b_F)^φ = P_F · P_W · b_F^φ
(A_E · A_W · b_F)^β = Q_F · Q_W · b_F^β
```

따라서:

```
d^φ = P_F · P_W · b_F^φ + b_E^φ = P_F · P_W · b_F^φ - b_F^φ
d^β = Q_F · Q_W · b_F^β + b_E^β = Q_F · Q_W · b_F^β - b_F^β
```

### 8.2 d^β (β 수렴을 결정하는 핵심)

약어: T_fw = T_f + T_w

```
Q_F · Q_W = Q(T_fw) = [ cosh(λT_fw)     sinh(λT_fw)/λ ]
                       [ λsinh(λT_fw)    cosh(λT_fw)   ]
```

```
Q(T_fw) · b_F^β = [ cosh(λT_fw)·(-(f_β/λ²)(Ch-1)) + (sinh(λT_fw)/λ)·(-(f_β/λ)Sh)  ]
                   [ λsinh(λT_fw)·(-(f_β/λ²)(Ch-1)) + cosh(λT_fw)·(-(f_β/λ)Sh)       ]
```

첫 번째 성분:
```
= -(f_β/λ²)·[ cosh(λT_fw)·(Ch-1) + sinh(λT_fw)·Sh ]
= -(f_β/λ²)·[ cosh(λT_fw)·cosh(λT_f) - cosh(λT_fw) + sinh(λT_fw)·sinh(λT_f) ]
= -(f_β/λ²)·[ cosh(λ(T_fw+T_f)) - cosh(λT_fw) ]
= -(f_β/λ²)·[ cosh(λT_total) - cosh(λT_fw) ]
```

여기서 T_total = T_fw + T_f = 2T_f + T_w

따라서:
```
d₃ = -(f_β/λ²)·[ cosh(λT_total) - cosh(λT_fw) ] - (-(f_β/λ²)(Ch-1))
   = -(f_β/λ²)·[ cosh(λT_total) - cosh(λT_fw) - cosh(λT_f) + 1 ]
```

### 8.3 1사이클 후 β_final (정지 출발)

v₀ = [0, 0, β₀, 0]ᵀ일 때:

```
β_final = [Q_cycle]₁₁ · β₀ + d₃
        = cosh(λT_total) · β₀ + d₃
```

```
β_final = cosh(λT_total)·β₀ - (f_β/λ²)·[cosh(λT_total) - cosh(λT_fw) - cosh(λT_f) + 1]
```

정리:
```
β_final = [cosh(λT_total) - (f_β/λ²)(cosh(λT_total) - cosh(λT_fw) - cosh(λT_f) + 1)] · ...
```

실은 이것은 β₀와 f_β의 독립항이므로:

> **β_final = cosh(λT_total)·β₀ - (f_β/λ²)·Ψ**
>
> 여기서 **Ψ = cosh(λT_total) - cosh(λ(T_f+T_w)) - cosh(λT_f) + 1**

**수렴 조건** |β_final| < |β₀|:

```
|cosh(λT_total)·β₀ - (f_β/λ²)·Ψ| < |β₀|
```

```python
"""확장 모델 전달 행렬 계산 및 수렴비 분석"""
import numpy as np

# === 시스템 파라미터 (사람 크기 모델) ===
g = 9.81
R = 1.0        # 줄 곡률 반경 [m]
h = 0.85       # CoM 높이 [m]
M_total = 75   # 총 질량 [kg]
I_inv = 20     # 역진자 관성모멘트 [kg·m²]
c_foot = 0.280 # 발 변위 계수

omega = np.sqrt(g / (R + h))     # 정진자 진동수
lam = np.sqrt(M_total * g * h / I_inv)  # 역진자 낙하율

print(f"ω = {omega:.4f} rad/s,  T_quarter = {np.pi/(2*omega):.4f} s")
print(f"λ = {lam:.4f} rad/s")

# === 제어 파라미터 ===
tau_fold = 100    # 접기 토크 [Nm]
I_delta = 5.0     # 접기 관성모멘트 [kg·m²]
a_f = tau_fold / I_delta  # 접기 각가속도

f_phi = (c_foot / R) * a_f   # 줄 가력
f_beta = (c_foot / h) * a_f  # β 가력

# === 행렬 생성 함수 ===
def make_P(omega, T):
    """φ 전달 부분행렬 (2x2 회전)"""
    c, s = np.cos(omega*T), np.sin(omega*T)
    return np.array([[c, s/omega], [-omega*s, c]])

def make_Q(lam, T):
    """β 전달 부분행렬 (2x2 쌍곡 회전)"""
    ch, sh = np.cosh(lam*T), np.sinh(lam*T)
    return np.array([[ch, sh/lam], [lam*sh, ch]])

def make_A(omega, lam, T):
    """전체 4x4 전달 행렬"""
    A = np.zeros((4, 4))
    A[:2, :2] = make_P(omega, T)
    A[2:, 2:] = make_Q(lam, T)
    return A

def make_b_fold(omega, lam, T_f, f_phi, f_beta):
    """FOLD 변위 벡터"""
    C = np.cos(omega * T_f)
    S = np.sin(omega * T_f)
    Ch = np.cosh(lam * T_f)
    Sh = np.sinh(lam * T_f)
    return np.array([
        f_phi/omega**2 * (1 - C),
        f_phi/omega * S,
        -f_beta/lam**2 * (Ch - 1),
        -f_beta/lam * Sh
    ])

# === 1사이클 전달 계산 ===
def one_cycle(T_f, T_w, omega, lam, f_phi, f_beta):
    """1사이클 전달 행렬 M과 변위 벡터 d 계산"""
    A_F = make_A(omega, lam, T_f)
    A_W = make_A(omega, lam, T_w)
    A_E = A_F  # T_e = T_f
    
    b_F = make_b_fold(omega, lam, T_f, f_phi, f_beta)
    b_E = -b_F
    
    M = A_E @ A_W @ A_F
    d = A_E @ A_W @ b_F + b_E
    
    return M, d

# === 수렴비 스윕 ===
beta0 = np.radians(5)  # 초기 기울기 5°

print(f"\n{'T_f':>6} {'T_w':>6} {'T_total':>7} {'β_final':>10} {'r':>8}")
print("-" * 45)

for T_f in [0.01, 0.05, 0.10, 0.15, 0.20]:
    for T_w_frac in [0.1, 0.15, 0.2, 0.25, 0.3]:
        T_quarter = np.pi / (2 * omega)
        T_w = T_w_frac * T_quarter
        
        M, d = one_cycle(T_f, T_w, omega, lam, f_phi, f_beta)
        
        v0 = np.array([0, 0, beta0, 0])
        v_final = M @ v0 + d
        
        beta_final = v_final[2]
        r = abs(beta_final / beta0)
        
        T_total = 2*T_f + T_w
        print(f"{T_f:6.3f} {T_w:6.3f} {T_total:7.3f} {np.degrees(beta_final):10.4f}° {r:8.4f}")
```
