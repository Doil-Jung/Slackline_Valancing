# 전류제어 + 단일 모델기반 칼만 — 설계노트 (2026-06-22)

> §7의 두 병목(펌웨어 비-전류제어, θ 추정 폭주)을 한 묶음으로 해결한 펌웨어
> `opencr_test/lqr_balance_current/lqr_balance_current.ino` 의 설계근거·수치검증·하드웨어
> 점진검증 절차. 게인/행렬은 `compute_K_measured.py`(v11_small 예시값, DT=0.002) 산출.

## 1. 진단 — θ 폭주의 두 근본 원인 (옛 `lqr_balance.ino` 코드에서 확정)

1. **가짜 토크 → 칼만 예측 불일치(양의 피드백).** 옛 펌웨어는 위치제어(`OP_EXTENDED_POSITION`)에
   `δ_goal = δ − τ/KP_EQUIV`(KP_EQUIV=8.0)로 토크를 흉내냈다. 그런데 칼만 예측은 `x_pred =
   Ad·x̂ + Bd·prev_tau`에서 **설계 토크 τ**를 넣는다. 모터가 실제로 내는 토크(위치서보 출력)는
   이와 다르므로 예측이 현실과 어긋난다. 모터가 움찔 → IMU가 모델이 예측 못 한 반작용을 관측 →
   innovation 급증 → 칼만이 그만큼 보정 → LQR이 더 큰 토크 → 더 큰 움찔. **자기반작용 양의 피드백.**

2. **상보필터(CF)와 칼만의 직렬 중첩 + α 오염.** 옛 펌웨어는 CF가 만든 `theta_cf`를 칼만의
   *측정값* `y_theta`로 다시 넣어 필터를 직렬 중첩했고, 더 나쁘게 `α = θ_cf − δ`,
   `α̇ = θ̇ − δ̇`(엔코더 생차분)로 합성했다. 결과적으로 **θ 오차가 α로 직접 새고**, 측정행렬
   `C_obs`가 가정한 {α,θ,α̇,θ̇} 독립성(대각 R_kf)이 깨진다.

## 2. 해법 — 단일 모델기반 칼만 (CF 제거)

CF를 없애고 IMU·엔코더의 **물리 측정을 그대로** 칼만에 넣는다. 측정행렬 C(4×6):

| z | 측정 | C 행 (φ,α,θ,φ̇,α̇,θ̇) |
|---|---|---|
| z₀ | θ_acc (가속도계 중력기울기, 절대 θ) | [0,0,1,0,0,0] |
| z₁ | θ̇_gyro (자이로 Y) | [0,0,0,0,0,1] |
| z₂ | δ = θ−α (엔코더 위치) | [0,−1,1,0,0,0] |
| z₃ | δ̇ = θ̇−α̇ (`PRESENT_VELOCITY`) | [0,0,0,0,−1,1] |

핵심: **α와 φ는 측정하지 않는다.** 칼만이 모델 커플링(Ad)과 엔코더 구속으로 복원한다. 이로써
칼만이 곧 상보필터 역할을(모델 기반으로 제대로) 흡수한다. 입력은 **전류제어의 진짜 τ**라서
원인 1도 동시 해소된다. α̇는 엔코더 생차분 대신 `PRESENT_VELOCITY`를 직접 읽어(§7-3 해소) δ̇로 넣는다.

**게이팅:** 모터 구동으로 가속도 크기가 1g에서 벗어나면(ratio 0.64~1.56 밖) z₀(θ_acc)
innovation을 0으로 막는다(`직립근방 게이팅`, 간단판). 정상상태 L은 z₀ 포함 가정이라, 게이팅이
잦으면 θ 절대기준은 자이로 적분에 의존 → 단기 드리프트 가능. 직립 근방 짧은 구동에선 무방하나,
오래 큰 구동이 필요하면 IMU 선형가속을 운동학으로 예측해 빼는 EKF 측정모델로 격상할 것.

## 3. 전류제어 전환

- `OP_CURRENT` 모드, `CURRENT_LIMIT=1193`(하드 상한). τ→전류: `GoalCurrent_unit = τ × 285.082`
  (= 1000/(Kt·2.69), Kt=1.304 공칭). TAU_MAX=3.0 → 855 unit(2.30A, 한계 내).
- **MOTOR_DIR(±1)**: 전류 부호 ↔ 모델 τ 방향 매핑. **엔코더↔δ 부호 불일치는 미해결 실물검증
  항목**(§7)이므로 펌웨어에 상수로 분리하고, 브링업에서 결정한다(아래 절차 2).
- `prev_tau`는 **실제로 적용된 모델 τ**(전류 cap 반영, `commandTorque()` 반환)를 쓴다 → 전류가
  CUR_SAFE에 걸려도 칼만 예측이 실제 토크와 일치.

## 4. 수치검증 (사이드 시뮬, scipy)

- 가제어성 rank 6/6, 관측가능성 rank 6/6.
- 폐루프 max|eig| = 0.9981, 관측기 max|eig| = 0.9937 (둘 다 <1, 분리원리상 안정).
- **관측기 정합**: 추정 초기값을 0으로 틀리게 줘도 추적 — 최종 θ 추정오차 0.0004°.
  (펌웨어의 innovation 행/열 매핑이 정확함을 확인.)
- **폐루프**: 무노이즈 θ→0.0000°로 수렴(발산/θ폭주 없음). 측정노이즈 하에선 ~1° 바닥에서
  유계 진동(느린 0.998극이 노이즈를 누적한 것; 더 좋은 센서·튜닝으로 축소).
- **유의**: LQR 극이 느리고(≈1 rad/s) 작은 로봇에서 과도 피크가 큼(IC 0.5°→피크 3.8°,
  2.9°→22°, 무노이즈). 저구동·비정규 플랜트 특성이며 §6.3 "v11_small 큰 각도 복원 경계선"과
  일치 — LQR이 약한 바로 그 구간이 FWE의 표적.

## 5. 하드웨어 브링업 절차 (★순서·게인 주의)

> **이 플랜트는 개루프 불안정(도립진자)이다.** 따라서 흔한 '낮은 게인부터 점진'은 여기선
> 틀린다 — gain이 낮으면 제어가 불안정 극을 못 잡아 **균형이 아니라 발산**한다(80° 안전정지).
> 게인별 폐루프 max|eig|: gain 0.01→1.039, 0.05→1.014, 0.1→1.002(모두 발산),
> **0.2→0.999, 0.3~1.0→0.997~0.998(안정).** 최소 안정 게인 ≈ 0.2~0.3.

1. **센서 점검('d').** 손으로 기울여 thAcc·δ·δ̇가 부호·크기 맞는지, 정지 시 ratio~1.0인지.
2. **MOTOR_DIR 결정 — 폐루프로 찾지 말 것.** (낮은 게인=발산이라 위험.) 먼저 `torque_cal`
   스케치로 작은 **+전류**가 힙을 **+δ(앞접기)** 방향으로 미는지 *개루프*로 확인 → 아니면
   `MOTOR_DIR`을 −1로. (엔코더↔δ 부호 불일치는 §7 실물검증 항목.)
3. **폐루프 시작.** `CUR_SAFE=600`(≈1.6A), `gain_scale=0.30`(안정 하한 근처)에서 'z'→'c'.
   잘 잡으면 게인 0.5→0.7→1.0, 전류 상한 855까지 단계적으로 ↑.
4. 안정화 확인 후 실측(m,ℓ,I,Kt)으로 `compute_K_measured.py` 재계산 → 상수 교체 → FWE 이식.
5. **★실물 줄(베어링 진자) 위에서.** 모델은 발이 줄 위(φ 원호)에 있다고 가정 — 벤치에 발을
   고정하면 φ 자유도가 없어 모델과 어긋난다.

### 5.1 무엇이 보일까 — MuJoCo 거동 재현성 (LQR, gain=1.0)
이 펌웨어는 **LQR**이다. 펌웨어 플랜트(v11_small)에 초기 5° 기울임을 주면(선형 풀상태FB 기준):

| gain | δ 피크 | 펴짐(|δ|<5°) | θ피크 | maxτ | 비고 |
|---|---|---|---|---|---|
| **1.0(설계점)** | +49°@0.22s | **0.88s** | 37.5° | 2.50 | MuJoCo "1초 내 펴기"와 일치 |
| 1.5 | +50°@0.36s | 1.40s | 38° | 3.00(상한) | 더 느림 |
| 2.0 | — | — | — | 64%포화 | **불안정** |

→ **게인을 올릴 필요 없다.** LQR은 gain=1.0이 최적이라 1.5는 토크상한에 닿아 더 느려지고
2.0은 불안정·포화한다(펌웨어도 1.0에서 캡). gain=1.0에서 **δ≈49° 접힘 → 0.9초 내 펴짐**으로
MuJoCo의 "크게 접었다 1초 내 펴기"를 정성·정량적으로 재현한다. (완전정착 꼬리는 느린 0.998극으로
~2~3초; 노이즈 하 ~1° 바닥.) 단 이는 LQR 연속 비례복원이지 FWE의 **의도적 과접기-대기(n·T_osc)-펴기**
안무는 아니다(그건 ε_FWE 상태머신=다음 단계). 더 빠른 펴짐을 원하면 게인이 아니라 **Q 재튜닝**
(각도가중↑·R↓)으로: 각도 16배·R=1e-4면 펴짐 0.76s·무포화·안정.
※주의: 위는 사람 없이 *명목 모델* 기준. δ 피크 49°는 DELTA_MAX 60°에 근접, θ피크 37°는 소각
가정을 넘어서므로 실물 수치는 다를 수 있고, v11_small의 큰각 한계(§6.3)와 일치한다.
