```
M1 = 30.0 kg (하체)
m2_eff = 45.0 kg (상체+머리)
L1 = 0.85 m, LC1 = 0.425 m
LC2_eff = 0.4667 m
I1_cm = 1.8062, I2_cm = 3.8133
p1 = 51.00, p2 = 21.00, p1/p2 = 2.429
h_CoM = 0.9600 m (발목 위 무게중심 높이)
```

## 계산 1: R* (CoM 불변 조건을 만족하는 R)

**조건**: `[0, p₁, p₂] · M⁻¹(R) · [0, -1, 1]ᵀ = 0`

이 조건을 만족하는 R을 [0.01, 10.0] 범위에서 탐색.

### 결과: **해 없음**

```
Value at R=0.01: -14.992263
Value at R=1.0:  -14.992263
Value at R=10.0: -14.992263
```

**조건값이 R에 전혀 의존하지 않고 상수 (-14.99).**

### 해석

R이 아무리 변해도 p₁ ≠ p₂에 의한 CoM 변화를 보상할 수 없다.
→ **H1(p₁ = p₂)은 H3과 독립적인 필요조건이다.**
→ 줄의 곡률로는 체형의 질량 비대칭을 보상할 수 없다.

### 추가 의문

R에 무관하게 상수라는 것은 수학적으로 매우 흥미로운 결과.
이것이 질량 행렬의 구조적 성질에서 나오는 것인지 분석적으로 확인할 필요가 있음.
(예: M의 역행렬에서 R이 정확히 소거되는 구조가 있는지)

---

## 계산 2: ρ_foot (자유공간에서 접힘 시 발 궤적의 곡률 반경)

**방법**:
1. 자유공간에서 CoM 고정 + 각운동량 보존(L=0) 조건
2. 접힘 각도 δ를 0 → 0.3 rad로 변화시키며 발 궤적 (x_f, z_f) 계산
3. z = c·x² 포물선 피팅으로 곡률 반경 추출: ρ = 1/(2c)

### 결과

```
Parabola fit: z = 6.887864 * x^2
ρ_foot = 0.072591 m  (0.076 × h_CoM)
dAlpha/dDelta at δ=0: -0.423011
```

### 해석

- **ρ_foot = 0.073 m** — 매우 작은 값
- **h_CoM 대비 0.076배** — 파울레티의 최적 R (1.0~1.5 × h_CoM ≈ 0.96~1.44 m)과 전혀 다른 스케일
- 발 궤적의 곡률이 매우 급격하다는 의미 (거의 직선에 가까운 수평 이동 후 급격히 위로 감)

### 의문점

1. ρ_foot이 이렇게 작다면, 자유공간에서의 발 궤적과 줄의 곡선이 매칭되는 것은 현실적으로 불가능?
2. 아니면 계산에 오류가 있는지 확인 필요:
   - 발 궤적을 시각적으로 그려서 궤적 형태 확인
   - 다른 체형 파라미터(로봇 스케일 등)로도 계산하여 스케일링 확인
3. ρ_foot 정의 자체를 재검토할 필요:
   - 포물선 근사가 적절한 범위에서 이루어졌는지
   - 곡률의 물리적 의미가 원래 가설과 일치하는지

## 결론 및 다음 단계

### 확인된 것
1. **H1(p₁ = p₂)과 H3(R = ρ_foot)는 독립적인 조건이다** — 두 가설은 합쳐지지 않음
2. p₁ = p₂는 체형의 질량·길이 관계로, R로 보상 불가

### 확인 필요한 것
1. ρ_foot 계산의 정확성 검증 (발 궤적 시각화)
2. ρ_foot이 왜 이렇게 작은지 물리적 해석
3. 가설 H3의 재검토: "발 궤적 곡률 매칭"이 최적 R의 조건이 아니라면, 최적 R을 결정하는 다른 물리적 조건은 무엇인가?
4. R에 무관한 CoM 조건값(-14.99)의 해석적 유도
