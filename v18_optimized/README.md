## 핵심 설계 원칙 (형상최적화 문서 §0)

1. **길이가 길수록 안정** — 가능한 한 크게 (80cm, 여유되면 100cm)
2. **하체 무게추 금지** — 저중심은 발 던지기 효율을 망침
3. **발끝은 비워라** — 질량은 힙 근처로 몰기
4. **장비는 머리에** — 관성 앵커 + I_cm↑ = win-win
